  is the feedback loop FL movers → Ξ at gates → releases → FL movers, i.e. R177's UP cycles, now with an explicit instance of one
  link.

## 1. The mechanism (construction recipe for L-RED)
Ingredients, all realised in odxi_n37 (vertex numbers there):
1. An FL run whose movers have a Ξ/W gap. Here W's cycle node is 13 (priority 30) and every mover's Ξ cycle node is 20 (priority 6),
   through the single ODIFF vertex 27 of u23sw64. FL movers are value-dirty, so the gap exists at every mover: Ξ ⊴ W pointwise, and a
   released W-tied option needs Ξ(current) ◁ W.
2. A band vertex t (32: self-loop, priority 8) with Ξ(x) ◁ val(t) ⊴ W(x) at every state of the run. Then a gate o = (Odd, edges x, t)
   has:
   - σ̄(o) = x (Odd's best reply in Ξ);
   - τ(o) = t dual-optimal, since val(t) ⊴ W(x) ⊴ Ξ^d_τ(x) (Even's best reply to τ is at least W). So o ∈ ODIFF and τ never moves at o.
3. Two gates: 33 → {2, 32} reads the mover 2, whose Ξ rises at states 2, 3, 5, 6, 7. 34 → {32, 36} reads 9 via a pad 36 (Odd, single
   edge), and Ξ(9) is constant on states 1..9. The pad makes the two options tie exactly at state 0 (no early release).
4. A chooser e (35: Even, edges 33, 34). The options are W-tied (both have W = (32, ∅, 1)), start at 34. At states 1..4 Ξ(34) ▷ Ξ(33),
   so nothing is released (the key rule keeps 34 since 33 is not in the arena). At state 5, Ξ(33) passes Ξ(34), 33 is released, and
   the BFS key (33) < (34) picks it: an FL move at 5 → 6.
- To amplify, the chooser must itself feed a gate (its Ξ rises at its move), and choosers need several crossings. Each crossing needs
  the rising side to overtake a W-tied sibling in key order. Whether such a cascade can be made long is R179's question.
- Constraints any amplifier must keep (from the recipe; READING): (a) the band condition at every gate for the whole run (σ̄ and τ fixed
  there, else the TWO-FIX window ends, which FL-ANCHOR counts anyway); (b) W-ties of the chooser's options; (c) the key order matching
  the overtake order.

## 2. What remains provable (OPEN)
- An «overtake» bound. Per chooser e and W-constant run, count the states where some option's Ξ passes the current option's Ξ. Ξ is
  monotone at every vertex (VJ), so the passes of a fixed pair (y, z) alternate only if both rise. A polynomial bound on alternations
  of monotone sequences needs structure: L-RED's counting-only grid shows that counts alone do not suffice.
- On the corpus, Ξ at ODIFF vertices is constant on the gating states of every FL run (box 132 XIB 0). The only FL mover on an ODIFF
  vertex's Ξ-play (scratch check, gating states) is nep22f_n64's cycle node 48, at the run's single, last transition. Under the
  hypothesis «Ξ constant at ODIFF vertices on gating states», FL-ANCHOR gives FL ≤ (n + m)(1 + changes at W-cycle nodes + σ̄ changes)
  per run (conditional on [RULE]). This restates box 132; it is not a new lemma.

## 5. L-RED R179 and the revised target (Lead relay 14:04Z; claude/l-red a612b0a5, docs/red/R179-odxi.md, read through the relay)
- R179 kills the «constant» target on a real N5 run inside 𝒞^1O, with no gadget. DEAD instance: odxi_min_n12 (sha1 51661a75a4ec…;
  n 12, ODIFF 1). At FL transition 1, Even 7 switches 10 → 2 on an exact W-tie at even cycle node 5, which breaks Odd's cheap cycle
  10 → 7 → 10: Ξ(10) goes (7, ∅, 1) → (5, ∅, 7). R179 also has a lasso type (odxi_lasso_n13) and odxi_many_n32 (8 FL transitions,
  43 ODIFF Ξ-changes). My odxi_n37 (§0) is a gadget instance of the same DEAD and of the release step.
- Is «charge each ODIFF Ξ-change to the FL move that caused it» circular with FL-ANCHOR? YES (PROVED (lane), two lines):
  - By Lemma PREFIX's value formula, Ξ_j(o) ≠ Ξ_(j−1)(o) needs some Even vertex on o's Ξ-play (from σ̄(o), cycle included) to change
    strategy at j. τ and σ̄ are fixed, so in an FL run every such change is an FL move of transition j.
  - Hence GCH ≤ Σ_j |{o ∈ ODIFF : a mover of j lies on o's Ξ-play}| + (changes at cycle nodes) ≤ (|ODIFF| + |CN|) · FL. Substituted
    into FL ≤ CAP (1 + GCH), this gives FL ≤ CAP (1 + (|ODIFF| + |CN|) FL), which is vacuous.
- So (READING) the right object is the FL run length itself. FL-ANCHOR together with R178's XI-NEW is the relocation:
  - within an epoch, FL is at most CAP;
  - every new epoch is opened by a Ξ-rise at a gate or a cycle node, caused by a move of the same run;
  - a long FL run is therefore a self-sustaining feedback loop of gate overtakes.
  What is missing is a NON-CIRCULAR potential for that loop, i.e. one that does not count moves. Bounding the number of ODIFF
  Ξ-changes is equivalent to bounding FL, up to the factor CAP and the factor (|ODIFF| + |CN|).
- Revised targets O(1) / poly(n) for ODIFF Ξ-changes per FL run are therefore the same open problem as FL-POLY. I do not pursue them
  separately. R180 (L-RED) measures both against n.
