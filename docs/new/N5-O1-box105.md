- Lemma NONTIE-RET (PROVED, lane, elementary).
  - Statement: call a return of X NON-TIE if W(X) changes at its leave transition. Then in every W-run F, the number of non-tie returns of
    X is ≤ WCH_F(X) (the transitions of F changing W(X)). Every return of X is non-tie or a TIE return, i.e. its leave is a W-tie.
  - Proof: distinct returns of X have distinct leave transitions, because the leave precedes the re-entry and X holds one target at a
    time. A non-tie return's leave changes W(X). □
  - So RET_F(X) ≤ WCH_F(X) + TRET_F(X), where TRET_F(X) counts the tie returns.
- Corollary (PROVED, lane): RET-POLY ⇐ R3-POLY ∧ TRET-POLY.
  - Through PAY (box 98) this gives WRUN-POLY ⇐ R3-POLY ∧ TRET-POLY.
  - That is R95's «R3-POLY ∧ TIE-POLY» face, with TIE replaced by tie RETURNS. It is no new reduction. It locates the ping-pong: non-tie
    returns are paid by W-changes (L-RED's wx.py data, 16 / 16, is the non-tie case), and the counter's gap is the tie returns.
- Tie returns, bounded separately: NOT done.
  - Where they live: on the corpus they occur only in W-flat / W-tie families (xing, tog6b), ≤ 31 per W-run (n = 32).
  - A bound would have to come from T54 IDX-MONO / LEX-BFS: at a W-tie switch, S4a takes the least-index / key-least W-tight arena edge.
    The arena (Iσ) toggles, so X can leave and re-enter a tight target as Iσ changes. That makes TRET a count of Iσ-toggles at fixed W, i.e.
    Ξ-changes again (Iσ is defined by Ξ).
  - READING: the tie face is the XI-CH-POLY core at fixed W (R95's INT-XCH⁰ on W-constant intervals).
