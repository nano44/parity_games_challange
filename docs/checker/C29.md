## 4. Limits (iii): does (f) lean on the lane's definition of "value-changing"?
No, provided "value-preserving" is read as R15 (d) reads it.
- The O(n³) part does not depend on the definition.
  - Each transition of S is either a separator (a crossing or a non-flat fallback, counted once each, X + N of them) or lies inside a piece.
  - Inside a piece there is no crossing. So on F, Ξ = W (Lemma G (a)), and on the fixed R, Ξ = π ⊕ θ and W = π ⊕ w with fixed θ, w (Lemma G (b)). "Ξ changes" and "W changes" therefore coincide; that is signed Lemma G, not the lane's text.
  - So "(n − 2)·(X + N + 1) + X + N" bounds transitions changing Ξ, W or both.
- The O(n⁵) part needs "value-preserving ⇒ Ωσ = Ξ unchanged", the hypothesis of R15 (d). Ωτ is unchanged with τ fixed.
  - REFEREE-2's signed (v) and §6 say "transitions that change no value", i.e. neither Ξ nor W.
  - That is the lane's "Ξ or W" definition. It is not a reading in which only W counts.
- So the definition only makes explicit what REFEREE-2 signed. Limit (iii)'s caveat is accurate and sufficient.
- Optional N-3: in (f), write "value-preserving runs (Ξ and W unchanged) ≤ 4n(n−1)", so the reader need not go to (iii).
