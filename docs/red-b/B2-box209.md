## 4. Where E-DOM is used, and whether the use is valid (the Lead's question)
- Directly in exactly one place: (K2′) l. 101-106, to make the most relevant vertex z of Π Δ Π′ an e-vertex (or c_W, K0, K3, which
  (K0′) removes). Everything that compares classes through values inherits it: (K1′) (via F1), (K4′) (via LOC-GATE3), (K5′) (via
  DOM), and through those (L1′)-(L5′), (P1)-(P4), (P6) and the tail. B-ONLY3 (a separate landed fact) is used in (K3′ b, d) and
  (P4) case (3).
- The use is valid on Γ3: E-DOM3 needs only that every pad lies below every e-vertex; the pads have Ω ≤ 2 (P-N5-REACH l. 130) and
  every e-vertex has Ω above every β (Ω ≥ 6). Counter edom3 (every vertex more relevant than the least relevant e-vertex is an
  e-vertex, c_W, K0 or K3) is 0 on every genome run (81 frozen, all exhaustive and random genomes).
- Control (edomctl.py; the test key "edomx" of eng3.py, NOT R104's game): raising 1-3 β-vertices to (largest e-priority) + 1 breaks
  E-DOM3; on 2,000 random genomes (seed 1, N ≤ 5, M ≤ 12, both tie rules, every reference) k2 fires on 281 genomes (347 adjacent inversions of the sorted (value, class) list), and
  with it k1 (23 genomes), k3, k4, k5, l1-l5, p4, tail; bonly3, notie3, locgate3 fire as well (the landed facts themselves need E-DOM). So
  (K2′) is where the argument breaks without E-DOM, consistent with L-SI 52's report (E-DOM dropped on F_n: N5′-xi exponential; I did
  not read that report, the Lead quoted it).

## 5. Attacks tried and why each fails
- Exhaustive smallest tiers (§3): no violation; the tiers with M = N are vacuous (every mover has one option), the first rich tiers are
  (1, 4), (1, 5), (2, 4). (1, 6), (2, 5) and beyond are not run (counts 10^7-10^8 at ~4,000 genomes/s).
- Tie rules: three rules (keep-low, high, rand) on every frozen genome and per run on random ones; N5′-xi's own rule via n5v. No
  statement of §2-§5 looks at which best successor is taken; the counters agree.
- Every reference state b (not only T3): LEVEL3 is claimed for all b; the allref / exhaustive / random rows test all b.
- Pressure points the box lists (§8): (1) (K2′)/(K0′) at pb_g and across states: k0 tests «Λ = K1 iff K0, K3 ∈ Π» at every non-core
  vertex and state; k2 tests all pairs at all states at once, including the DOM triples. (2) (L2′) at pe_g: l2 0, and the e-vertex /
  pe_g never in FRONT. (3) (P4) case (3) and (D1′): d1 checks (D1′) on the full edge set; p4c3 0 on those 788 occurrences. (4) (P5)/(P7)
  BR-SEG-G on H: p6, p7 0 (p7 bounds each plateau by the Even vertices of Y, sharper than n_E3). (5) PLATEAU3 (ii): tail 0, longest
  tail 59 (a mutant). (6) N5XI-G3's tie step: §3 D.
- Climbs (climb3.py) on T3, T3/(N + M), plateau length per mover of Y, Φ values, stalls and tail length: best values small (T3 21 at
  (22, 51), plateau 6); no candidate violated a counter.
- E-DOM removed (control, §4): the argument fails exactly where expected; on Γ3 itself E-DOM3 cannot fail.
