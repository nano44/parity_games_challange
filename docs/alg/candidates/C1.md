# C1: NE(k), nested-escape fatal attractors (L-ALG, 2026-10-15; written before any test)

Status: CANDIDATE (sound by construction; completeness is the open question; polynomial for every fixed k).
Idea added over psolB/psolQ/psolC: the measured obstruction (docs/attr/A3-psolC-results.md section 3, DTR15-4 p.11) is the
escape branch: the opponent leaves the candidate set X for good and parks in a sub-trap that he loses in the parity game,
but psolC's reachability condition ("some later visit to X has a prefix maximum of p's parity") never credits p for that.
C1 credits it, by judging the escape region with the same solver one level down (a recursion on a strictly different
object: the escape game lives on (V \ X) x C, where C is the set of priorities, with two sinks). The recursion depth is a
fixed parameter k; NE(0) is literal psolC. The question C1 asks: is there a fixed k such that NE(k) is complete? The
expected killer (to be measured, not assumed): the depth needed grows with the size of the Two Counters game tc N.

## 1. Pseudocode (max-parity, TARGET.md section 1 conventions; players p in {0 = Even, 1 = Odd}, q = 1 - p)
Notation. G = (V, owner, E, pr), C = pr(V). Attr_p(G, A, T): standard attractor of T for p inside the vertex set A.
P_p(A) = {v in A : pr(v) mod 2 = p}.

Product game Pi_p(G, A, X) (DTR15-4 Definition 2, max-parity form, start priority included): states (v, c), v in A,
c in C; owner(v, c) = owner(v); moves (v, c) -> (w, max(c, pr(w))) for (v, w) in E with w in A.
Good_p(X) = {(y, c) : y in X, c mod 2 = p}. Entry state of x in X: (x, pr(x)).

Escape game Esc_p(G, A, X): a parity game with vertex set {(u, c) : u in A \ X, c in C} + {TOP, BOT};
pr(u, c) = pr(u); pr(TOP) = p (i.e. 0 if p = Even, 1 if p = Odd), pr(BOT) = q; owner(u, c) = owner(u); TOP and BOT
owned by p with a self-loop each. Moves from (u, c), for each (u, w) in E with w in A:
  if w not in X: -> (w, max(c, pr(w)));
  if w in X and max(c, pr(w)) mod 2 = p: -> TOP;      (a later visit to X with a good prefix maximum)
  if w in X and max(c, pr(w)) mod 2 = q: -> BOT.      (a bad visit: p has not won this segment)

```
NE_k(G, A):                                     # returns win: A -> {0, 1, undecided}; sound for every k >= 0
  win := undecided on A
  loop:
    for p in (0, 1):
      X := GFP_k(G, A, p)
      if X != {}:
        D := Attr_p(G, A, X); win[D] := p; A := A \ D; restart the loop
    return win

GFP_k(G, A, p):                                 # greatest fixpoint of X -> X ∩ W_k(G, A, X, p) from X = P_p(A)
  X := P_p(A)
  while X != {}:
    W := W_k(G, A, X, p)
    if X ⊆ W: return X
    X := X ∩ W
  return {}

W_k(G, A, X, p):                                # vertices of X from which p wins the level-k segment game
  if k = 0: R := {}
  else:
    E := Esc_p(G, A, X)
    r := NE_{k-1}(E, V(E))                      # recursive call, one level down, on the escape game
    R := {(u, c) in V(E) \ {TOP, BOT} : r(u, c) = p}
  T := Good_p(X) ∪ R  (as states of Pi_p(G, A, X))
  return {x in X : (x, pr(x)) in Attr_p(Pi_p(G, A, X), V(Pi), T)}
```
NE(k) on input G = NE_k(G, V). NE(0) = psolC of DTR15-4 Fig. 5 (same fixpoint, same product, R = {}); the only change at
k >= 1 is the extra target R in W_k.

Positional strategies (TARGET.md section 5, D2 change 5): the strategies NE_k certifies carry memory (the current
prefix maximum c, as DTR15-4 Thm 3 says for psolC). The implementation outputs positional strategies on every decided
region D by oracle extraction with the candidate itself: for each p-vertex v of D and each successor w in D, restrict v
to the single edge (v, w) and re-run NE_k on the subgame G[D]; keep the first w for which NE_k decides all of D for p.
At most |D| * deg calls, each on a game no larger than G: polynomial. If no edge is accepted (the candidate is incomplete
on the restricted subgame), the implementation records STRAT-FAIL and, for verification only, falls back to Zielonka on
G[D] (labelled; never counted as the candidate's output). Every strategy is checked with experiments/harness/verify.py.

## 2. Soundness (claim, with proof sketch; to be refereed only if the candidate survives)
Claim S(k): for every G, A, and p, every x in GFP_k(G, A, p) is won by p in the subgame G[A], hence so is Attr_p(G, A, X).
Proof by induction on k. Let X* = GFP_k(G, A, p), so X* ⊆ W_k(G, A, X*, p). Fix x in X*. p's strategy from x: play the
Pi-attractor strategy towards T = Good ∪ R. Three kinds of consistent plays:
(i) the play reaches Good at some (y, c): y in X*, and the maximum priority on the segment from x to y (x and y included)
    is c, of parity p. Restart the same strategy from y.
(ii) the play reaches R at (u, c) (k >= 1 only): by the induction hypothesis S(k-1) applied to the escape game E, p wins E
    from (u, c). Follow that strategy. Its plays in E never reach BOT (BOT is a q-win sink); a play reaching TOP is, in G,
    a visit to X* whose prefix maximum since x has parity p: case (i), restart; a play that never reaches TOP or BOT stays
    in A \ X* for ever and satisfies the parity condition of E, which is the parity condition of G on those vertices.
(iii) neither: impossible, the attractor strategy reaches T in finitely many steps.
An infinite play with infinitely many restarts is a concatenation of segments each of whose maximum has parity p; the
maximum seen infinitely often is the maximum of infinitely many such segment maxima, of parity p. A play with finitely
many restarts ends in case (ii)'s tail, won by p. So p wins from x; attractors preserve winning. (Base k = 0: R = {},
cases (i) only: DTR15-4 Lemma 2 / Thm 2.)
The decided regions are removed and the loop restarts, as in psolC; removal of a dominion keeps the rest a valid subgame
of G and the remaining regions unchanged (standard). All strategies above use the memory c; positional strategies are
produced separately (section 1).

## 3. Running time (TARGET.md section 3 model, word RAM, numbers at bit cost)
Let n = |A|, m = |E|, d = |C| <= n + 1. Pi has at most n d states and m d moves; Esc has at most n d + 2 vertices and
m d + 2 moves, built in O(m d) time with indices of O(log(n d)) bits.
T_0(n, m) = O(n^2 m d): psolC (DTR15-4 Thm 2): at most n decisions, each at most n fixpoint iterations of one product
attractor O(m d) (the fixpoint iterations over X shrink X by at least one vertex each).
T_k(n, m) <= 2 n * n * (O(m d) + T_{k-1}(n d + 2, m d + 2)) for k >= 1 (at most n decisions, 2 players, at most n
fixpoint iterations, each one product attractor and one recursive call on Esc). Unrolling, with d <= n + 1:
T_k(n, m) = O((2 n d)^{2k+2} * m * d^{k+1}) = n^{O(k)} * m, polynomial in n + m for every fixed k. All numbers
manipulated are vertex indices and priorities of O(k log n) bits; no big integers. Strategy extraction: at most
n * m further calls of NE_k on games no larger than G. Priority compression (TARGET section 1): O(n log n), charged.
Running-time claim needing no unproven statement: NE(k) runs in time n^{O(k)} m. The unproven claim is completeness.

## 4. Why it is outside the known barriers (first reading; L-LIT signs off only if the candidate survives)
B1/B2 (separating automata): NE(k) is not a product of G with a fixed automaton over the priority alphabet; the escape
games depend on the current vertex set X (the automaton would read vertex membership, outside B1's alphabet; B16 is
about time-bounded weak separators, different object). B3 (fixed-tree recursions): NE(k) is adaptive (X is computed from
the game). B5-B7 (per-algorithm families): NE(k) is new; B7's examples are the first thing tested. B8-B14 (strategy
improvement, LCP, USO): not of that form. B17: no conflict.

## 5. Falsification plan (cheapest first; outcome recorded in docs/alg/DEAD.md if killed)
(a) the counterexample library, k = 1, 2, 3; (b) all n <= 3 (NE(0) already solves all, A3), the 1,380 psolC-partial n = 4
games (the only n = 4 games where NE(k) can fail, as NE(k)'s decided set contains NE(0)'s: W_k ⊇ W_0 for every X, so the
greatest fixpoints are nested); (c) random n = 5..12; (d) the 13 M1 families at growing size: for each, the smallest
k that solves it completely, as a function of size.
Kill criteria: (K1) a wrong decision (impossible by section 2; if observed, the implementation is wrong: fix or kill);
(K2) a game that NE(k) leaves undecided for every k up to the largest affordable, with the needed k growing with the
size of a family; (K3) an instance family where the needed k is unbounded. K2/K3 kill the candidate as an M4 route.
