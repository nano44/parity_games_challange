# C2: NE'(k), nested fatal attractors on the full product game (L-ALG, 2026-10-15; written before its tests)

Status: CANDIDATE (sound by construction; polynomial for every fixed k; completeness open).
Designed against the killer of C1 at k = 1 (docs/alg/DEAD.md, instance experiments/alg/instances/walk_s1_k1_n7_m10_1.pg):
C1's escape game turns every bad visit to X into a loss (sink BOT), but in the real play a bad visit merely continues
the segment, and a good visit may still follow (there: ... 4 -> 5 (bad, prefix maximum 5) -> 6 (good, 6)). C2 removes
the sinks: the recursive call is made on the whole product game H, in which only the good visits are sinks.

## 1. Pseudocode (delta against C1.md section 1; everything else is identical)
Product game H_p(G, A, X): vertex set = the states of Pi_p(G, A, X) reachable from the entry states (x, START),
x in X; owner(v, c) = owner(v); pr(v, c) = pr(v), except that every Good state (y, c) (y in X, c of p's parity, not an
entry state) is a sink: its only move is a self-loop and its priority is p's parity (p). All other moves as in Pi:
(v, c) -> (w, max(c, pr(w))) for (v, w) in E, w in A; from an entry state (x, START) the maximum starts at pr(x).
```
W'_k(G, A, X, p):
  if k = 0: R := {}
  else: r := NE'_{k-1}(H_p(G, A, X), V(H));  R := {s in V(H) : r(s) = p}
  return {x in X : (x, START) in Attr_p(Pi, V(Pi), Good_p(X) ∪ R)}
```
NE'_k, GFP'_k as NE_k, GFP_k of C1 with W'_k in place of W_k. NE'(0) = NE(0) = psolC.
Strategies: as C1 (oracle extraction with NE'(k) on each player's final region, verified by harness verify.py).

## 2. Soundness
As C1.md section 2, with case (ii) replaced by: the play reaches a state (u, c) of R; by the induction hypothesis p wins
H from (u, c); p's winning strategy in H either reaches a Good sink (a visit to X whose prefix maximum since the segment
start has p's parity: restart from that vertex of X), or never does and then satisfies H's parity condition, which on
non-sink states is G's parity condition. Hence every play is a concatenation of good segments, or ends in a tail won by
p under the parity condition. (Entry states are not sinks; a good visit at an entry vertex y counts only through its
non-entry copy (y, c), reached after at least one move, as DTR's "later visit".)

## 3. Running time (TARGET.md section 3)
|V(H)| <= n d + |X| <= n (d + 1), |E(H)| <= m d + n. T'_k(n, m) <= 2 n^2 (O(m d) + T'_{k-1}(n (d + 1), m d + n)),
T'_0 = O(n^2 m d): T'_k(n, m) = n^{O(k)} m, polynomial for every fixed k, indices of O(k log n) bits. No big integers.
No unproven claim in the running-time bound; completeness is the open claim.

## 4. Relation to C1
For every X, the true p-winning region of the escape game maps into the true p-winning region of H (a strategy that
never reaches BOT and reaches TOP or wins the parity condition does the same in H). NE'(k-1) and NE(k-1) are partial
solvers, so the decided sets need not be nested; the data decide. Barrier reading: as C1.md section 4.

## 5. Falsification plan
As C1.md section 5, plus: every C1 killer; the mutation walk (experiments/alg/walk.py --mode h) inside the
psolC-failure region hunting NE'(1) failures, then NE'(2) failures seeded with those, up to n = 12.
Kill criteria as C1 (K2/K3: needed k grows).
