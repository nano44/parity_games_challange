# C3: ZP, Zielonka's recursion with psolC pruning at every call (L-ALG, 2026-10-15 10:40Z; written before its tests)

Status: CANDIDATE. Complete and sound by construction (it is Zielonka's algorithm on the residual of a sound partial solver);
the open claim is the running time. It leaves the fatal-attractor family (DEAD.md C1, C2: fixed nesting depth = registers):
here the depth is unbounded and the cost is the number of recursive calls, which psolC's pruning may or may not keep polynomial.

## 1. Pseudocode (max-parity; G[A] the subgame on A; Attr_p the attractor)
```
ZP(G, A):                                    # returns (W_0, W_1), a partition of A
  (D_0, D_1, R) := psolC(G[A])               # DTR15-4 Fig. 5, literal reading (= NE(0)); R = undecided residual
  if R = {}: return (D_0, D_1)
  d := max priority in R; p := d mod 2; q := 1 - p
  T := Attr_p(G[R], P_d ∩ R)
  (W'_0, W'_1) := ZP(G, R \ T)               # call 1
  if W'_q = {}: W_p := R; W_q := {}
  else:
    B := Attr_q(G[R], W'_q)
    (W''_0, W''_1) := ZP(G, R \ B)           # call 2
    W_q := B ∪ W''_q; W_p := W''_p
  return (D_0 ∪ W_0, D_1 ∪ W_1)
```
ZP(G) = ZP(G, V). Strategies: Zielonka's construction on the residual part (attractor strategies; standard), psolC's regions by
oracle extraction with ZP itself (as C1.md section 1); all verified with harness verify.py.

## 2. Correctness
Zielonka's algorithm is correct on every game (McNaughton 1993 / Zielonka 1998, standard; the harness zielonka.py is the
fleet's reference). psolC's decisions are sound (DTR Thm 2) and removing a decided region D together with... note: psolC's
decided regions D_p are each of the form Attr_p(X) in the game alive at the time, so the residual R is a trap for the
decided players in the usual way (A3 / C1.md section 2): W_q(G[R]) = W_q(G[A]) ∩ R and W_p(G[R]) = W_p(G[A]) ∩ R for both
players. Hence (D_0 ∪ W_0, D_1 ∪ W_1) is the partition of A. Complete by construction.

## 3. Running time (TARGET section 3) — the open claim
Each call costs one psolC run, O(n^2 m d), plus two attractors. Let N(G) be the number of recursive calls. Zielonka alone has
N = 2^{Theta(n)} on known families (Friedmann recursiveladder; counter_core robust against memoisation: BARRIERS B5). psolC
solves recursiveladder, counter_core and counter_rob completely (A3), so N = 1 there. On the families psolC decides nothing
(tc, tc+, counter_symsi, counter_rr: A3) the first call recurses; whether psolC prunes the SUBgames is the question.
Unproven claim needed for M4: N(G) <= poly(n). Honest expectation (to be measured, not assumed): N grows exponentially
on some family, since nothing in psolC's pruning addresses Zielonka's re-solve after removing the opponent's dominion (call 2).
Kill criterion: N(G) superpolynomial on any family (growth exponent rising with size), or any instance where ZP's call count
exceeds plain Zielonka's by more than its pruning saves (never: pruning only removes vertices).

## 4. Barrier reading
B5 (Zielonka families) applies to the recursion but the families named there are pruned away by psolC; B3 does not apply
(adaptive); B1/B2 do not apply (no automaton product). B6 (Two Counters) targets tl/zlk/pp/...: tc is the first test.
