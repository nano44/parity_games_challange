# Dead candidates (L-ALG). Each: smallest failing instance (experiments/alg/instances/), exact obstruction, idea killed.

## C1 NE(k), nested-escape fatal attractors (docs/alg/candidates/C1.md) — DEAD as a fixed-k algorithm (2026-10-15 12:40Z)
- Data: NE(1) is complete on every game with n <= 4 (all 1,380 psolC-partial canonical n = 4 games, regenerated by
  experiments/alg/psolc_fail_n4.py; n <= 3 by A3, NE(0) = psolC) and on tc N <= 6, counter_symsi N <= 10 (strategies verified).
- Killer of k = 1: experiments/alg/instances/c1_k1_min_n7_m10.pg (7 vertices, 10 edges, 5 distinct priorities; Even wins all;
  shrunk by walk.py). NE(1) decides nothing; NE(2) solves it. Mechanism (hand-traced, notes/L-ALG.md): Even's fixpoint
  X = {1, 2, 5, 6}; from 1 Odd plays 1 -> 2 -> 0 (prefix max 4, 0 not in X); in the escape game from (0, 4) Odd goes
  0 -> 3 -> 4 -> 5 with prefix max 5 (a BAD visit to X = sink BOT, a loss for Even), although in the real play the segment
  continues 5 -> 6 (priority 6, a GOOD visit). The escape game's sink BOT is too pessimistic: a bad visit to X is not a
  loss, it is a continuation.
- Killer of k = 2: experiments/alg/instances/c1_k2_min_n11_m15.pg (11 vertices, 15 edges, 9 distinct priorities; Even wins
  all). NE(2) decides nothing; NE(3) solves it. Same mechanism one level down.
- Obstruction (exact): the escape game Esc_p(G, A, X) judges a bad visit to X as a loss; repairing that needs the full
  product game, i.e. candidate C2 (NE'(1) solves both killers). Growth: k = 1 fails at n = 7, k = 2 at n = 11 (kill
  criterion K2 of C1.md: the needed depth grows with the instance); no family with provably unbounded k was built (K3 open,
  not needed once C2 subsumes the idea).
- Idea killed: judging the opponent's escape by a sub-game that cuts at the candidate set X. Idea kept (in C2): recursion on
  the product game with the segment's prefix maximum as memory.
