# Dead candidates (L-ALG). Each: smallest failing instance (experiments/alg/instances/), exact obstruction, idea killed.

## C1 NE(k), nested-escape fatal attractors (docs/alg/candidates/C1.md) — DEAD as a fixed-k algorithm (2026-10-15 10:17Z)
- Data: NE(1) is complete on every game with n <= 4 (all 1,380 psolC-partial canonical n = 4 games, regenerated by
  experiments/alg/psolc_fail_n4.py; n <= 3 by A3, NE(0) = psolC) and on tc N <= 6, counter_symsi N <= 10 (strategies verified).
- Killer of k = 1: experiments/alg/instances/c1_k1_min_n7_m10.pg (7 vertices, 10 edges, 5 distinct priorities; Even wins all;
  shrunk by walk.py). NE(1) decides nothing; NE(2) solves it. Mechanism (hand-traced, notes/L-ALG.md): Even's fixpoint
  X = {1, 2, 5, 6}; from 1 Odd plays 1 -> 2 -> 0 (prefix max 4, 0 not in X); in the escape game from (0, 4) Odd goes
  0 -> 3 -> 4 -> 5 with prefix max 5 (a BAD visit to X = sink BOT, a loss for Even), although in the real play the segment
  continues 5 -> 6 (priority 6, a GOOD visit). The escape game's sink BOT is too pessimistic: a bad visit to X is not a
  loss, it is a continuation.
- Killer of k = 2: experiments/alg/instances/c1_k2_min_n11_m15.pg (11 vertices, 15 edges, 9 distinct priorities; Even wins
  all). NE(2) decides nothing; NE(3) solves it. Same mechanism one level down.
- Obstruction (exact): the escape game Esc_p(G, A, X) judges a bad visit to X as a loss; repairing that needs the full
  product game, i.e. candidate C2 (NE'(1) solves both killers). Growth: k = 1 fails at n = 7, k = 2 at n = 11 (kill
  criterion K2 of C1.md: the needed depth grows with the instance); no family with provably unbounded k was built (K3 open,
  not needed once C2 subsumes the idea).
- Idea killed: judging the opponent's escape by a sub-game that cuts at the candidate set X. Idea kept (in C2): recursion on
  the product game with the segment's prefix maximum as memory.

## C2 NE'(k), nested fatal attractors on the full product game (docs/alg/candidates/C2.md) — DEAD as a fixed-k algorithm (2026-10-15 10:35Z)
- Data: NE'(1) solves every C1 killer, every library game, all 1,380 psolC-partial n = 4 games, and 84,571 Strahler-2 games
  from the mutation walk (strtest.py, two seeds), with no wrong decision anywhere.
- Killer of k = 1: 45 shrunk games with 10..15 vertices (experiments/alg/out/c2k1_fail_seeds.jsonl; smallest
  experiments/alg/instances/cross_h_k1_n10_m16_*.pg), ALL of Strahler number 3; NE'(2) solves them.
- Killer family (explicit, unbounded): the sibling-trap family S_s (experiments/alg/strfam.py; instances/strfam_S{s}_n*.pg):
  S_1 = one vertex, priority 1, self-loop; S_{s+1} = two copies A, B of S_s, a connector c of even priority M+1 and a top
  vertex t of odd priority M+2 (M = max priority of S_s), edges A -> t, B -> c, c -> A's vertex 0, t -> B's vertex 0; all
  vertices Even's, Odd wins all; |S_s| = 3 * 2^(s-1) - 2. S_2 is the psolC killer psolc_min_n4_m6.pg up to relabelling.
  Strahler number s (DP-checked for s <= 3; by construction the Odd decomposition tree is the perfect binary tree of height s).
  Measured: NE'(k) solves S_s iff k >= s - 1, for s = 1..4 (S_4: 22 vertices, NE'(2) decides nothing, NE'(3) solves in 13 s);
  S_5 (46 vertices) running at the time of writing (notes/L-ALG.md Log).
- Obstruction (exact): the nesting depth needed is the Strahler number minus one (T-ALG1 (c), docs/alg/T-ALG1.md), i.e. the
  register number (DJT Thm 8); the family S_s has Strahler number log_2(n) + O(1), so every fixed k is incomplete and
  k = Theta(log n) costs n^{O(log n)}: the quasi-polynomial territory of universal trees / register games, not M4.
- Idea killed: ANY fixed-depth nesting of weak (reachability-under-prefix-maximum) conditions, i.e. the whole fatal-attractor
  family (psol, psolB, psolQ, psolC, C1, C2): depth = registers. What survives as a (non-M4) by-product: T-ALG1 (a), psolC is
  complete exactly on Strahler-1 games (proof in docs/alg/T-ALG1.md, unrefereed).
