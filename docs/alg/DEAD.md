# Dead candidates (L-ALG). Each: smallest failing instance (experiments/alg/instances/), exact obstruction, idea killed.

## C1 NE(k), nested-escape fatal attractors (docs/alg/candidates/C1.md) — DEAD as a fixed-k algorithm (2026-10-15 10:17Z)
- Data: NE(1) is complete on every game with n <= 4 (all 1,380 psolC-partial canonical n = 4 games, regenerated by
  experiments/alg/psolc_fail_n4.py; n <= 3 by A3, NE(0) = psolC) and on tc N <= 6, counter_symsi N <= 10 (strategies verified).
- Killer of k = 1: experiments/alg/instances/c1_k1_min_n7_m10.pg (7 vertices, 10 edges, 5 distinct priorities; Even wins all;
  shrunk by walk.py). NE(1) decides nothing; NE(2) solves it. Mechanism (hand-traced, notes/L-ALG.md): Even's fixpoint
  X = {1, 2, 5, 6}; from 1 Odd plays 1 -> 2 -> 0 (prefix max 4, 0 not in X); in the escape game from (0, 4) Odd goes
  0 -> 3 -> 4 -> 5 with prefix max 5 (a BAD visit to X = sink BOT, a loss for Even), although in the real play the segment
  continues 5 -> 6 (priority 6, a GOOD visit). The escape game's sink BOT is too pessimistic: a bad visit to X is not a
  loss, it is a continuation.
- Killer of k = 2: experiments/alg/instances/c1_k2_min_n11_m15.pg (11 vertices, 15 edges, 9 distinct priorities; Even wins
  all). NE(2) decides nothing; NE(3) solves it. Same mechanism one level down.
- Obstruction (exact): the escape game Esc_p(G, A, X) judges a bad visit to X as a loss; repairing that needs the full
  product game, i.e. candidate C2 (NE'(1) solves both killers). Growth: k = 1 fails at n = 7, k = 2 at n = 11 (kill
  criterion K2 of C1.md: the needed depth grows with the instance); no family with provably unbounded k was built (K3 open,
  not needed once C2 subsumes the idea).
- Idea killed: judging the opponent's escape by a sub-game that cuts at the candidate set X. Idea kept (in C2): recursion on
  the product game with the segment's prefix maximum as memory.

- Data: NE'(1) solves every C1 killer, every library game, all 1,380 psolC-partial n = 4 games, and 84,571 Strahler-2 games
  from the mutation walk (strtest.py, two seeds), with no wrong decision anywhere.
- Killer of k = 1: 45 shrunk games with 10..15 vertices (experiments/alg/out/c2k1_fail_seeds.jsonl; smallest
  experiments/alg/instances/cross_h_k1_n10_m16_*.pg), ALL of Strahler number 3; NE'(2) solves them.
- Killer family (explicit, unbounded): the sibling-trap family S_s (experiments/alg/strfam.py; instances/strfam_S{s}_n*.pg):
  S_1 = one vertex, priority 1, self-loop; S_{s+1} = two copies A, B of S_s, a connector c of even priority M+1 and a top
  vertex t of odd priority M+2 (M = max priority of S_s), edges A -> t, B -> c, c -> A's vertex 0, t -> B's vertex 0; all
  vertices Even's, Odd wins all; |S_s| = 3 * 2^(s-1) - 2. S_2 is the psolC killer psolc_min_n4_m6.pg up to relabelling.
  Strahler number s (DP-checked for s <= 3; by construction the Odd decomposition tree is the perfect binary tree of height s).
  Measured: NE'(k) solves S_s iff k >= s - 1, for s = 1..4 (S_4: 22 vertices, NE'(2) decides nothing, NE'(3) solves in 13 s);
  S_5 (46 vertices) running at the time of writing (notes/L-ALG.md Log).
- Obstruction (exact, citable): on the family S_s (Strahler number s, |S_s| = 3*2^(s-1)-2), NE'(k) decides every vertex iff
  k >= s-1, measured for s = 1, 2, 3, 4 (S_1..S_4; NE'(3) on S_5 did not finish in 1700 s of Python, so s = 5 is unmeasured).
  Every psolC (= NE'(0)) failure found (1,389 games) has Strahler number 2 and every NE'(1) failure found (45 games) has
  Strahler number 3 (experiments/attr/strahler.py). Reading: the nesting depth of prefix-maximum memories that the family
  needs equals the Strahler number minus one, and by Daviaud-Jurdzinski-Thejaswini, arXiv 2003.08627v2, Lemma 7 + Theorem 8
  the Strahler number equals Lehtinen's (defensive) register number; so each nesting level is one register, the hierarchy
  NE'(k) is the register hierarchy, and since S_s has Strahler number log_2((n+2)/3) + 1, no fixed k is complete and
  k = Theta(log n) costs n^{O(log n)} (DJT Prop. 3 bounds the Strahler number by floor(lg n) + 1): the quasi-polynomial
  territory of universal trees / register games (DJT Thm 32), not M4. Conjectured exact statement: T-ALG1 (c).
- Idea killed: ANY fixed-depth nesting of weak (reachability-under-prefix-maximum) conditions, i.e. the whole fatal-attractor
  family (psol, psolB, psolQ, psolC, C1, C2): depth = registers. What survives as a (non-M4) by-product: T-ALG1 (a), psolC is
  complete exactly on Strahler-1 games (proof in docs/alg/T-ALG1.md, unrefereed).

  psolC-partial n = 4 games, 8,000 random games (n = 5..12); on all 13 M1 families at every size run it makes <= 5 recursive
  calls (tc N <= 14, tc+ N <= 12, counter_symsi N <= 12, counter_rr N <= 20; the other 9 families 1-2 calls), where plain
  Zielonka grows exponentially on 9 of them (experiments/alg/out/zp_families_c3_{a,b,c}.csv). So the published hard families
  are not its killers: psolC solves their recursion nodes.
- Killer family (explicit, exponential): T_R = R tiles of the 32-vertex unit U8 = experiments/alg/instances/zp_ga_K8_n32_calls247.pg
  (itself 8 copies of the psolC-blind gadget S_2 with owner swaps, priority shifts and 13 inter-block edges, found by the
  genetic search zp_ga.py), tile i with priorities shifted by 36 i, plus at every tile the two cross edges
  (vertex 0 of tile i -> vertex 7 of tile i-1) and (vertex 21 of tile i -> vertex 4 of tile i+1) (zp_ladder2.build with
  template (18, [(0,-1,7), (21,1,4)]); instances/zp_tile8_R{1,2,3,4,5}_n*.pg; curve tool zp_curve.py).
  Measured ZP recursive calls: R = 1: 247 (n = 32), R = 2: 7,273 (n = 64), R = 3: 234,133 (n = 96): a factor of ~30 per tile of
  32 vertices, i.e. calls >= 30^(n/32) ~ 2^(n/6.5), while the unit alone is tiny. (R = 4, n = 128, running at the time of
  writing: out/zp_curve_tile8_R4.log.) A second unit (U10 = zp_ga_K10_n40_calls659.pg, template (11, 8 edges)) gives
  659 / 10,795 / 132,507 at R = 1/2/3 (n = 40/80/120). GA table without tiling: 129 / 247 / 659 / 1,943 / 4,173 / 12,255
  calls at n = 24/32/40/48/56/64 (instances/zp_ga_K*.pg): a constant factor ~2.5 per 8 vertices.
- Obstruction (exact): psolC prunes a recursion node only if the node's game has a Strahler-1-certifiable dominion for some
  player (T-ALG1); the gadget S_2 and its compositions are psolC-blind at every node that Zielonka's recursion visits, and then
  the recursion is plain Zielonka's: the second call (re-solving the game after removing the attractor of the opponent's
  dominion found by the first call) re-solves almost everything. Nothing in the pruning addresses that re-solve.
- Idea killed: "partial solver + complete exponential fallback" as a polynomial algorithm: the fallback inherits its
  exponential families as soon as the partial solver is blind on them, and Strahler-2 gadgets make psolC blind everywhere.
  Idea kept: the published 13 families are weak tests for hybrids; the GA/tiling search (zp_ga.py, zp_ladder2.py,
  zp_curve.py) is the right falsifier for complete-but-unproven candidates.
