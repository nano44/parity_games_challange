# Referee report: arXiv 2511.03752 v1 ("Attractors Is All You Need: Parity Games In Polynomial Time")

Referee: REFEREE. Date: 2026-10-14. Task: R1 (M2). Deadline 2026-10-16 18:30Z.

## Verdict: BROKEN

The paper's central claim (Theorem 1: the set A(G, d) is a dominion) is false. A 4-vertex game, with no
self-loops, on which the algorithm (Algorithm 1, read literally) outputs the wrong winner for every vertex:
`docs/referee/scratch/cex1-minparity.pg`. Lemma 2 (A(G, d̃) contains the minimal dominion) is false on the same
game, and under the charitable readings of the paper's definitions the algorithm does not terminate on it (Lemma 3
false). Details in sections 3 and 5. The earliest false sentence is in the proof of Theorem 1: "However, as v
must be visited, it follows that u ∉ U^k" (section 5.4).

## 2. The claimed theorem in TARGET.md vocabulary

The paper's conventions differ from TARGET.md in one respect that matters:

| | paper | TARGET.md |
| --- | --- | --- |
| priorities | on vertices, ρ : V → ℕ | on vertices, pr : V → {0..n} |
| winner of a play | **MIN-parity**: Even wins iff the *lowest* priority seen infinitely often is even (Sec. 1 and Sec. 2) | **MAX-parity** |
| self-loops | assumed absent (Sec. 3, first paragraph); removal delegated to a citation | allowed |
| strategies | positional partial functions (Sec. 2) | general; positional determinacy may be used |
| output | the pair (W_Even, W_Odd) only; no strategies | (W_E, W_O); implementations in the gauntlet must also output positional strategies |

Translation: a min-parity game with priorities ρ is equivalent to the max-parity game with priorities
ρ'(v) = M − ρ(v), M the smallest even number ≥ max ρ (parities preserved, order reversed). Under that translation
the paper's claim, in TARGET.md's words, is exactly the target statement of section 2 (M4): a deterministic
algorithm that on every parity game G (after self-loop removal) halts within O(n²(n + m)) steps and outputs
(W_E(G), W_O(G)). Theorem 7 in the paper ("There exists an algorithm that solves parity games in O(n²·(n+m))")
is that claim. The paper's running-time bound counts "d" as the numeric value of the top priority (section 5.6),
which TARGET.md's compression to {0..n} would repair; irrelevant since the algorithm is wrong.

## 3. The counterexample

### 3.1 The game (paper's convention: min-parity, no self-loops)

`docs/referee/scratch/cex1-minparity.pg` (sha256 `572abc2b02a935338d8fd4c1cbc2459b406c04a4b671c0b48ef36830b6fa9673`):

```
parity 3;
0 3 1 1,2 "v";
1 2 0 0 "u";
2 4 0 3 "x";
3 4 1 2,1 "y";
```

| vertex | owner | priority | successors |
| --- | --- | --- | --- |
| 0 (v) | Odd | 3 | 1, 2 |
| 1 (u) | Even | 2 | 0 |
| 2 (x) | Even | 4 | 3 |
| 3 (y) | Odd | 4 | 2, 1 |

**Truth: Even wins all four vertices.** Even has no choice anywhere (u and x have one successor each). The simple
cycles are {0,1} (priorities 3,2: min 2), {2,3} (4,4: min 4) and {0,2,3,1} (3,4,4,2: min 2); all have even minimum.
The only way for Odd to avoid u (priority 2) is to leave 0 for 2 and then cycle on {2,3} forever, which has
minimum 4. So no play has odd minimum.

Independent confirmation: Oink (pinned 8fbf0a7, `--zlk -v`) on the max-parity twin
`cex1-maxparity.pg` (priorities 4 − ρ: 1, 2, 0, 0; sha256 `2a321382e6f276e1b2be57a206d4703bf3bcd62dfacb2ff9d72f6d8399166991`)
reports "solution verified" with winner Even on all four vertices (`cex1-maxparity.sol`).

### 3.2 What Algorithm 1 does (literal reading)

Line 5: d̂ = 4 (max priority), player ○ = Even. Line 7: d̄ = 3 (max odd priority). Line 8: compute A(G, 3), the
"Odd-dominion" candidate:

| step | value | why |
| --- | --- | --- |
| U^0 = U_3(G) | {0} | odd priorities ≤ 3 |
| A^0 = Odd-Attr(G, {0}) | {0,1,2,3} | 1 (Even, only successor 0); 3 (Odd, successor 1); 2 (Even, only successor 3) |
| Odd-A*_3(G) | ∅ | k ∈ {0, 2}: U_{−1} = ∅, U_1 = ∅ (no priority 1 vertex) |
| base of A'_3(A^0) | {1} | vertices of A^0 not in A* ∪ U_3 with priority < 3: only u (priority 2) |
| A'_3(A^0) = Even-Attr(G, {1}) | {1} | 0 and 3 are Odd-owned with a successor outside {1}; 2's successor is 3 |
| U^1 = U^0 \ Even-Attr(G, (V \ A^0) ∪ A') | {0} \ {1} = {0} | fixed point |
| A(G, 3) | {0,1,2,3} | |

Line 9: W_Odd = {0,1,2,3}; line 10: G = ∅; the loop ends. **Output: W_Even = ∅, W_Odd = {0,1,2,3}.** Every vertex
is wrong. Theorem 1 claims A(G,3) is an Odd-dominion; Odd wins nothing.

Reproduce: `python3 -I docs/referee/scratch/aiayn.py --pg docs/referee/scratch/cex1-minparity.pg --trace`.

### 3.3 Why: the mechanism the paper relies on does not exist

U^{k+1} removes from U^k the vertices that the *opponent* (here Even) can *force* into A' (bad low-priority
vertices). From v = 0 Even cannot force a visit to u = 1: Odd can go to x = 2 instead. But Odd going to 2 means Odd
never returns to U = {0}: it cycles in {2,3} on priority 4, which it loses. The paper's proof of Theorem 1 argues
with the vertex "we must visit from u to U^k" (u must indeed be visited on every path from 0 back to 0), but the
definition only tests whether the opponent can force that visit. The two notions differ exactly when the attractor
player can avoid the bad vertex only by never returning to U, through vertices of priority > d. Those vertices are
excluded from the base of A' by the filter "ρ(v) < d", so nothing in the construction looks at them. See 5.4.

### 3.4 Other readings of the paper's definitions (all fail)

The definitions leave four binary choices open (section 6). I implemented all 16 combinations
(`aiayn.py --all-readings`). On cex1:

| reading | result on cex1 |
| --- | --- |
| literal (A' base filtered by ρ < d; A* in G; A' and the peel use the opponent's attractor) | wrong: W_Odd = V |
| drop the "ρ < d" filter in A' (any attractor-player choice) | stuck: A(G,3) = A(G,4) = ∅ with G ≠ ∅, the while loop makes no progress (Lemma 3 false) |
| A* restricted to A^k instead of G | same as literal: wrong |
| A' with the player's own attractor, or the peel with the player's own attractor (not both) | stuck |
| both A' and the peel with the player's own attractor | correct on cex1, but wrong on ~10% of random games (table in 3.6) |

### 3.5 A second counterexample: a solitaire game

`cex2-minparity.pg` (sha256 `8ee8f82b572da6563c4b91c363382ab912671bd38a5851bf54594c684d7fef57`), found by random
search, every vertex Odd-owned:

```
parity 3;
0 6 1 3,2;
1 5 1 3,0;
2 6 1 3,0;
3 4 1 1,2;
```

Every cycle through vertex 1 (priority 5) enters it from vertex 3 (priority 4), so Even wins everywhere
(Oink on the twin `cex2-maxparity.pg`: Even on all four). Algorithm 1: d̂ = 6, d̄ = 5, U_5 = {1}, A^0 = V,
A* = ∅, base of A' = {3}, Even-Attr({3}) = {3} (Even owns nothing, so attractors of Even are their base sets),
U^1 = U^0: A(G,5) = V, output W_Odd = V. Here the peel is vacuous by construction: with no Even vertices the
opponent's attractor never grows, so U^1 = U^0 whenever U^0 ∩ A' = ∅, which always holds. So on any solitaire
game for player ○ the function returns the whole ○-attractor of U_d whether or not ○ can win it.

## 4. Definitions, re-derived

Section numbers are the paper's. ✓ means I agree the definition is standard and unambiguous as used.

- **Parity game** (Sec. 2): (V, E, ρ, (V_◇, V_□)), E left-total, ρ : V → ℕ. ✓. Min-parity (see section 2 above).
  The paper writes "inf(π) is the set of priorities of π" and means the priorities seen infinitely often; harmless.
- **Strategy, consistency, Play(v, ρ_○), winning from v** (Sec. 2): positional partial functions. ✓ for the
  purpose of the algorithm (positional determinacy is cited). The strategy "closed on W" is the usual one.
- **○-closed set, ¬○-trap** (Sec. 2): W is ○-closed iff some ○-strategy is closed on W. ✓ (equivalently: every
  ¬○ vertex of W has all successors in W, every ○ vertex of W has one).
- **Dominion** (Sec. 2): "D is a dominion for ○ if D is ○-closed and ○ wins all vertices in D". This is weaker
  than the standard definition (○ has a strategy that stays in D and wins). It does not say "wins within D": a
  ○-closed set each of whose vertices ○ wins in G by leaving it qualifies. For the algorithm's soundness the weak
  form suffices, but only together with an argument that removing A preserves the winners of the rest, which the
  paper does not give (gap G4). "Dominions are closed under union" ✓ (same player). "There exists a minimal
  dominion in each non-empty parity game" ✓ (by determinacy some player wins somewhere; finiteness).
- **Arena restriction G \ U** (Sec. 2): ✓, with the usual caveat that the result is a parity game only if every
  remaining vertex keeps a successor; true when U is an attractor of the removing player's opponent... here U = A
  is a ○-attractor, so V \ A is a ○-trap (Lemma 1) and every vertex outside A keeps a successor outside A. ✓.
- **Attractor** (Sec. 2): standard inductive definition; monotone, idempotent. ✓.
- **Lemma 1** (Zielonka): V \ ○-Attr(G, U) is a ○-trap. ✓ (standard).
- **U_d(G)** (Sec. 3) = vertices with priority ≤ d of the same parity as d. ✓.
- **○-A*_d(G)** (Sec. 3) = ⋃_{k ≤ d, par(k) ≠ par(d)} {v ∈ ○-Attr(G, U_{k−1}(G)) : ρ(v) = k}: vertices of the
  opponent's parity k ≤ d that ○ can force (in the whole current G) to a vertex of ○'s parity with priority < k.
  Unambiguous as written. Note that the targets U_{k−1}(G) are taken in G, not in the current U^k; the attracting
  paths may leave A^k. The paper never addresses this (gap G1).
- **○-A'_d(G, A)** (Sec. 3) = ¬○-Attr(G, {v ∈ A \ (A* ∪ U_d(G)) : ρ(v) < d}). The base set is: vertices of A of
  the opponent's parity, priority < d, not in A*. Vertices of A with priority > d (all of the opponent's parity
  when d is the top priority of ○'s parity) are excluded by the filter. This exclusion is what cex1 exploits.
- **A^k, U^k, A(G, d)** (Sec. 3): U^0 = U_d, A^k = ○-Attr(G, U^k), U^{k+1} = U^k \ ¬○-Attr(G, (V \ A^k) ∪ A'(A^k)).
  U^k is non-increasing, so A = ⋂_k A^k = A^k at the first fixed point. ✓ well-defined; ≤ |U_d| + 1 iterations.
  Properties that do hold at the fixed point (my derivation): (i) ¬○ cannot leave A from U (U ∩ ¬○-Attr(V \ A) = ∅),
  so A is ○-closed; (ii) T := A \ ¬○-Attr((V \ A) ∪ A') is a ¬○-trap containing U. What does not follow: that ○
  can reach U from T \ U while staying in T, or that staying in T is a win for ○ (cex1: T = A = V, and the trap
  T contains the losing cycle {2,3}).

## 5. Lemmas and theorems, re-derived

### 5.1 Theorem 1 (A(G, d) is a ○-dominion). FALSE.
Counterexample: cex1 with d = 3 (section 3.2), A(G, 3) = V while W_Odd(G) = ∅; cex2 with d = 5 likewise. The
statement fails under the paper's weak dominion definition too (no vertex of A is won by Odd).

### 5.2 Lemma 2 (the minimal ○-dominion D ⊆ A(G, d̃), d̃ the max priority of parity ○). FALSE.
cex1: the only Even-dominion is V (every vertex is Even-won, and no proper subset is Even-closed: 0 → {1,2} forces
1 and 2 in, 2 → 3, 3 → {1,2} forces 1 in, 1 → 0). So D = V is the minimal dominion, ○ = Even, d̃ = 4. A(G, 4):
U^0 = {1,2,3}, A^0 = V, Even-A*_4 = ∅ (vertex 0 has priority 3 but Even-Attr(G, U_2 = {1}) = {1}), base of
A' = {0}, A' = Odd-Attr({0}) = V (1 → 0; 3 → 1; 2 → 3), U^1 = ∅, A(G, 4) = ∅ ⊉ D.

### 5.3 Lemma 3 (A(G, d̂) or A(G, d̄) non-empty, or G empty). UNPROVED; FALSE under the charitable readings.
Its proof is "follows from Lemma 2", which is false. Under the literal reading I found no game on which both sets
are empty (section 3.6); that is not a proof. Under the reading that drops the "ρ < d" filter, cex1 makes both
empty and Algorithm 1 loops forever.

### 5.4 Proof of Theorem 1, sentence by sentence (the earliest false step)
1. "Let k be such that A = A^k." ✓ (fixed point exists).
2. "It suffices to show that all vertices in U^k either stay in U^k or can reach some vertex u ∈ U^k via A such
   that p(u) < p(v) for each v we must visit in A." NOT SUFFICIENT: it says nothing about plays that never return
   to U^k. The opponent may keep the play in A \ U^k forever (cex1: {2,3}), and "we must visit" is undefined.
3. "Let u ∈ U^k, then if u is owned by ○ and it has some neighbour in U^k, then it holds, similarly for ¬○ with all
   neighbours." ✓ trivially.
4. "If u is owned by ○, then it must have at least one neighbour in A^k \ A'_d(A^k); otherwise u ∉ U^k. Similarly
   if u is owned by ¬○ for all neighbours." ✓ (this is what the peel guarantees, with ¬○-Attr(…) in place of A').
5. "Let v ∈ A^k \ U^k be the vertex with the lowest priority that we must visit from u to U^k. If v is owned by ○
   and there is no play ending at some u' ∈ U^k with ρ(v) > ρ(u'), then clearly v ∈ A'_d(A^k), similarly if v is
   owned by ¬○ and for all choices." Loose but, read as "v is a bad vertex not in A*", matches the base of A'.
6. **"However, as v must be visited, it follows that u ∉ U^k." FALSE.** u ∉ U^{k+1} requires u ∈ ¬○-Attr(G, (V \
   A^k) ∪ A'), i.e. that the opponent can *force* a visit to A' (or an exit from A^k). "Must be visited on the way
   back to U^k" does not give that: ○ can refuse to go back. cex1, d = 3: u = vertex 0 ∈ U^1, v = vertex 1 ∈ A',
   every path from 0 back to 0 passes 1, yet 0 ∉ Even-Attr(G, {1}). The remark after the proof ("the token is
   always pushed to another vertex") does not help: no self-loops are involved.
7. "Hence, such v does not exist." Does not follow.

### 5.5 Proof of Lemma 2, step by step
1. "D̃ = D ∩ U_d̃ and D̆ = D ∩ U_d̃" — typo; D̆ must be D \ U_d̃ (the opponent-parity vertices of D).
2. "v ∉ ○-Attr(G, U_{p(v)−1}) means ¬○ can avoid U_{p(v)−1} from v, or only reach it at larger priority" — the
   attractor gives the first alternative only; the second clause is not what an attractor says.
3. **"Therefore, v is not winning for ○." FALSE.** ¬○ avoiding every ○-vertex of priority < p(v) from v does not
   make ○ lose from v: the play may never return to v and have an even minimum above p(v). cex1 with ○ = Even,
   v = vertex 0 (priority 3): Odd avoids U_2 = {1} by 0 → 2 → 3 → 2 → …, with minimum 4; Even wins from 0.
4. "If the winning strategy on D does not visit v infinitely often, then there exists D' ⊊ D that is a dominion."
   UNPROVED and false as stated: in cex1 the Even strategy (forced) admits plays that visit 0 finitely often (the
   Odd-chosen {2,3} cycle), yet no proper sub-dominion exists. Minimality gives a strongly connected strategy
   graph, not "every play visits v infinitely often".
5. "If there exist k and u ∈ D̃ with u ∉ U^{k+1} and D̃ ⊆ U^k then there exists v ∈ D̆ ∩ ¬○-Attr(…)." Plausible
   (the peel attracts u through D, and D's ○-vertices of D̃ have a successor in D) but not argued.
6. "because D̃ ⊆ U^j implies D̆ ⊆ A*" — this implication is nowhere proved; it is the (false) step 3 again.
7. "by the definition of D and D̃ ⊆ U^j, it cannot be that v ∈ V \ A^j" — needs D ⊆ ○-Attr(U^j), which follows from
   D ⊆ ○-Attr(D̃) only if every cycle of D passes D̃; true for a ○-won D (every cycle's minimum is ○'s parity), but
   not written. Minor.
8. Conclusion fails on cex1 (5.2).

### 5.6 Theorem 4 (correctness), Lemma 5, Theorem 6, Theorem 7
- Theorem 4 rests on Theorem 1 (false) and Lemma 3 (unproved). Its proof also skips the argument that removing A
  from G preserves the winning regions of the remaining vertices (gap G4; the missing argument: V \ A is a ○-trap
  by Lemma 1 since A is a ○-attractor, and A ⊆ W_○(G), so W_¬○(G \ A) = W_¬○(G) \ A; this is standard but absent).
- Lemma 5 (A in O(n(n+m))): the bound as written is O(d(n+m)) for A* with d the numeric top priority, i.e.
  pseudo-polynomial in the priority values; with priorities compressed to {0..n} (TARGET.md section 1) the count is
  O(n) attractors per A* and O(n) peeling rounds, so O(n(n+m)) holds. Lines of the argument are otherwise fine.
- Theorem 6 (O(n²(n+m))): ≤ n loop iterations, ≤ 2 calls of A each: fine given Lemma 5. The proof refers to
  "the loop of line 3" (it is line 4).
- Theorem 7 is Theorems 4 and 6 together; false because Theorem 4 is.

## 7. Gaps (every step that is not machine-checked)

Nothing in the paper is machine-checked. Beyond the false steps above:

- G1. A* attracts to U_{k−1}(G), a set that may contain vertices outside the current A^k; the attracting path may
  leave A^k. No lemma covers it.
- G2. "We must visit" (proof of Theorem 1) is undefined; the definitions implement "the opponent can force", which
  is a different and weaker notion (the false step).
- G3. Vertices of A \ U with priority > d are excluded from A' and never analysed; plays confined to them decide the
  game (cex1, cex2).
- G4. Soundness of removing A (Theorem 4) needs V \ A to be a ○-trap plus A ⊆ W_○(G); the argument is absent.
- G5. The dominion definition is the weak one (section 4); Theorem 1 does not say which is meant.
- G6. Lemma 3 has no proof independent of Lemma 2.
- G7. Self-loop removal is cited, not specified; the Remark after Theorem 1 says the proof relies on their absence.
- G8. Running time is stated in terms of the numeric priority d; polynomial only after compression.
- G9. No strategies are output (TARGET.md section 5, D2 change 5).
- G10. The paper's own worked example (Figure 1) contains a self-loop, so its algorithm does not apply to it.
