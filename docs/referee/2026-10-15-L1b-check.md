## 2. Lemma 2.1' re-derived
G^cyc (cycle a_1 → … → a_n → a_1, pr(a_{n−1}) = 2) and G^tail (a_1 → … → a_{n−1} → z ⟲, pr(z) = 1) are TARGET games with n
vertices and one player; W_E(G^cyc) = V (every play runs through a_{n−1} forever), a_1 ∉ W_E(G^tail) (the unique play sees
priority 2 once). Both are deterministic, so the depth-D unravelling of the root is the label word of length D + 1: G^cyc
gives P_1^{n−2} P_2 P_1^{n−1} P_2 …, G^tail gives P_1^{n−2} P_2 P_1^ω; they first differ at position 2n − 2. Lemma 1.6 then
forces δ ≥ 2n − 2 and c ≥ δ. For n = 2 the root is the P_2 vertex itself and the argument still works (words P_2 P_1 P_2 … vs
P_2 P_1 P_1 …). Machine check: depth-k types of the two roots (my refinement on their disjoint union) first differ at
k = 2n − 2 for n = 2, …, 7. OK.

## 3. Theorem B re-derived
Statement: (v, G) winning, (v', G') losing, both one-player Büchi with ≤ n vertices ⇒ their depth-(2n − 1) types differ.
(*) Quotienting the part of G reachable from v keeps ≤ n vertices, the depth-D type of v and the winner, and makes full types
distinct; since the refinement sequence of a ≤ n-vertex structure has ≤ n − 1 strict steps, depth-(n − 1) types are already
distinct there. OK.
Suppose the depth-D types agree. π = stem x_0..x_{a−1} (shortest, v to a P_2 vertex u on a cycle) followed by a shortest
cycle through u; forth-condition path π' in G' with x'_t ≡_{D−t} π(t). Claim 1 (no repetition across a P_2 position of π',
else v' wins) OK. Claim 2 (x'_t = x'_{t'}, t < t' ≤ D − n + 1 ⇒ π(t) = π(t'), via ≡_{D−t} ⊆ ≡_{D−t'}, transitivity of type
equality and (*)) OK. Claim 3 (π(t) = π(t'), t < t' ⇒ a P_2 position of π in (t, t']): the two cases written (both ≥ a; t < a ≤ t')
are right; the third case t < t' < a is omitted (finding 1): it cannot occur because the stem is a shortest path and hence
repetition-free — one line. Conclusion: x'_0, …, x'_{D−n+1} pairwise distinct (a repetition x'_t = x'_{t'} gives by Claims 2–3 a
P_2 position q ∈ (t, t'] of π with x'_q ∈ P_2 since D − q ≥ n − 1 ≥ 0, contradicting Claim 1), so D − n + 2 ≤ |V'| ≤ n. OK.
"Hence W_E is a union of depth-(2n − 1) types and a program of depth 2n − 1 exists": each depth-k type on one-player games is
a modal formula of depth k over P_2 with ◇ (= Cpre_E) and □ = ¬◇¬; finitely many types; OK (cost unbounded, as the lane says).
Machine check (minimal depth = least k with no depth-k type containing both a winning and a losing pointed game, over ALL
pointed one-player Büchi games with ≤ n vertices): n = 1: 0; n = 2: 2; n = 3: 4; n = 4: 6 (3,248,306 pointed games; mixed types per
depth 2, 6, 48, 61, 46, 8, 0). So the minimal depth is 2n − 2 for n ≤ 4, between Lemma 2.1' (≥ 2n − 2) and Theorem B (≤ 2n − 1); Theorem B's bound is off by one from the truth for small n,
as the lane notes (notebook "off-by-one"). Type counts per depth stabilise at quotients of size 2, 14, 442, 48,062.
Consequence for T-L1: correct: locality alone cannot exceed 2n − 1 gates; a super-linear bound must count gates at bounded depth.
