# Referee report: T4 section 3(c), the lasso observation on deterministic weak separators

Referee: REFEREE. Date: 2026-10-14. Routed by the Lead 2026-10-14 18:58Z. Deliverable for L-STRUCT.

## Claim and source
- Claim: docs/lit/T4-weak-separators.md at trunk bcef882, section 3(c) (L-LIT, unrefereed): for a deterministic weak
  (n,d)-separator A, every cycle C of A's reachable transition graph with odd maximum satisfies
  (length of a shortest path q0 → C) + |C| > n; consequences (i) a weak separator whose reachable odd cycles are all
  short is strong, hence has ≥ s(n,d) states; (ii) a weak separator smaller than s(n,d) contains an odd cycle of
  lasso length > n that is never realised by an odd graph with ≤ n vertices.
- Definitions checked against arXiv 1807.10546 v2 (Czerwiński, Daviaud, Fijalkow, Jurdziński, Lazić, Parys), LaTeX
  source (e-print sha256 `ec825cd8…`), file `the-separation-approach.tex` §"Languages of play encodings" and
  §"Safety separating automata", and `intro.tex` lines 161–166 (separator). Verbatim:
  - alphabet Σ_d = {1, …, d}; a play is encoded by the sequence of its edge priorities;
  - "a (parity game) graph is called even if every cycle in it is even (i.e., the highest priority that occurs on the
    cycle is even)"; EvenCycles_{n,d} = "infinite words that encode an infinite path in an even graph with at most n
    vertices and d priorities"; OddCycles_{n,d} "defined in an analogous way" (every cycle odd);
  - a safety automaton "accepts an infinite word if there is an infinite run of the automaton on the word in which no
    rejecting state ever occurs"; deterministic = the transition relation is a function (total);
  - "a language S separates J from K if J ⊆ S and S ∩ K = ∅", an automaton is a separator of two languages if L(A)
    separates them; an (n,d)-separator separates EvenCycles_{n,d} from OddCycles_{n,d}.
  - Graphs are directed graphs with positive-integer edge priorities; the source states no restriction on self-loops or
    on parallel edges with different priorities (see finding 4).

## Verdict: OK. The statement and the inference both hold. Three strengthenings and one citation nit follow, numbered.

### Re-derivation of the statement
Let A be deterministic, with rejecting state ⊥ (T4's convention; the paper's total transition function with a set of
rejecting states is the same thing). Let R be A's reachable transition graph: states reachable from q0 by non-⊥
transitions, edges (q, p, δ(q,p)) with δ(q,p) ≠ ⊥. Let C be a *simple* cycle of R with odd maximum priority and P a
shortest path from q0 to a vertex c0 of C (P may be empty if q0 ∈ C). Being shortest, P is simple and meets C only in
c0. The lasso graph H = P ∪ C (vertices: the |P| vertices of P other than c0, plus the |C| vertices of C; edges: those
of P and of C, with their priorities) is a directed graph with edge priorities in Σ_d, every vertex has an outgoing
edge, and its only cycle is C: any cycle of H uses only edges of H, the edges of P form a path leaving each of its
vertices once and never returning, so a cycle of H lies inside C, and C is simple. Hence every cycle of H is odd: H is
an odd graph with |P| + |C| vertices. The infinite path of H that follows P and then goes round C forever is encoded
by the word w = π(P) · π(C)^ω ∈ OddCycles_{|P|+|C|, d}. The unique run of A on w is exactly P followed by C repeated;
it never visits ⊥, so A accepts w. If |P| + |C| ≤ n then OddCycles_{|P|+|C|,d} ⊆ OddCycles_{n,d} (a graph with fewer
vertices is a graph with at most n vertices), so w ∈ OddCycles_{n,d} and (W2) is violated. Therefore |P| + |C| > n. ✓

### Re-derivation of the inferences
(i) Suppose every reachable odd cycle of A has lasso length ≤ n. By the statement there is none, so every simple cycle
of R has even maximum. Let w be any word accepted by A; its run is an infinite path in R; the edges it uses infinitely
often form a strongly connected subgraph of R, in which the maximum priority m is the limsup of w; m lies on a closed
walk, hence on a simple cycle of R (the edge carrying m lies on some simple cycle of the strongly connected set),
whose maximum is then m; that maximum is even. So w ∈ LimsupEven_d: A satisfies (S2), and with (W1) it is a strong
(n,d)-separator, so |A| ≥ s(n,d). ✓ (Note the hypothesis is, by the statement, equivalent to "R has no odd cycle".)
(ii) A weak separator with fewer than s(n,d) states is not strong, hence by (i) has a reachable odd cycle; by the
statement its lasso length exceeds n; and since A accepts the lasso word, that word is not in OddCycles_{n,d}, i.e. it
is realised by no odd graph with ≤ n vertices. ✓

## Findings (none blocking)
1. **Strengthening, the exact condition.** For every reachable odd cycle C and *every* finite path P from q0 to C (not
   only a shortest one), the lasso word π(P)·π(C)^ω is accepted, so (W2) gives the exact necessary condition
   π(P)·π(C)^ω ∉ OddCycles_{n,d}. The count |P| + |C| > n is only the special case in which the lasso graph itself is
   the witness; a smaller odd graph may realise the same word when labels repeat (example: C a 3-cycle labelled
   3,3,3 with P empty: |C| = 3 but 3^ω ∈ OddCycles_{1,d}, realised by one vertex with a self-loop). L-LIT's clause
   "never realised by an odd graph with ≤ n vertices" in (ii) is the exact condition; the count is the cheap filter,
   necessary but not sufficient. L-STRUCT should state the filter as "minimal odd-graph size of π(P)·π(C)^ω exceeds n"
   when it needs the sharp form, and |P|+|C| > n when it needs the cheap one.
2. **Precision: C must be a simple cycle.** For a non-simple closed walk with odd maximum the lasso graph can contain
   even sub-cycles and need not be odd. No loss: the edge carrying the maximum lies on a simple sub-cycle whose
   maximum is the same odd number, so the statement holds for that cycle. Write "simple cycle".
3. **Scope: determinism is not needed for the statement.** The argument uses only that P·C^ω is a run avoiding ⊥, and
   the paper's acceptance is "there is a run avoiding rejecting states", so the same filter applies to every
   non-deterministic safety (n,d)-separator (any reachable odd cycle with any path from q0 to it). Inference (i) uses
   determinism in the same way the paper's Lemma 5.2 line does (for a non-deterministic automaton "every run avoiding
   ⊥ has even limsup" is what (S2) needs, and the same cycle argument gives it, run by run). So (i) and (ii) also hold
   for non-deterministic safety separators with s(n,d) replaced by the non-deterministic strong minimum.
4. **Citation nit (T4 §3(b), line 57, not §3(c)).** T4 attributes "at most one label per ordered pair" to CDFJLP §2.1.
   I find no such statement in the v2 source (`grep` for ordered pair / parallel / E ⊆ V × … returns nothing); the paper
   only says graphs are directed with positive-integer edge priorities. Harmless for (c) (the lasso uses each ordered
   pair once), but relevant to the SAT encoding's enumeration of "maximal" graphs: with parallel edges of different
   priorities allowed, the class of (n,d)-graphs is larger and the maximal graphs are different. L-LIT should either
   find the restriction in the paper (I may have missed a figure caption; the source has none) or prove that parallel
   edges do not change EvenCycles_{n,d}/OddCycles_{n,d} before relying on it.
