## (a) Lemma CHANGE-NEW
Hard check 1: the call is a function of (R, T) and of nothing else carried across visits. I read best_vertices (644-776)
and everything it calls, and listed every piece of state it reads:
- V: asserted empty on entry (648) and rebuilt from R (662-667). R is the argument.
- Locals: prevV, Z, CurR, CurZ, curdist (651-655). Candidates is a scratch array, written (714) before it is read (735).
- Q: the shared queue. It is empty on entry, because every producer drains it: 488, 697, 727, 883, 918, 944, 967, 1032; and
  the 898-912 seeding is drained at 918 when nonempty.
- str: read only at 73, and only to decide whether to write str. No set membership depends on str.
- attracts (41-56): reads Z, R and the static game.
- attractVertices (66-101): reads R, Z, G (= the arena argument), priorities and ins/outs (static).
- attractTangle (110-185): reads tpr, tv and tout (the tangle store, i.e. T), this->G (132), R, Z and G (the argument).
- Not read: X, W, the dominion state (S, dom_vector) and the pea_* arrays.
- this->G is read only at 132, and changes only at 1035, in the dominion loop after search_rec.
- So within one phase, where G′ is fixed, the call's set-level trace is a function of (R, p, T, order datum). It does not
  depend on depth, on X or on the position in the search. ✓
N11-a1 (closed). §23s cites STR-DET (R8) for "does not depend on str". That is not needed here: within best_vertices, str is
never read for a set decision (73 only guards a str write). STR-DET is about extraction (268), which best_vertices does not
call. The claim holds by the code reading above.

Hard check 2: within a phase, tangles are only appended.
- A tangle is stored at 440 (tidx = tpr.size()) and 461 (tpr.push_back). Nothing else removes or reorders it.
- tpr[t] = −1 happens only at 134, and only for a tangle with a vertex outside this->G. this->G changes only at 1035, in the
  dominion loop that runs after search_rec and ends the phase.
- A tangle with a vertex outside G′ can never fire in the phase anyway (its vertices must lie in R ∪ Z ⊆ G′, 138-139). So
  whether the lazy deletion has happened yet does not change any set output.
- So the alive set T only grows, T_x ⊆ T_y, and "born between x and y" = index in [ntv(x), ntv(y)). ✓

Step 1 (first difference). The inputs of each tattr in the call are determined by R, V and the earlier outputs: region-step
inputs by V and the earlier regions (690-702); threshold inputs by the round's Z (724); V by the candidate tests (713-760),
which read Z and R. So the first differing tattr e_k has equal input in both visits. A pure length difference cannot occur
first, because the length is determined by the outputs. ✓

Step 2 (region step at e_k). Same prefix P(τ⁺), so E_y ∩ T_x = E_x. EXACT gives Z_out(x) = Cl(base; T_x \ E_x) ⊆
Cl(base; T_y \ E_y) = Z_out(y). EXACT* gives Z_out(y) = Cl(base; F(y)), and F(y) ∩ E_y = ∅ (138-139). If F(y) ⊆ T_x, then
F(y) ⊆ T_x \ E_x and Z_out(y) ⊆ Z_out(x), so the outputs are equal, a contradiction. Hence F(y) ⊄ T_x: a tangle born
between x and y fires at e_k. ✓

Step 3 (threshold level at e_k). G11-a1 (closed). The level-t tattr (722-731) starts with Q = all of Z (724), Gx = R and no
consumption. So by DTL-proof Lemma 1.2 its output is exactly Cl_t(Z_in; T) over all of T. That gives
Z_out(x) = Cl_t(Z_in; T_x) ⊆ Cl_t(Z_in; T_y) = Z_out(y). By soundness, Z_out(y) ⊆ Cl_t(Z_in; used(y)). The same
contradiction argument applies. The "§22r Corollary" that §23s cites is about cross-visit monotonicity under (NS), and is
not what this step uses; Lemma 1.2 is. ✓

## (b) Corollary
- Distinct consecutive pairs (x_k, y_k) of one context have disjoint birth intervals [ntv(x_k), ntv(y_k)), since ntv is
  non-decreasing along the visits. Their witness tangles are therefore distinct, and each fires at R. So
  D_R ≤ #fired⁺(R). ✓
- A relevant-steal pair has P_y(σ⁺) ≠ P_x(σ⁺) at some step, hence a differing tattr output, so it is a differing pair:
  N*_R ≤ D_R. ✓
- With R10/R11, F_R ≤ 3·N*_R (G-P7-c2, consecutive pairs). So F_R ≤ 3·D_R ≤ 3·#fired⁺(R), with no premise. ✓
- With the R9 budget (as of record): GAP-A ⇐ (CTX⁺) ∧ (FIRED⁺-R), given STR-DET. SIGN.

## (c) Honest limit
- Tight: on spp_chain_up_n43, the root context (|R| = 43) has 42 visits and D_R = #fired⁺ = 41, in both orders. Both
  dtl_changenew.py and my probe give this.
- Is (FIRED⁺-R) at G′ essentially GAP-A? Answer in two parts.
  - Over all contexts: (FIRED⁺-R) and (CTX⁺) are both IMPLIED by GAP-A.
    - If S is polynomial, the tangles stored in a phase number ≤ n·S (Lemma W, DTL-proof §3(a), one extraction per top per
      search; not re-checked here), so #fired⁺(R) ≤ n·S.
    - The distinct contexts number ≤ (best_vertices calls per search)·S. That is polynomial, because every search_rec
      iteration removes at least one vertex of its R (879-890, 936-951, 962-991), and child contexts are disjoint subsets.
    - So GAP-A ⇔ (CTX⁺) ∧ (FIRED⁺-R), given STR-DET: the reduction is an equivalence. (FIRED⁺-R) is not a weaker or easier
      statement than what GAP-A needs. Like C1 of packet 10, it is a reformulation; its value is that it is per-context and
      free of steal bookkeeping.
  - At G′ alone: (FIRED⁺-R) at the root bounds only the root's own e*-transitions. S can be driven by deep contexts with few
    root firings, so FIRED⁺(G′) alone does not imply GAP-A. Conversely it is implied by GAP-A. On chain families where every
    search's new tangle fires at the root (spp_chain_up_n43), #fired⁺(G′) = S − 1, so at G′ it IS the search count. In that
    sense it is "GAP-A's core at the root", as §23s and R11 G-R11-6 say.

  identical, so no differing pair lies in an overlap, and each differing pair is charged by at most one transition.

  intervals).
