# S4: subgame-optimal start (a constructive reading of Friedmann's Lemma 4.3)

Status: UNDER TEST (2026-10-15).

## The opening
Friedmann LMCS 7(3:19) 2011 (arXiv 1106.0778) Lemma 4.3 ([Vög00]): for every parity game there is an improvement policy
I^lin with at most |V| iterations. Proof (p.7): fix a ≺-optimal σ*; I^lin(σ)(v) = σ*(v) whenever (v, σ*(v)) is in the arena
A_{G,σ}, else σ(v); the set m(σ) = {v : σ(v) = σ*(v)} grows strictly at every step because the restricted game
G' = (edges of σ, σ* and all of Odd's) keeps σ* optimal and some σ*-edge is improving there. The policy is non-constructive:
it needs σ*.

## The rule, exactly (S4 = subgame-optimal start, then a base rule)
```
S4(G):  if V = ∅ return ()
        p = max priority, T = {v : pr(v) = p}, A = Attr_{p mod 2}(T)           (Zielonka's first step)
        σ' = S4(G restricted to V \ A)                                           (optimal there, recursively)
        σ0 = σ' on V \ A (its edges exist in G), best-reward on A
        run SI on G from σ0 with the base rule (switch-all, or msf); return the final strategy
```
Iterations = sum over the recursion of the SI iterations at each level (depth ≤ d ≤ n + 1).
Implementation: `solve_S4` in experiments/si/si.py; rules `S4` (switch-all) and `S4:msf`.
Note: the Lemma 4.3 step itself is not used: once σ0 agrees with σ' on V \ A, "switch toward σ'" never fires; what remains
is the hypothesis that σ' is close to σ*, so that few iterations are needed on G. (A variant that keeps σ' as a target
and switches toward it in preference to switch-all was considered; it coincides with S4 as long as σ agrees with σ'.)

## Cost per iteration at bit cost
As switch-all (one valuation, O(n^2 m)) or as msf; the attractor computations are O(m) per level.

## Why it should be outside the barriers, before testing
- B8's fine print: every SI lower bound fixes the start strategy (Thm 6.14 and 8.4: "starting with ι_{G_n}"). S4 computes
  its own start, so the published runs do not apply as stated. Friedmann's sink games are won entirely by Odd and the
  counter lives in paths to the 1-sink, so removing the top-priority attractor need not simplify them: this is the
  expected failure mode.
- B9: not index-based (it is switch-all with a computed start). B11-B14: not applicable.

## Unproven assumptions, named
- A1: the optimum of V \ Attr(top) is within polynomially many improvement steps of the optimum of G, for every G.
- A2: the recursion's total count is dominated by the top level (depth ≤ n + 1 anyway).
