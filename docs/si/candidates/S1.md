# S1: Random-Action-Removal (the original Random-Facet) with Vöge-Jurdziński valuations — M4-R candidate

Status: UNDER TEST (2026-10-15). Verdict recorded in docs/si/DEAD.md or reported to the Lead.

## The rule, exactly
Zwick, arXiv 2607.06334 v1, Appendix D Figure 1 ("Rand-Act-Rem"), read on the strategy-improvement AUSO of a parity game
(his section 3: vertices = Even's positional strategies, edge a -> a[r] oriented toward the better valuation):
```
RAR(F, a):                      F = Even's available edges (initially all of E restricted to V_E), a = current strategy
  B = {(v, r) : v in V_E, r in F(v), r != a(v)}
  if B is empty: return a
  (v, r) = uniformly random element of B        (fresh random choice at every call: Random-Facet, not Random-Facet*)
  b = RAR(F minus (v, r), a)                     (optimum of the game without the edge (v, r), reached from a)
  if Ξ_b(r) ≻ Ξ_b(b(v)):  c = b[v -> r]; return RAR(F, c)     (the edge is improving at b: switch, one iteration)
  else: return b
```
Valuations Ξ_σ: Friedmann LMCS 7(3:19) 2011 (arXiv 1106.0778) section 3 (cycle node, more-relevant path nodes, length), via the
optimal counterstrategy (Lemma 3.1, VJ00). Priorities made injective by rank (experiments/si/si.py header). Start strategy:
PGSolver's best-reward initial strategy (stratimpralgs.ml:85-87), as in the M1 bench. Iterations = switches (Zwick's path length).
Implementation: experiments/si/si.py, `Engine.rar`.

## Cost per iteration at bit cost (TARGET.md section 3)
One valuation per switch and one per recursion leaf: a valuation is n triples (vertex, n-bit set, length ≤ n), computed in
O(n^2 m) word operations (n candidate cycle nodes, each an O(n m) restriction pass); comparisons cost O(n) bits. Random bits:
O(log m) per call. Number of calls ≤ (m + 1)·(switches + 1), so total time is polynomial in n + m times the number of switches.
No big integers beyond n-bit set keys. Verified in the engine: `Engine.evals` counts evaluations (each cached per strategy).

## Why it lies outside B8-B14 (docs/lit/BARRIERS.md), before testing
- B8 (switch-all, switch-best, Zadeh, Cunningham): different rule; those are deterministic.
- B9 (Disser-Loho-Maat-Mosis 2512.16684 Thm 4.3): index-based deterministic rules with o(m/log m) memory. RAR is randomized and
  compares valuations.
- B10: Random-Edge (Friedmann thesis Thm 4.76) is a different rule. Random-Facet*: the 2^Ω~(√m) bound of SODA 2011 needs a fixed
  permutation; the errata (arXiv 1410.7871 v1, p.1-2) withdraws it for Random-Facet itself: "the claim that the expected numbers of
  steps performed by Random-Facet and Random-Facet* are the same is false". The surviving Random-Facet lower bound is for
  shortest paths (Friedmann-Hansen-Zwick arXiv 1410.7530, Theorem 6.3: e^Ω(√n) = e^Ω(M^{1/3}/log M) switches on G_{n,r,s,t}),
  a 1-player weighted setting; no transfer to parity games is published that L-SI found (B10 column "outside": "ORIGINAL
  Random-Facet: no lower bound on parity games known to L-LIT").
- B11 (symmetric SI), B12 (path prediction), B13 (LCP pivoting), B14 (abstract AUSOs: "We do not expect our methods to yield
  realizable AUSOs"): not this rule or not realizable.
- Upper bound: Zwick 2607.06334 Theorem 8.2, F(n,k) ≤ (n+k) e^{2√(n ln(k/n))+...} switches: subexponential, so M4-R needs the
  parity-game AUSOs to be far easier than the worst abstract ones.

## Unproven assumptions, named
- A1: the expected number of switches is polynomial in n + m on every parity game. The shortest-path lower bound (1410.7530
  Thm 6.3) is the strongest evidence against it: the FHZ randomized counter is built from gadgets that parity sink games can
  usually express (the SODA 2011 construction was a parity game). L-SI expects A1 to be FALSE; the test is whether the M1
  families or small adversarial games already show it.
- A2: expected evaluations polynomial (follows from A1 by the call bound above).
- A3: the rule is insensitive to the start strategy up to polynomial factors (untested; the bench uses the best-reward start).

## Kill criteria (TARGET.md section 5 step 2, Lead brief step 3)
Super-polynomial growth of the mean switch count on any family (switchallexp, switchbestexp, the 11 other M1 families) or
a growth of the adversarial maximum (n ≤ 10, hill-climb over mean of 10 seeds) faster than n^c for a stable c.
