# S5: Zadeh's least-entered rule with the canonical (index) tie-break

Status: UNDER TEST (2026-10-15 12:50Z). Added after the Lead's ruling that new deterministic candidates must be immune to
gate relabelling (L-RED's kill of MSF, docs/si/DEAD.md).

## The rule, exactly
Valuations as in S1. Memory: an occurrence record φ(v, w) = number of times the edge (v, w) has been switched to so far
(all zero at the start). Each iteration switches one improving edge minimising φ; ties: smallest v, then smallest w.
Start: best-reward. Implementation: `Engine.rule_zadeh` (experiments/si/si.py). Memory: m counters of O(log iterations) bits.

## Cost per iteration at bit cost
One valuation (O(n^2 m)) plus O(m) counter comparisons. Polynomial.

## Why it should be outside the barriers, before testing
- Gate relabelling (L-RED's lemma in preparation) re-assigns the LEVEL of a switch; the rule never reads levels or any
  valuation content beyond the improving set, so a construction must control the occurrence record itself.
- B8 (Zadeh): Friedmann IPCO 2011 and Disser-Friedmann-Hopp arXiv 1911.01074 v2 Thm 6.18 use a strategy-dependent
  pre-order ≺σ with an explicit exception as the tie-breaking rule (1911.01074 section 6.2, p.15: "Apply the first
  improving switch contained in I^min_σ with respect to the ordering ≺σ with the following exception ..."), and state
  (p.3) that fixing a tie-breaking rule "cannot be avoided". The index tie-break is a fixed order on edges, not ≺σ;
  whether their construction survives this tie-break is open to L-SI's knowledge. PGSolver's zadehexp family (built for
  PGSolver's Zadeh implementation) gives 19, 71, 155, 271, 419, 599, 811, 1331, 1979 iterations for N = 2..12 under this
  rule: second differences constant 32, i.e. ~16 N^2 (not exponential).
- B9 (DLMM Thm 4.3): index-based rules with o(m/log m) memory states; Zadeh's record has (iterations+1)^m states.
- Not symmetric (B11), not LCP (B13).

## Unproven assumptions, named
- A1: no sink-game construction forces the index tie-break to follow DFH's ≺σ on every visited strategy. (L-SI expects
  this to be FALSE eventually, by relabelling vertices so that the index order realises ≺σ where it matters; the 197-page
  construction was not re-derived.)
- A2: the occurrence record cannot be driven exponentially high by a polynomial-size game (this IS what DFH prove for
  their tie-break).

## Kill criteria
As S2: super-polynomial growth on any family (now including L-RED's gated_bland once available) or in the gadget-chain /
adversarial searches.
