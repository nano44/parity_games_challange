- SCC-RED, step by step:
  - §1 (plays from C reach only D(G)-reachable movers): R104's edges. DATA reach232.py: over ALL Γ3 edges, the movers reachable from x
    are D(G)-reachable from x, for all 4,935 movers of 53 frozen genomes (r229-r231 inst, Ξ-cyclic included): reachfail 0, selfdiff 0.
  - t0 := max f over ALL reachable SCCs. From t0 on, every outside mover reachable from C is final, so C's option values are those of G_C
    (values at a vertex depend only on what is reachable from it; Odd's reply is pointwise optimal, R125's [OPT]). ✓ The remark that
    direct successors do not suffice is supported by a control (§2).
  - The states t0, t0 + 1, … restricted to C form a HOW3 run of G_C. ✓ Its length is ≤ H(C), so f(C) ≤ t0 + H(C); the «+1» is slack. ✓
  - Chain: F non-increasing along reachability, induction from the sinks, T3 = max_C f(C) (every HOW3 step before T3 switches a mover). ✓
  - Corollary T3 ≤ Σ_C (M_C + 1) ≤ M + N. ✓
  - Special cases: no self-loop gives H ≤ 1. A Ξ self-loop gives H ≤ deg − 1 (STRICT on HOW3: each switch strictly raises V(x), so no
    option repeats). ✓
- GAP G1 (wording; affects what SCC-LIN must bound). H(C) is defined with «HOW3's tie rule», but R125's HOW3 is not a single rule: any
  ⊴-best successor may be taken when the current one is not best. N5′-xi's S4a picks one particular choice.
  - DATA (rand232.py; set 400 random genomes, my generator r231/dep231.rgen, seed 2321; unit genome): my engine's T3 differs from n5v's by
    ±1 on 7 of 400. The four inspected (r271, r296, r327, r363) all have tie events (a mover must switch and has ≥ 2 ⊴-best successors:
    6 / 1 / 3 / 3); 7 of 40 agreeing genomes have them too.
  - Fix: define H(C) as the maximum over every HOW3-legal tie resolution (and over starts and final exits). SCC-LIN then has to bound that.
- CAP: Ω_t(g_k) = ext(g_k, min⊴ of the faces) by LOC-GATE3 + NO-TIE3; g_k and m_(x,k) are in no Π (CN2-3), so ext is monotone (F4′):
  ext(m, Ω(g_k)) ⊴ ext(m, Ω(pβ_k)). ✓ (The «⊴» is not strict, which is right: equality when Odd takes β.)

## 2. Counters on my own engine (how3_232.py; out/how3_232_inst26.out, out/rand232_s2321.out)
- locfail (unit SCC: loc(C) > M_C + 1) and chainfail (unit genome: T3 above the chain bound with loc for H): 0 on L-SI's 26 frozen
  instances and 0 on 400 random genomes (seed 2321).
- On the 26, own T3 = n5v T3 on every genome (t3diff 0), and every per-instance number equals L-SI's out/inst99.out: T3, #SCC, giant SCC
  size, its loc, max ratio. Examples: MWR4/8/16_2 T3 30 / 54 / 102 in one SCC of 44 / 80 / 152 movers, ratio 0.33 / 0.316 / 0.308;
  C98_2_2_3 ratio 0.8.
- Control (CTRL=1: e(C) over DIRECT successor SCCs only; 7 instances): locfail 24 (MW8_2 10, FW8_2 14). So the counter detects
  violations. With direct successors, f(C) − max f(direct succ) exceeds M_C + 1 on those SCCs. So a direct-successor version of SCC-RED
  could not be combined with SCC-LIN (H ≤ M_C). This supports L-SI's remark that the proof needs ALL reachable SCCs; it does not by
  itself prove the direct version false, which would also need H(C) itself.
