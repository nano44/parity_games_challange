## 1. Proof read
- ASC-WIT (a):
  - The play is c_i → y (W-target, a mover of level lev(c_i) − 1) → gate g1 = (y, σ_t(y)).
  - If Odd takes the W-face, the next vertex is e(g1). It lies before Λ on v's play (it is more relevant than w by B-ONLY3, so it cannot
    lie on the cycle, whose maximum is w). So e(g1) ∈ Π_t(v) and it is c_(i+1).
  - Its level is lev(c_i) − 1, so under [E-LEV] it is less relevant than c_i. Then there is no ascent. OK.
- ASC-WIT (c):
  - The suffix from pβ(g1) reaches Λ at the same place as v's play, so E(pβ) = {c_(i+1), …, c_p} and Λ(pβ) = w.
  - With equal cycle nodes, the most relevant vertex z of Π(pe) Δ Π(pβ) is an e when the e-parts differ (E-DOM). It is even, so by (b) z ∈ Π(pe).
  - Either c_(i+1) ∈ E(pe), or c_(i+1) lies in the difference and z is more relevant than it. OK.
- ASC-ROOT:
  - The base case is correct. A level-0 gate's W-face runs e → c_W, and c_W ≠ w, so case (d) applies.
  - In the step, seq(pe(g1)) starts with e(g1) at level ℓ − 1 and contains an e ⪰ c_(i+1) ≻ c_i ≻ e(g1). So it has an ascent.
  - Before its first ascent the sequence only descends, which gives lev(c′_j) ≤ ℓ − 1 by [E-LEV]. The induction applies. OK.
- RE-COUNT:
  - E-MON3 makes every change a strict lex increase, so the sets of I are pairwise distinct, D_I = 1 + #changes, and the top is a new element.
  - A top that is not a re-entry was never in any E_s, s < t, so it is a first entry. Each e has at most one first entry. OK.
  - Slightly sharper: the first entries exclude the elements of the interval's first set, so D_I ≤ 1 + (Mact_I − |E_(t0)|) + Rtop_I.

## 2. RE-EQUIV arithmetic
- Λ_t(v) only moves to strictly larger reward (F1, F2), so each Λ value is one interval, and CYC allows ≤ 2M + 3 of them.
- D^tot_E(v) ≤ Σ_I D_I(v) ≤ (2M + 3)(1 + M) + Σ_I Rtop_I(v).
- Σ_v (D^tot_E(v) − 1) ≤ n3((2M + 3)(M + 1) − 1) + Rtop, and T-QUIET3 (P-N5-CHAIN l. 224) gives the stated bound. Rtop ≤ n3·T3, since each
  (v, step) holds at most one change. OK.
