## 2. (b) Where 3M comes from — READING
- A split u is a mover or a gate (Lemma SPLIT (i)). Its new successor b is one of u's edges. Movers have M edges in all (one per option;
  in Γ3, to the pads m_(x,k)). Gates have 2 faces each (2M edges; in Γ3, pe_g and pβ_g). So |SPL_y(v, I)| ≤ #edges out of movers and
  gates = 3M. This is a static count, not a dynamic one.
- Premise: (i) needs every other Even vertex frozen: β_g (two successors in Γ3: xt and pb_g), K0, K1, K3. That holds on standard states,
  i.e. under HOW3 / R118 REACH3-CYC (conditional for Ξ-cyclic genomes; my R228-fw §2 checks it on FW: nonstd 0). Off standard states, a
  split at β_g would add M more edges (4M). The lane states (i) via F6 / [G3], so this is consistent. Note it.
- DATA: nspl (max #split pairs per (v, I, y)) ≤ 5 on all 25 genomes (FW6_4, FW8_4: 5 = k + 1, = C there); spl3m 0.
