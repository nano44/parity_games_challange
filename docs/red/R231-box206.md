- LOUD-SPLIT. (i) loud steps + ≤ Q + 1 maximal quiet windows, each ≤ L (QUIET). ✓ (ii) per vertex ≤ 2M + 2 Λ-changes. ✓ (iii) loud depth
  d ∈ [0, c] means no Λ changes at t and some v whose E changes at depth d with Λ(v) fixed; Λ rises, so each Λ value is one interval:
  ≤ 2M + 3 intervals per vertex, each with ≤ S_c(M) − 1 counted changes; distinct steps are charged to distinct (v, change). ✓
  (iv) the rest is Q_(>c). ✓ Exponent: S_c = O(M^(c+1)), n = O(N + M), L = O((N + M)^3) ⇒ Q = O((N + M)^(c+3)), T = O((N + M)^(c+6)). ✓
