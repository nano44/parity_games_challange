## Definitions
- A W-run F is as in R162 / L-NEW box 111.
- U ⊆ V WITNESSES F if every W-changing transition of F changes W at some u ∈ U.
- DESC*(F) = min over witness sets U of DESC_U(F) = Σ_{u ∈ U} DESC_F(u).
  - Vertex descents do not depend on U, so DESC* is a weighted set cover.
- STAIR-U (R162, lane): |F| ≤ T1_F + |U|(3n + 1) + (3n + 2)·DESC_U(F) for every witness set U.
- CONJECTURE DESC*-LIN (R162): DESC*(F) ≤ c·n.

## 2. PROVED (lane): what fbg says about the counted set
- Lemma (cheap, from STAIR-U): DESC*(F) ≥ (WCT_F − |U*|(3n + 1)) / (3n + 2) for an optimal U*. So any W-run with WCT_F ≫ |U*|·n needs
  DESC* super-linear.
  - fbg is NOT of that kind: WCT ≈ |F| ≈ K·m2 and |U*|·3n ≈ m2·n ≥ K·m2. Its descents are not forced by STAIR-U. They are a
    fact of the dynamics, not of the bound.
- Consequence. No conjecture of the form «DESC* ≤ c·n» can carry G-N5-TIME. On fbg the counted set is as large as the run itself.
  - The potential argument (STAIR / STAIR-U) turns DESC* into |F| at a cost of 3n + 2 per descent, which here is MORE than |F|.
  - So the staircase potential does not separate fbg's quadratic run from a super-quadratic one. A repaired conjecture must allow
    DESC* ≈ |F|, e.g. DESC* ≤ c·n² (DESC*-QUAD), which with STAIR-U gives only |F| = O(n³).
