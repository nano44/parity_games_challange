## 3. Lemma LEVEL
- (L1): pure bookkeeping from (K1). SURVIVES.
- (L2): e-vertices are never in FRONT. With a non-lagging successor they do not lag (K3 (d) at t and at b). With a lagging successor
  their class is strictly above it (K3 (d)). SURVIVES.
- (L3), the case (α) argument:
  - A lagging z with a non-lagging successor y cannot be a gate: (K4) at b, then (K3 (c)) at t, then (K1).
  - It cannot be a β-vertex: its frozen successor is the same at t and at b.
  - So z is a mover, and m_t = class_b(σ_t(z)).
  - Case (β): a cycle wholly in FRONT has the class (c, ∅) of its cycle node c, which is a β-vertex (CN2).
  - SURVIVES.
- (L4), the map s on FRONT at a stall:
  - Mover z ↦ σ_b(z). Its class at t is ≤ class_(t+1)(z) (K5), which equals m_t (stall), and its class at b equals class_b(z) > m_t. So
    it lags, with class m_t.
  - Gate g ↦ σ̄_t(g). A non-lagging face would pin g ((K4) at b). A lagging e-face is not in FRONT (L2). So the image is β_g, and
    σ̄_t(g) = β_g.
  - β ↦ its Ξ-target mover, with the same class at t and at b (K3 (c)).
  - s maps the finite set FRONT into itself, so it has a cycle, which alternates mover → b-gate → β → Ξ-target.
  - Only the mover case uses the stall, as the text says. SURVIVES.
- (L5): |{m}| ≤ 2M (M gate classes at b, M β-cycle classes); |FRONT| ≤ N + 2M (by (L2)). P = 2M(N + 2M). SURVIVES.
