  2-even, which learns nothing. The actual result is -1 with V = {8, 9}; the ideal (C6) is -1 with V = {8}. Ids are
  L-ALG internal: sorted by (priority, id), the same as Oink's reindexed labels. Oink's own trace confirms the actual
  set: "best vertices: 8/7 9/9".
- Pruning rounds (my tracer, exact against Oink; L-ALG ids):
  * actual: {1,2,4,5,8,9,11,14,18,19}, {1,2,8,9,11,14,18,19}, {1,2,8,9,11,18,19}, {1,2,8,9,18,19}, {1,8,9,18}, {8,9}, {}
  * ideal: {1,2,4,5,8,9,11,14,18,19}, {1,2,4,8,9,11,14,18,19}, {1,2,4,8,9,11,18,19}, {1,2,4,8,9,18,19}, {1,4,8,9,18},
    {4,8,9}, {8}, {}
- READING: the PROVED part is per round (Theorem M-cond's induction: V_i ⊆ V̂_i at every round i), and that holds here
  at every round. But a -1 result returns the LAST NONEMPTY round. The actual run empties one round earlier (round 6
  vs round 7), so its return set {8, 9} is a round-5 set and need not be inside the ideal round-6 set {8}. So "V_actual ⊆
  V̂" is proved for stable results and for the per-round sets, NOT for -1 return sets. The data line "13/13 weaker" uses
  the returned V (dtl_deficit.py: weaker = (ra == -1 and rh == 1) or (ra == rh and Va <= Vh)), so it tests the
  unproved form. That is the first counterexample to it.
- Why it matters for (H4): the same call is a DEF change. Search 2 -> 3 in dtl_pyref's numbering, piece 0, equal
  context; the ideal is -1 {8} both times; the actual goes {8} -> {8, 9}. This is a -1 -> -1 re-target whose new target is
  a SUPERSET of the ideal's, so neither "DEF never goes down" nor "the actual target is inside the ideal target" can be
  used to bound re-targets. A bound on DEF per context has to work with return sets that move outside the ideal's.
