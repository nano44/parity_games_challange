## 1. Why the observer descends, and the windowed attempt (DATA, qtrace.py on win_K4 / obs_K4)
- obs (all of y_1..y_m) in one round:
  - a ladder change at hp's rise (MWTp_i);
  - then at h's rise (MWT_i) a switch y_m → y_1, whose first difference is at the ladder bit;
  - then y_1 → y_2 → … → y_m, each a switch whose change position is the new target's own q-bit, more significant each time;
  - the step y_1 → y_2 is the round's single DESCENT (q-bit after ladder bit).
  - This is L-NEW's §2 picture. It needs y_1 to beat y_m at the round start: after hp's rise only r_1 carries h's new level.
- Window observers {y_s, y_(s+1)} (mkwin.py W = 2): NO descents.
  - A window stays on y_(s+1): it never falls back, because y_(s+1) is never worse than y_s once both are on the same side.
  - Each window has 2K + 1 changes, all at ladder bits, all ascending. win_K4: DESC = 4, which is obs's own.
- Suffix observers {y_s, …, y_m} (W = 0): each jumps back to y_s at its round's ladder change and descends at the next flip. So observer
  s descends at its own transition, s = 1 … m − 1, every round. DT = K(m − 2), DESC = K(m − 1) (obs's own included).

## 3. PROVED (lane): Theorem STAIR-U (restates L-NEW's STAIR over a witness set)
- Statement. Let F be a W-run and U ⊆ V with: every W-changing transition of F changes W at some u ∈ U. Then
  WCT_F ≤ |U|(3n + 1) + (3n + 2)·DESC_U(F), and |F| ≤ T1_F + |U|(3n + 1) + (3n + 2)·DESC_U(F).
- Proof. It is L-NEW's proof with Ψ_U := Σ_{u ∈ U} ψ(u), where ψ(u) = the position of u's last change (3n + 1 before the first),
  so Ψ_U ∈ [0, |U|(3n + 1)].
  - At a W-changing transition with no descent in U, every changed u ∈ U ascends (ψ falls by ≥ 1), and at least one u ∈ U changes
    (witness), so Ψ_U falls by ≥ 1.
  - A descent raises ψ(u) by ≤ 3n + 1.
  - So the descent-free W-changing transitions number ≤ |U|(3n + 1) + (3n + 1)·DESC_U, and the others ≤ DESC_U. Add T1 as in
    STAIR. □
- U = V is L-NEW's STAIR. U = the core gives, on cp / suf, DESC_U = 0 and so WCT ≤ |U|(3n + 1), whatever the observers do.
- CONJECTURE DESC*-LIN, the repaired DESC-LIN: min over witness sets U of DESC_U(F) ≤ c·n. It implies |F| = T1 + O(n²). It is not
  computed exactly here (a set-cover-like minimum). desc2 bounds it from above with a chosen U plus a WITVIOL check.
- A structural repair does NOT work: «count descents only at vertices with in-edges» (UIN) dies the same way. Give each copy an Odd
  predecessor p_c → obs_c, so that obs_c has an in-edge and p_c copies it (DESC-COPY). Then DESC_U = K·n_base again. (READING; the
  instance is immediate from cp_K plus one Odd single-successor vertex per copy. Not run.)

## 4. Nested carries: why they are not built here (READING), and what is open
- The box asked for two carry levels: an outer selector whose carry restarts obs's 12-round staircase several times inside one
  W-run.
- (i) A passive observer cannot help. A vertex with no in-edges is read by no other vertex.
  - When the rest of the game still witnesses F (WITVIOL = 0, measured on every family here), STAIR-U with U = the rest charges
    nothing to the observer's descents.
  - So nesting at a passive vertex inflates DESC but never |F|. That is §2 in a sentence.
  - The general claim (a passive vertex never makes WITVIOL > 0 for U = the rest) is a READING, not proved. It would need: a
    transition that changes W only at in-degree-0 vertices is impossible, or rare.
- (ii) In the core, obs's run has NO carries at all (DESC = 0 on mkrw_K12_m24).
  - Its K rounds are not carries in the bit sense. The pivot h climbs a ladder whose bits (MWT_1, MWTp_1, MWT_2, …) get MORE
    significant each round (qtrace: positions 7, 6, 5, 4, …).
  - The reactors' wave changes sit at those same ladder bits. The «restart» is an ascent at the ladder, not a re-fix of a lower bit.
  - So the core run is a family of n ascending staircases of length ≤ 3n + 1, which is exactly what STAIR-U pays with |U|(3n + 1).
- (iii) A genuine nested carry needs a CORE vertex whose high digit changes and whose lower digit then re-climbs. This means re-arming
  a lower selector after a higher change, inside one W-run, at a vertex that witnesses F.
  - That is the depth-2/3 re-arm question of R158 (FEEDBACK) and R160 (WIDTH): depth-2 re-arming exists (fbg, |F| = K(m2 + c),
    additive), and depth 3 was not built.
  - The obstruction on record is R158's lane READING (A)/(B), with instances fbA_K4_m8_m8 (|F| 44 = ungated) and fbB_K2_m6_m6 (|F| 6).
    - (A): a later gate opens early, because the shared line carries the NEW root while b_j carries hp's old level.
    - (B): clamping is τ-improvable for Odd, or loops back.
  - R161's READING (a pair cannot feed itself; l-red 871610eb) says the fuel for a re-arm must come from outside XICH.
  - Nothing landed blocks nested carries. G-N5-TIME stays OPEN.
