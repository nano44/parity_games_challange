## 1. Proofs checked
- (PROJ). If e_S ∈ X \ Y, the most relevant element z of X Δ Y is at least as relevant as e_S, because e_S itself is in X Δ Y. So
  z ∈ π(X) Δ π(Y) = π(X Δ Y), and it is the maximum there, on the same side. Correct.
- (PROJ-MON). If max(X Δ Y) is at least as relevant as e_S, it is also max(π(X) Δ π(Y)). Otherwise π(X) = π(Y). Correct, including the
  boundary case z = e_S.
- (4′), case «g_o's play passes B». With σ_t(B) = S, FLIP (1) says Odd takes e at g_S. So g_o's play continues B g_S e_S w … to the
  cycle node λ. λ lies below every e, so every e-vertex on that play is in Π_t(g_o), and E_t(g_o) ⊇ {e_S} ∪ E_t(w). For a superset, π(A)
  >lex π(B) is impossible, since the symmetric difference lies in B. So the clause fails and P^U_t ⇒ P_t. In the other case, e_S ∉
  E_t(g_o) and (PROJ) makes the clauses equal. Correct.
- (5′). Off S, FLIP (2) gives e_S ∉ E_t(g_o) for every o, so P^U_t ⟺ P_t by (PROJ). Correct.
- (6′). P^U_t is a function of the π-sets, which are monotone by E-MON and (PROJ-MON). Correct.
- Extension (lane): FLIP-U holds for every Λ(B) that B-ONLY allows, not only K1 / K2. FLIP-A's three facts (α)-(γ) (R223-flip.md §1)
  are all that (4′) uses as well, in particular «λ is below every e» for the superset step. With λ = b_S there are 0 flips (FLIP-A (i)).
- LOW-NULL: an e less relevant than e_S is cut by π, so it never enters FLIP-U's bound. Under [E-LEV], e-priorities are ordered by
  (level, gate index), so every e of a lower level is cut. Correct as a statement about the BOUND. Read causally («cannot add a flip»),
  it is right only in the sense that the bound for B_l does not depend on them.
- POOL-ALT. Consecutive sets come from disjoint pools, so the symmetric difference is the union and its maximum lies in the larger set.
  The maxima therefore strictly increase inside P_A ∪ P_B ∪ {−∞}. Correct.
- POOL-ALT's use (§3 there) is labelled READING. It needs disjoint pools, and also needs e_S ∈ a_t \ b_t under PRIV. That second point
  holds without PRIV too, by FLIP (2) off S and by the superset case on S. As a reading it is fine. It is not a lemma about counters.

## 3. The reading «Q2 is closed by P-QUIET; only the Q1 lag tower remains»
- At db6e9b50 the note itself (§0, §6) still lists Q2 as «not excluded». It was written before R223 item 4. The reading comes through the
  Lead.
- Q2: AGREE, conditionally. P-QUIET (R223-q2.md) is PROVED-CONDITIONAL on P-N5-QUIET's Theorem QUIET, which is in referee review and not
  landed. Given QUIET, every E-decided switch is at a loud step, and the P-decided switches number at most N·T ≤ N(1 + Σ_v (D^tot_E(v) −
  1))(L + 1). So Q2 adds nothing beyond Q1 on IDEAL-CYC. For N5′-xi on Γ3 it also needs links 1-2 of R223-q2.md §4: REACH3-CYC, now
  SURVIVES as DATA (R223-reach.md), and QUIET re-proved on Γ3.
- Q1: PARTLY.
  - What is proved to remain (T-QUIET): T is polynomial unless Σ_v D^tot_E(v), the number of class changes over all vertices, is
    super-polynomial.
  - For SET bits, FLIP-U / FLIP-ALL charge their flips to U-projection changes.
  - The «lag tower» (w_l reaching the same upper e's one count behind, by a different route) is L-SI's READING of what a doubling SET bit
    needs. It is not a lemma. POOL-ALT excludes only disjoint pools, and «shared pool ⇒ lagging merged copy» is argued informally (box 85
    §5: «Plays that pass a common e-vertex coincide from there on»).
  - So «only the lag tower remains» is a CONJECTURE (TWO-COPY-RED, labelled so by L-SI). The proved residue is «Σ_v D^tot_E(v)
    super-polynomial», with SET-bit flips charged to U-projections.
  - Two routes stay open, besides the lag tower: an exponential counter could also raise Σ D^tot_E through cycle-node changes (D^tot_E
    counts (Λ, E) classes), or through e-set changes at vertices that are not hubs.
- Suggested wording for L-SI's next note: «Q1 (proved residue): Σ_v D^tot_E(v) super-polynomial; the lag tower is our candidate
  mechanism (READING), not a necessity.»
