## Summary
- Every PERMANENT elimination lemma opened (Ye Thm 4.1; HMZ Lemma 6.4; Scherrer §7-§8; Post-Ye Lemma 3.6) has three ingredients:
  - (R) a fixed a-posteriori REFERENCE: the optimal solution's reduced costs / advantages. Phase-local eliminations (Post-Ye Lemma 3.3,
    Scherrer Lemmas 12-13) use the last policy of the phase instead and last only until the next cycle or recurrent class.
  - (P) a PIGEONHOLE on gap = Σ_actions (reduced cost × flux), with every flux in a polynomial window ([1, m/(1−γ)]; path layer [1, n]).
    One current action carries ≥ gap/poly of the reduced cost.
  - (C) a GEOMETRIC CONTRACTION of the gap per step, from the RULE: Dantzig (1 − (1−γ)/m, or 1 − 1/n² per cycle-free pivot) or Howard
    (factor γ, via value iteration, HMZ Lemma 5.5).
  - So after O(poly · log poly) steps the gap is below that action's reduced cost / poly, and it never returns.
- Ordinal analogue for Ξ inside one W-run (§3).
  - (R) is available: Ξ_end, the Ξ at the end of the W-run (Ξ is non-decreasing on F).
  - Lemma ELIM-ORD-β (PROVED, L-LIT, elementary). Let β_t(v) := Ξ_t(σ_t(v)). β never falls along F. Once β_t(v) ⊵ Ξ_end(w), the edge
    (v, w) is never adopted again in F. DATA: 0 violations, β never falls, over 1,132 corpus runs and the fx / latew families.
  - The stronger "Ξ_t(v) ▷ v ⊕ Ξ_end(w)" form is DEAD unconditionally: 13 violations (tog6a_n32, tog6b_n32, kt6_n58, x31_lem_t32,
    gci3_n24). Its proof needs two side conditions (§3).
  - (P) and (C) have no Ξ analogue. Ξ is a two-player value, not additive. On frozen-σ̄ stretches (BIP) T56's ISO makes it additive with
    path fluxes in [1, n], so (P) is available there. (C) needs a rule property that S4a's τ-optimum does not have (it is neither Dantzig
    nor Howard in G_ρ). That contraction is the missing lemma.
- The fx_K_m test (L-RED R137).
  - One edge is adopted K·m/4 + 1 times in one W-run (RETMAX 17, 33, 65, 33, 65, 129), and ELIM-ORD-β never fires early for it.
  - But the HMZ-shaped TRUE elimination window is HW = m + 1, independent of K (17 at m = 16, 33 at m = 32). Some non-final edge in use at
    any state is left for good within m + 1 transitions.
  - So fx does not break an HMZ-type statement. CONJECTURE ELIM-WIN: HW_F ≤ p(n) on every W-run. With HMZ's counting it would give
    |F| ≤ (m_E + 1)·p(n) (§4).

## 1. Sources (opened; quotes re-checked by grep: Ye p. 9 Thm 4.1, HMZ p. 10 Lemma 6.4)
### 1.1 Ye, "The simplex and policy-iteration methods are strongly polynomial for the Markov decision problem with a fixed discount rate", Math. Oper. Res. 36(4) (2011) 593-603: OPENED (author final, web.stanford.edu/~yyye/SimplexMDP4.pdf, sha256 5825bfe4…; printed pp. 5-9). Ye's m = states, n = actions.
- Lemma 3.1 (ii)-(iii), p. 5: «any basic variable … has its value 1 ≤ x^π_i ≤ m/(1−γ)»; e^T x = m/(1−γ).
- Lemma 3.2, p. 5: unique optimal dual (y*, s*); non-optimal action j has s*_j > 0.
- Lemma 4.1, pp. 7-8: c^T x^{π^t} − z* ≤ (1 − (1−γ)/m)^t (c^T x^{π^0} − z*) (Dantzig).
- Lemma 4.2, p. 8: «(i) If a policy π is not optimal, then there is an action j ∈ π ∩ N … such that s*_j ≥ (1−γ)/m² (c^T x^π − z*)»;
  (ii) x^{π^t}_{j⁰} ≤ m²/(1−γ)·(c^T x^{π^t} − z*)/(c^T x^{π^0} − z*). Mechanism: gap = Σ_{j∈π} s*_j x^π_j and pigeonhole.
- Theorem 4.1, p. 9: «there is an action j⁰ ∈ π⁰ ∩ N … that would never appear in any of the policies generated by the simplex method
  after T := ⌈m/(1−γ) · log(m²/(1−γ))⌉ iterations» (flux < 1 contradicts Lemma 3.1). Theorem 4.2 / Cor. 4.1: the same for Howard PI, the
  facts being «independent of how the policy sequence is generated as long as the action with the most-negative-reduced-cost is included».
### 1.2 Hansen-Miltersen-Zwick, "Strategy iteration is strongly polynomial for 2-player turn-based stochastic games with a constant discount factor", J. ACM 60(1) 2013; OPENED as arXiv 1008.0530v1 (sha256 f53a6b51…; printed pp. 6-10; J. ACM numbering not checked)
- Lemma 5.5, p. 9: «‖v^k − v*‖∞ ≤ γ^k ‖v⁰ − v*‖∞» (strategy iteration dominated by value iteration; Lemmas 5.3, 5.4).
- Lemmas 6.1-6.3, p. 9 (flux and reduced cost: ‖v^{π''} − v^π‖₁ ≤ n/(1−γ)·(c^π)_a, etc.).
- Lemma 6.4, p. 10: «Let L = log_{1/γ} n²/(1−γ). Then, every strategy σ^k contains an action that does not appear in any strategy σ^ℓ,
  where k + L < ℓ ≤ N.» Reference π* = π^N, the optimal profile. Theorem 6.5: (m+1)(1 + log_{1/γ} n²/(1−γ)) iterations.
- Two players: Min plays a best response each iteration, and only player-1 actions are eliminated («We may assume, therefore, that a ∈ A₁»,
  using (c^{π*})_{A₂} ≤ 0).
### 1.3 Scherrer, "Improved and generalized upper bounds on the complexity of policy iteration", Math. Oper. Res. 41(3) 2016; OPENED as arXiv 1306.0386v4 (sha256 391b6481…; pp. 3-6, 8-10, 13, 15)
- Theorem 3 (Howard): (m−n)/(1−γ)·log(1/(1−γ)). The proof (§7) uses the advantage w.r.t. v* and the γ-contraction (Lemma 2): «if some
  policy π is not optimal, then one of its non-optimal actions will be eliminated for good after at most k* iterations».
- Theorem 4 (Simplex-PI): n(m−n)(1 + 2/(1−γ) log(1/(1−γ))) («every k* iterations, a non-optimal action is eliminated for good»).
- Lemma 13, p. 13: «either an action is eliminated from policies after at most ⌈n²τ_t log(n²τ_t)⌉ iterations, or a recurrent class is
  broken …». The reference is π†, the last policy before a new recurrent class, so the elimination is phase-local.
- Lemma 8 (deterministic Howard: a new cycle within n iterations): combinatorial, no threshold.
### 1.4 Post-Ye, arXiv 1208.5083v2 (Math. Oper. Res. 2015): OPENED (sha256 c51876eb…; pp. 6-9)
- Lemma 3.1, p. 6: «If a is on a path in π then 1 ≤ x^π_a ≤ n, and if a is on a cycle then 1/(1−γ) ≤ x^π_a ≤ n/(1−γ)».
- Lemma 3.3, p. 7: within O(n² log n) iterations, a new cycle, a broken cycle, the end, or «some action in π never appears in a policy again
  until a new cycle is created». The reference is the last pre-cycle policy.
- Lemma 3.6, pp. 8-9: «after O(n log n) iterations in which a new cycle is created, some action in π is either eliminated from cycles for the
  remainder of the algorithm or entirely eliminated from policies». The reference is the optimal gains r*. The contractions are
  combinatorial: 1 − 1/n per new cycle (Lemma 3.5), 1 − 1/n² per cycle-free pivot (Lemma 3.2).

## 3. Ordinal elimination (PROVED, L-LIT, elementary) and its tests
Setting: a W-run F (τ fixed, no fallback, λ_W fixed), states p..q. Ξ_t := Ξ of σ_t. Every transition applies a non-empty set of switches
from Iσ_t (INTERVAL-SI (iii) / R91's premise), so Ξ_{t+1} ⊵ Ξ_t (R15).
- Lemma BETA-MON. β_t(v) := Ξ_t(σ_t(v)) is non-decreasing in t, for every Even v.
  - Proof. If v does not switch at t: β_{t+1}(v) = Ξ_{t+1}(σ_t(v)) ⊵ Ξ_t(σ_t(v)). If v switches to w, then (v, w) ∈ Iσ_t, i.e.
    Ξ_t(w) ▷ Ξ_t(σ_t(v)), and β_{t+1}(v) = Ξ_{t+1}(w) ⊵ Ξ_t(w). □
- Lemma ELIM-ORD-β. If β_t(v) ⊵ Ξ_end(w) for some t in F, then (v, w) is not adopted at any s ≥ t in F.
  - Proof. An adoption at s needs Ξ_s(w) ▷ Ξ_s(σ_s(v)) = β_s(v) ⊵ β_t(v) ⊵ Ξ_end(w) ⊵ Ξ_s(w). □
- The ⊕ form "Ξ_t(v) ▷ v ⊕ Ξ_end(w) ⇒ never again" would follow if Ξ_{s+1}(v) = v ⊕ Ξ_{s+1}(w) and v ⊕ · were monotone. Both fail in
  edge cases: si.Engine.extend keeps the cycle node, so at an even Ξ-cycle node v the true value (v, ∅, 0) beats the extension; and
  OR-ing v's bit into a path set that already contains it is not order-preserving. DATA: 13 violations (VIOLX) over the corpus,
  e.g. experiments/red/so/instances/tog6a_n32.pg, red/fbx/instances/kt6_n58.pg. So the ⊕ form is DEAD as an unconditional statement.
- DATA (T58-elim-check.py; corpus sbcg 719 + alt 413 runs, 300 s each, all finished):
  - VIOL (β) 0; BMON 0; VIOLX 6 + 7.
  - Largest W-run 159 transitions (runfam_K40, n 79). RETMAX per edge per W-run: 18 (topfix_n10, n 210).

## 4. The HMZ shape, tested on fx_K_m (L-RED R137) and latew
- Definition. For a W-run F and state t: HW_F(t) := min over the edges e ∈ σ_t with e ∉ σ_q of (the last state at which e ∈ σ) + 1 − t.
  HW_F := max_t HW_F(t). This is the quantity of HMZ Lemma 6.4 («every strategy σ^k contains an action that does not appear in any σ^ℓ,
  k + L < ℓ»), measured directly (no threshold).
- Counting (PROVED, as HMZ Thm 6.5). |F| ≤ (m_E + 1)·HW_F, where m_E is the number of Even edges.
  - Proof: from any state t, within HW_F transitions some edge of σ_t is left for good. Each such edge is distinct, since a retired edge
    is never in σ again. □
- CONJECTURE ELIM-WIN: HW_F ≤ p(n) for every W-run F of N5. (Then |F| ≤ (m_E + 1)·p(n), i.e. the within-W-run part of G-N5-TIME.)

- Reading of the fx test.
  - The returns at X are real: K·m/4 + 1 adoptions of one edge. An edge-wise threshold cannot bound them, because ELIM-ORD-β fires
    only at the end for X's two edges. So a per-edge "eliminated after p(n) returns" statement is false on fx.
  - The HMZ statement is about SOME edge of the current strategy, and that survives: HW = m + 1 regardless of K. The reactor edges retire
    one per wave step, while X keeps toggling.
  - This is exactly the shape of HMZ Lemma 6.4. It counts retirements of distinct edges, not returns of one edge.
- What would refute ELIM-WIN: a W-run in which, for super-polynomially many transitions, every non-final edge in use keeps coming back,
  i.e. a counter in which every digit returns. That is L-SI's / L-RED's mixed-radix counter target (T55 COUNTER) seen from the edge side.
