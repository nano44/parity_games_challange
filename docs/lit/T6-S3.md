## Question (2), L4: vertex-priority lower bounds
**Literature verdict: none found.** No opened source states a lower bound on separators or universal trees for
vertex-priority games.
- Czerwiński et al. 1807.10546 v2 work with "edge priorities" throughout (§2.1, p.3: "we refer to as edge priorities, or simply
  priorities"); Thm 5.1 is for that setting.
- Arnold-Niwiński-Parys CSL 2021: fixed-point expressions; the game reading is edge-labelled (Parys-Wiącek cite it with
  CDFJLP as the edge-priority necessity proofs, below).
- Colcombet-Fijalkow-Gawrychowski-Ohlmann LMCS 2022 and the Games on Graphs book: edge-coloured graphs throughout; no
  vertex-labelled lower bound found (grep of both texts for vertex-labelled/vertex priorities).
- Parys-Wiącek arXiv 2305.00308 v1, p.8 (Sec. 4): "for games with priorities on edges it can be shown that n-universality is
  indeed required [8,1]. However most papers (including ours) define parity games with priorities on vertices, in which case
  the necessity proof does not apply." They then use ⌊n/2⌋-universal trees (Jurdziński-Lazić's η <= ⌊n/2⌋): an UPPER bound
  only. They give no vertex-priority lower bound.
- The same paper, p.2, gives the conversion the Lead asked about, verbatim: "(A general method for switching from priorities on
  edges to priorities in vertices is to replace each vertex by d vertices, one for each priority, and to redirect every edge
  to a copy of the target vertex having the appropriate priority; then the number of vertices changes from n to nd.)"
  (It is stated as a remark, without proof or theorem number.)

**A reduction that transfers the edge lower bound (L-LIT derivation, UNREFEREED; REFEREE to check before use).**
Notation as S1/S2: s^E(k,d), s^V(n,d) minimal deterministic strong separators; w^E, w^V weak; Σ_d = {1..d}.
- Claim R. For all k >= 1 and even d: s^E(k,d) <= s^V(k·d, d) and w^E(k,d) <= w^V(k·d, d).
- Proof sketch. Let H be an edge-labelled graph with k vertices (the E convention, one edge per (source, target, priority)).
  Let H' be the Parys-Wiącek conversion: vertices (v,p) for v ∈ V(H), p ∈ Σ_d, priority of (v,p) is p, and an edge (u,p) -> (v,q)
  for each edge u -q-> v of H. H' has k·d vertices; every vertex has a successor iff it does in H. A path
  v0 -p1-> v1 -p2-> v2 ... of H gives the path (v0,1) (v1,p1) (v2,p2) ... of H', whose vertex-priority word is 1·p1 p2 ...
  Conversely every path of H' projects to a path of H with the same word after the first letter. Cycles of H' project to
  cycles of H with the same set of priorities, so H' is even (odd) iff H is even (odd). Hence, for every word w:
  w ∈ EvenCycles^E_{k,d} ⇒ 1·w ∈ EvenCycles^V_{kd,d}, and w ∈ OddCycles^E_{k,d} ⇒ 1·w ∈ OddCycles^V_{kd,d}; and
  w ∈ LimsupOdd ⇔ 1·w ∈ LimsupOdd. So if A is a deterministic strong (weak) vertex separator for (kd, d), the automaton
  A' = A with initial state δ(q0, 1) is a deterministic strong (weak) edge separator for (k, d), with no more states. QED (sketch)
  Points to check: (i) S1's exact definition of the V convention (does it allow the start letter to be the priority of the
  start vertex, as used here?); (ii) S1's E convention (multi-edges) vs the "one label per pair" S convention; the
  construction is the same for both; (iii) the ⊥ state, if A uses one: δ(q0,1) is defined because 1·w is accepted for even w.
- Consequence for the diagonal. For d' <= n, restricting a strong (n, n)-separator to the letters Σ_{d'} gives a strong
  (n, d')-separator (EvenCycles^V_{n,d'} ⊆ EvenCycles^V_{n,n}, LimsupOdd_{d'} ⊆ LimsupOdd_n), so s^V(n,n) >= s^V(n,d').
  With Claim R and CDFJLP Thm 5.1 (which bounds non-deterministic strong separators, hence s^E):
      s^V(n, n) >= s^V(n, d') >= s^E(⌊n/d'⌋, d') >= C(⌊lg⌊n/d'⌋⌋ + d'/2 − 1, ⌊lg⌊n/d'⌋⌋).
  Taking d' ≈ sqrt(n) (even) gives about C(½ lg n + ½ sqrt(n) − 1, ½ lg n) >= (sqrt(n)/lg n)^(½ lg n − 1) = n^Ω(log n):
  a SUPER-POLYNOMIAL lower bound on deterministic strong separators for vertex-priority games on the diagonal. For
  d = n^(1−ε) the same line gives n^Ω(ε log n). The constant in front of log n is worse than the edge bound (the n/d
  loss); a sharper transfer (n/2, as Parys-Wiącek's upper bound suggests) would need an argument that is not in the sources.
- Novelty of Claim R and the diagonal bound: not found stated in any opened source (CDFJLP, CFGO, ANP, PW, book, CF19).
  It is a short reduction from a published remark plus a published theorem; if it survives the referee, L-LIT would
  classify it as a lemma that closes the "necessity proof does not apply" caveat up to the n/d loss, which is worth stating
  in BARRIERS.md B1 (L-LIT will update B1 after the referee signs).
