## 1. Lemma B: SIGN (the point the Lead asked me to scrutinise)
- Real order. SPEC S1 compares P by the signed weight Σ ±2^rank. SPEC Q1 proves that this equals "the top-ranked h of P Δ P′ decides:
  even h on the better side, or odd h on the worse side". The packet's clause (ii) is exactly Q1's rule. Clauses (i) (reward of the cycle
  node, with rew = ±pp) and (iii) (longer is better at odd c, shorter at even c) are SPEC S1's.
- So §1's "real order" is the SPEC / engine order, lengths at cycle nodes included. It is not CAV's coarser order. ✓
- (a). For fixed c, (c, μ, ℓ) maps to the integer vector (ε_1 μ(h_1), ε_2 μ(h_2), …, ε_c ℓ) with h_i by decreasing rank.
  - ε = +1 at even h (more copies is better for Even) and −1 at odd h.
  - The last coordinate is −ℓ at even c and +ℓ at odd c.
  - (ii′) then (iii) is the lexicographic order of these vectors, and the map is injective. Blocks of different c are ordered by the
    injective rew. So ⊴ₓ is total and antisymmetric. ✓
- (b). For sets, the vertices with differing multiplicity are exactly P Δ P′. At the top one the multiplicities are 1 and 0, so (ii′) reads
  as (ii). ✓
- (c). Real values have set path parts: the play before its first visit to c is simple. A repeat there would close a cycle that never
  reaches c, which is impossible in a lasso. So real comparisons are unchanged. ✓
- Where multisets enter: only inside the chains of Steps 4-6. Each chain starts and ends at a real value, so Lemma B (a) carries
  transitivity and (c) carries the endpoints back to ⊴. The packet's remark that the SET prefix is not monotone is right: if x is the top of
  P Δ P′, adding x to both sets erases the difference. Lemma M needs the multiplicities.
- DATA:
  - The extended order (coded from the packet's text) and SPEC's signed-weight key agreed on all 46,356,800 ordered pairs of real values
    (40 sampled values per game, every pair).
  - Antisymmetry, "equal iff identical" and transitivity held on 869,190 random extended triples (multiplicities 0-3).
- Sensitivity (mutation.py): flipping the odd-h rule of the extended order gives 20 Lemma B mismatches in 300 games, so the comparison
  check is live.

## 2. Lemma M: SIGN
- Adding the same x (when rank x > rank c) to both multisets leaves every multiplicity difference unchanged. Adding 1 to both lengths leaves
  (iii) unchanged. With the same c, (i) does not arise. So strict and non-strict order are both preserved. ✓
- Real prefix: if x ≠ c and x does not occur on y's play before c, the play x, (play of y) has the same cycle and first visit to c, and P
  gains x iff rank x > rank c. ✓
- DATA: 405,014 strict random pairs; the prefix kept the strict order every time.

## 3. Lemma P1: SIGN (Step 5 scrutinised)
- Step 1: totality of ⊴ and "no improving edge" give V(y) ⊴ V(s(x)) on every Even edge; on Odd edges y = s(x). ✓
- Step 2 (prefix equation).
  - x ≠ c(x): x does not recur before c(x). If x is on the cycle, s(x)'s play reaches c(x) before returning to x. So V(x) = x ⊕ V(s x). ✓
  - x = c(x): V(s x) = (x, ∅, L − 1), since x tops its cycle. ✓
- Step 3: c(s x) = c(x) in both cases, and clause (i). ✓
- Step 4: each link V(x_i) = x_i ⊕ V(s x_i) ⊵ₓ x_i ⊕ V(x_{i+1}) uses Step 1, Lemma B (c) and Lemma M. All values involved have cycle node c0.
  Downward induction applies Lemma M to an already-extended tail, which is exactly why multiplicities are needed. ✓
- Step 5.
  - Case c0 ∈ C, p > 1. (c0, μ, p − 1) ⊴ₓ V(y_1) ⊴ (c0, ∅, L − 1). If the top t ≠ c0, then t is the top of μ with μ(t) = 1 > 0, so (ii′)
    forces t odd, and rew(t) = −pp(t) < −pp(c0) ≤ rew(c0). ✓
  - Case c0 ∉ C, μ_C ≠ ∅. Once around C gives V(y_0) ⊵ₓ (c0, μ_0 + μ_C, ℓ_0 + p). This is the one place a multiplicity 2 can arise
    (y_i ∈ μ_0 ∩ μ_C). The top of the difference is C's top t, with multiplicities μ_0(t) against μ_0(t) + 1, so t is odd. ✓
  - Case c0 ∉ C, μ_C = ∅. Only the length differs (ℓ_0 against ℓ_0 + p). ⊵ₓ excludes odd c0, and rew(t) ≤ pp(t) < pp(c0) = rew(c0). ✓
  - So equality rew(t) = rew(c0) holds only in the case c0 ∈ C, t = c0. ✓
- Step 6.
  - Along the σ′-play, rew(c(·)) is non-increasing (Step 3) and constant on the periodic cycle C′, with value c0 by injectivity.
  - Step 5 gives rew(c′) ≤ rew(c0) ≤ rew(c(v_0)). A strict inequality gives V_{σ′}(v_0) ◁ V(v_0) by (i).
  - With equalities, c′ = c0 = c(v_0) is C′'s top, and c(v_i) = c0 throughout. Step 4 on the simple prefix v_0 … v_b (b = the first visit
    of c0) gives V(v_0) ⊵ₓ (c0, set, b) = V_{σ′}(v_0), a real value. Lemma B (c) finishes. ✓
  - N-P1-1: b = 0 is v_0 = c0, where both values are (c0, ∅, 0).
- Corollary P1′ follows by antisymmetry and R17 F1. ✓
