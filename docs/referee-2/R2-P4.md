## 0. G-STR: the FDL needs equal str, not just equal sets (OPEN; DATA 0)
FDL (ii) (GAP-A-M 1620-1626) defines e as the first tattr whose OUTPUT differs. "Strictly larger" means the output is a set.
It then asserts that "every computation before e is identical" and that "before e, s+1 extracts exactly the SCCs that s
extracted there".
- Extraction (211-305) reads str[n] for p-vertices (268).
- A tattr whose output SET is the same in s and s+1 can still write different str. Suppose a tangle t ∈ T_{s+1} \ T_s^e
  (one that s learned later) fires in s+1 at the pop of one of its escapes. Its vertices join with the stored strategy
  (171), while in s the same vertices joined later by vertex rules with their DFS parents (89). The region set is equal,
  the strategies are not.
- Then the SCC of a closed region (SCC1: the set reachable from the top in the str-restricted graph) can differ. s+1 can
  learn a new tangle before the first set difference.
- Consequences if this happens:
  - s+1 runs an extra sptl pass, so the reduced-log alignment breaks.
  - In the worst case a transition has NO set-level first difference at all.
  - FDL (ii) and (iii) and §22e's sum do not count such transitions.
- This is the (a4)/Lemma S question of DTL-proof §3 (str changes at a fixed region set), which is open there.
- My R2-PROVED2 §13.1 (G-h1 closure) has the same hole: "s+1 learns nothing in its one pass: its SCCs are those of s's
  pass 1" assumes equal str. REFEREE's G-h1 discussion also argued only on sets. I withdraw "closed" for G-h1 to this
  extent: G-h1 is closed GIVEN (STR-DET) below.
- Needed hypothesis, or lemma (STR-DET): if every tattr before a point has equal set output in s and s+1, then every SCC
  extracted before that point is equal.
  - A weaker form suffices for the counting: s+1 creates no new tangle before its first set-level difference, and every
    transition has one.
  - With (STR-DET), FDL (ii)/(iii), G-h1 and everything below hold as written.
- DATA (mine; logs of every best_vertices region and rescue level, every −1 attractor, every Dom, every tangle creation;
  corpus + random, both in-orders): 4,290 consecutive same-phase pairs. In 0 of them s+1 creates a tangle before the first
  set difference, and in 0 of them there is no set difference at all. So (STR-DET) holds on all data.

## 2. (b) PREFIX-MONO and corollaries — SIGN WITH GAPS
- (S1), checked: every rule of the implemented Cl_q is positive in the set and in T. The "new vertices ≤ q" condition
  weakens as the set grows. A set closed at q′ is closed at q ≤ q′, since the q-rules are a subset of the q′-rules.
- Use of O1: tops are processed in decreasing index (691), and O1 (index non-decreasing in priority) gives pr(τ′) ≥ pr(τ)
  for the last processed top τ′ > τ. This is the only use, in the "not processed in run 2" case. Correct.
- Proof checked case by case:

  - Processed in both runs: S0 for run 1, step-ideal for run 2, then S1 with B ⊆ B′ and T ⊆ T′.
  - Processed in run 1 only: τ ∈ V ⊆ V′, so run 2 skips it only because τ ∈ P′(τ⁺) (692). P′(τ⁺) = P′(τ′) = Cl′_{q′}(…)
    by step-ideality, which is q-closed and ⊇ P(τ⁺) ∪ {τ}, so it contains Cl′_q ⊇ Cl_q ⊇ P(τ).
  - Base: ∅. Correct.
- C1: U = P(lowest index). Correct.
- C2: the threshold loop at level t pushes all of Z (724), with R fixed (no R[·] = false in 722-731) and Gx = R. By Lemma
  1.2 it computes the code closure, which is the implemented Cl_t of the level-(t−1) set. That closure is monotone in its
  input and in T, so W_t ⊆ W′_t by induction over t. Correct.
- C3: survival is "attracts(p, v, U, R) or attracts(p, v, W_{pr v − 1}, R)" (714, 734-740 with the 737 break; W

## 4. (d) Theorem ROOT-BOUND — SIGN WITH GAPS (G-Ψ)

  rescue level), or Ψ is equal and Φ_top falls (POS-FALL).

  RV, occupies a contiguous block, because each component only moves up inside the run.

## 5. (e) the §22e reduction — SIGN WITH GAPS (G-DOM, G-STR open)
The three named checks:
- (1) A best_vertices call is a function of (R, p, T), and of G and ω, both fixed in a phase.
  - V is initialised from R (662-667). X and W are not read.
  - str is read only at 73, for vertices already in the current set, and str affects no set.
  - Q is empty on entry. Candidates is written before it is read.
  - A deleted tangle and an undetected zombie answer false alike (132-135).
  Correct.
- (2) The −1 attractor's input is a function of (R, X). The scan 898-912 reads only R, X and attracts(·, X, R). Q and Z are
  empty on entry (Z reset at 875 and 955; nothing was added in the P branch), and t is set in the scan.
  - The attractor (918-923) consumes R as it pops, but popped vertices are in Z, so it computes the plain closure (Lemma
    1.2). That closure is monotone in T (1.2b) and ⊆ R. So at fixed (R, X) its output strictly grows at most n times
    along a phase. Correct.
  - The later steps 936-950 have no tangle rule and are functions of Z.
- (3) Nothing in §22c needs R = G′. PREFIX-MONO, C1-C4 and POS-FALL are statements about one call at a fixed context R
  with V_1 = the p-priority vertices of R. FDL gives the same input at the first differing call. Correct.
Arithmetic: per context R ∈ C_bv, the transitions with e* at R number ≤ (D_R+1)·H + D_R ≤ (D_R+1)(H+1); per (R, X) ∈ C_T,
≤ n. Correct, given that every transition has an e* of one of these two kinds.
- G-DOM (OPEN, DATA only). The sum needs e* never in sptl or Dom; §22e says so with "(DATA: never in sptl or Dom)".
  - sptl, provable (my argument). Pass 1's regions in each search equal that search's best_vertices final-round regions
    (same R, V and T; tangles learned at higher tops in pass 1 lie in consumed regions, 138). So an identical best_vertices
    call gives an identical pass 1. Repeated passes are deleted (G-h1). This is modulo G-STR.
  - Dom, NOT proved.
    - A tangle that s learns later lies in a later context, so it is disjoint from old X and from the earlier Dom parts.
      At a step where Dom and the final round's region loop are still step-for-step equal (YZ-read), its acceptance
      would also be a region-loop acceptance. That would put e* earlier, in best_vertices.
    - But Dom and the region loop separate at Dom's first straddling acceptance of an OLD tangle, which happens
      identically in s and s+1. After it the argument does not apply.
  - DATA (mine, corpus × 2 in-orders, labelling 0): first-difference kinds: region 282, rescue level 766, −1 attractor
    43, Dom 0.
- G-STR (OPEN, §0). A transition with no set-level difference, or in which s+1 learns before e*, is not counted. DATA 0 of
  4,290.
Hence: GAP-A ⇐ (CTX) ∧ (DIRTY) ∧ (STR-DET) ∧ (e* ∉ Dom), with the stated bound.

## 6. (f) Bit cost (TARGET.md §3) — SIGN (conditional)

- The algorithm's numbers are vertex indices, priorities ≤ n, tangle indices ≤ n·searches (Lemma W with SCC1), stack
  pointers and bits.
- Under the hypotheses, searches ≤ (n+2)·max_phase S = poly(n), so every number fits O(log n) bits, and the per-search
  cost is DTL-proof §3's polynomial (R2-PROVED2 (k)). So the bound gives polynomial time at bit cost.
