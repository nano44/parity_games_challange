## 1. (a) Lemma EXACT — SIGN
The setting is the region loop 690-705 of one pruning round at context R, for player p. CurR := R once per round (690). A popped
vertex leaves CurR (699). Z holds the prefix (703). attractVertices and attractTangles are called with (R, Z, G) = (CurR,
CurZ, CurR) and max_prio = pr τ (700-701).

Reading of the code, with CurZ := the region being built:
- Vertex rule, 69-90. Each u ∈ ins(w) of the popped w is examined. If u ∈ CurZ, only str is set (71-73). Otherwise u must lie
  in CurR with pr u ≤ pr τ (74). An opponent u is attracted iff it has no edge to CurR \ CurZ (78-85). An unpopped vertex in
  CurR is in CurZ or unattracted, so CurR \ CurZ = R \ (P(τ⁺) ∪ CurZ). The escape test is therefore "an edge into R outside
  P(τ⁺) ∪ CurZ", which is lfp's rule (dtl_ideal.py 38-41) with Z = P(τ⁺) ∪ CurZ.
- Tangle rule, 110-185, triggered at the pop of w only for t ∈ tin[w] (198-202). tin[w] holds the tangles that have w as an
  escape (443: built from tangleto, which becomes tout, 445-449).
  - Alive and of parity p: 116-118, plus the lazy deletion at 132-135. Since G shrinks only at 1035, between searches, this
    is exactly lfp's alive().
  - Each vertex must be in CurZ (136-137) or in CurR (138-139) with pr ≤ pr τ (140-141), and at least one must be new (146).
    So a vertex in P(τ⁺) or outside R rejects t.
  - Escapes, 153-157: none in CurR \ CurZ.
- Tops: τ is processed iff τ ∈ V \ P(τ⁺) (692), in decreasing index (691).
- O1: Oink sorts vertices by priority ascending before any solver runs (oink.cpp 35 → Game::sort, game.cpp 478-495;
  ties in arbitrary but fixed order). So pr τ′ ≥ pr τ for every top τ′ processed before τ.

(⊆). Every attraction is an instance of a rule of Cl_{pr τ}(·; T \ E_τ) in R, whose premises are already in the current
set:
- A tangle that fires has no vertex in P(τ⁺) (138-139), so it is not in E_τ.
- Its escapes are in CurZ, in P(τ⁺) or outside R. Its new vertices are in R \ P(τ⁺) with pr ≤ pr τ, and the triggering escape w
  is in CurZ.
- Each condition is monotone in the current set, so the region lies inside the least fixed point. This is (S0) together with
  the exclusion.

(⊇). I re-derived this as a single last-pop argument. Let S := P(τ⁺) ∪ region(τ). S contains the base P(τ⁺) ∪ {τ}. Take any rule
instance whose premises lie in S and whose conclusion u (or new set) lies outside S. Let w be the LAST-POPPED of its
triggering premises in S: the successor, or the escape. w was popped either in an earlier region τ″ (then pr τ″ ≥ pr τ by O1)
or in region τ.
- p-vertex u, pr u ≤ pr τ, edge to w. At w's pop, u ∉ CurZ″ and u ∈ CurR″, because u ∉ S. So u is attracted (74, 88),
  which contradicts u ∉ S.
- Opponent u, pr u ≤ pr τ, with every R-successor in S and at least one in S. At w's pop, each R-successor x of u is in
  P(τ″⁺), which is outside CurR″, or was popped no later than w, so x ∈ CurZ″. So u has no escape (80) and is
  attracted. Contradiction.
- Tangle t ∈ T \ E_τ with a new vertex, all escapes in S or outside R, and at least one escape in S. t has a new vertex, so
  t ⊄ P(τ⁺); t ∉ E_τ then forces t ∩ P(τ⁺) = ∅.
  - At w's pop, every vertex of t is in CurZ″ or in CurR″ (unconsumed).
  - Each such vertex has pr ≤ pr τ ≤ pr τ″: a vertex of region(τ) has pr ≤ pr τ by 74/140, a new vertex has pr ≤ pr τ
    by the rule, and τ itself has pr τ.
  - Every escape in S was popped by then, or lies in P(τ″⁺).
  - So 116-157 accept t and it fires (163-172). Contradiction.
So S is closed and contains the base, hence S ⊇ Cl. The §22r proof (closedness of P(τ⁺), then "the pop loop computes the
closure of the remaining instances") is the same argument split in two. Its first half holds at EVERY index τ, processed or
not, because it uses only O1 for the tops above τ. (b) needs exactly this.

## 2. (b) Lemma PREFIX-MONO-X — SIGN
Hypotheses: the same R and p, V ⊆ V′, T ⊆ T′ (alive, parity p), and (NS) at every τ processed in run 1.
- (NS) gives T \ E_τ ⊆ T′ \ E′_τ. If t ∈ T \ E_τ, then t ∈ T′. If also t ∈ E′_τ, then t ∈ E′_τ ∩ T ⊆ E_τ, a contradiction.
- The closure of lfp is monotone in its base and in its tangle set: every rule condition is monotone in Z.

The induction over τ in decreasing order:
- τ not processed in run 1: trivial.
- τ processed in both runs: EXACT twice, plus monotonicity.
- τ processed in run 1 only (the ABSORBED case, checked). Then τ ∈ V ⊆ V′ and τ ∉ processed′, so τ ∈ P′(τ⁺) (692).
  - By §1, P′(τ⁺) is closed under the threshold-pr τ rules of T′ \ E′_τ in R. EXACT's closedness half holds at an
    unprocessed index.
  - P′(τ⁺) contains P(τ⁺) (by induction) and τ.
  - So P′(τ) = P′(τ⁺) ⊇ Cl(P(τ⁺) ∪ {τ}; T′ \ E′_τ) ⊇ Cl(P(τ⁺) ∪ {τ}; T \ E_τ) = P(τ).
  - E′_τ is defined from P′(τ⁺) here, as §22r says, although τ is not processed in run 2.
- τ processed in run 2 only: trivial.

Along a phase, the hypotheses are met:
- Tangles are only appended (461), and G is fixed between dominion removals (1035), so the alive sets grow.
- Round 1 has the same V in every call at R (662-667).
- Later rounds are aligned by induction through (c) below.

N-b1. "PREFIX-MONO is the special case in which the later run is step-ideal" is loose. A step-ideal later run does not imply
(NS). PREFIX-MONO follows from the same induction with T′ in place of T′ \ E′_τ, where EXACT run 2 equals the unexcluded
closure. It does not follow from this statement.

G-P7-c1 (closed). The corollary as written derives only Π ≤ Π′ ("RV does not fall and Ψ does not shrink"). F_R also
counts e*-at-R transitions at which Π_R stays EQUAL (G-F1, R2-P6), so a STRICT rise at e* is needed without a new steal.
- POS-FALL's argument (§22c) transfers verbatim. FDL makes the input equal and the output strictly larger at e*.
  - If e* is in a threshold loop, Ψ grows strictly.
  - If e* is a region of τ_j, a vertex moves to τ_j from a lower-index top, while C4 (now from PREFIX-MONO-X) keeps every other
    vertex at a top of the same or higher index. So Φ_top falls strictly.
- Hence Π_R rises strictly at every e*-at-R transition without a new steal. L-ALG should add this line.

G-P7-c2 (closed). Which pairs are counted. The e*-pair of a transition s → s+1 (the visit of R at e* in s and the same
position in s+1) need not be a pair of CONSECUTIVE visits. R can be visited again later in s, and also early in s+1, with more
tangles. There are two correct ways to count.
- (i) Count the e*-pairs themselves. The lemma applies to any two calls at R with T ⊆ T′.
- (ii) Count only consecutive pairs, with N_R := # consecutive visit pairs of R in the phase with a new steal.
  - New steals chain: if no consecutive pair between visits a and b has one, the prefix inclusions compose, P_a(τ) ⊆ P_b(τ)
    at every round and index. So C4 holds between a and b, and the argument of G-P7-c1 gives a strict rise at e*.
  - So a non-rising e*-transition has a new steal on some consecutive pair inside its interval.
  - A consecutive pair lies in at most two e*-intervals: those of u−1 → u and u → u+1 if both of its visits are in search
    u, and only that of u → u+1 if it spans u → u+1.
  - So F_R ≤ N_R (descents) + 2·N_R = 3·N_R.
Either way, F_R is polynomial iff the counted new steals are.

## 5. What (FALL) reduces to
Given STR-DET, FDL, §22c-e/§22j and this packet:
  GAP-A ⇐ (CTX⁺) ∧ (FALL), and (FALL) ⇐ (NSTEAL),
- (NSTEAL): for every first-difference best_vertices context R, the number N_R of consecutive visit pairs of R within a phase
  with a NEW STEAL is polynomial.
- A new steal on a pair (a, b) is a region step (round r, top τ processed in a) and a tangle t ∈ T_a such that b's round-r
  prefix P_b(τ⁺) meets t without containing it, while a's prefix did not exclude t.
- Then F_R ≤ 3·N_R (G-P7-c2).
Status: proved as a reduction. (NSTEAL) itself is DATA only and open. Three observations bear on any proof:
- It is lossy. New steals occur at about 9.5 times as many pairs as non-rises. (NSTEAL) could be super-polynomial while (FALL)
  holds.
- The same old tangle is newly stolen again at a later round in the next search (fallv: tangle 2, round 3 then round 4).
  So a one-shot charge per (context, tangle) fails, and a potential over (round, top, tangle) has a range that grows with the
  stored tangles. This is §22r's circularity, now with an instance.
- The steal is a cross-round effect. Round r of the later visit starts from a larger V_r. A larger prefix at the same top is
  exactly what un-excludes a tangle in a and excludes it in b. Any bound must control how prefixes at a fixed (r, τ) can shrink
  and regrow. Only new steals shrink them (by PREFIX-MONO-X), so the question is whether new steals can feed each other without
  bound.
