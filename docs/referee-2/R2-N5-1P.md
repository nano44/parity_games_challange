## 2. The two facts (F1)/(F2) and (V1)/(V2)

prefix to λ avoids x (the play is simple up to the cycle); if x is on the cycle but not its top c, the path from ρ(x) to c runs
along the cycle and reaches c before returning to x. So Ω_ρ(x) = x ⊕ Ω_ρ(ρ(x)) with the ρ(x)-path avoiding x. ✓
(V2). For a = (c, P, ℓ), b = (c', P', ℓ'): if c ≠ c' the prefix changes neither cycle node, so the order is unchanged. If c = c'
and x ∉ P ∪ P' (the paths avoid x): both sets gain x or neither, (P ∪ X) Δ (P' ∪ X) = P Δ P', so the set comparison (most
relevant vertex of the symmetric difference) is unchanged; both lengths grow by one, so the length comparison is unchanged;
strictness is preserved. ✓ (The hypothesis "paths avoid x" is only needed as x ∉ P Δ P'; the box's form is fine.)

(F1). The box cites "VJ00 §5; Lemma F of N5-K10-box8.md", and Lemma F's proof is the one line "the arena optimum is pointwise
maximal over A_k (VJ00 §5)". The precise source is VJ00 (11): Θ_{σσ̄} = Ωσ, i.e. the ⊖-counter-strategy σ̄(v) := an Ωσ-minimal
successor is a POINTWISE best reply (Prop. 5.1 + Lemma 5.2). (F1) is (11) for the player who moves in the arena, which is ⊕,
so it is (11) applied to the DUAL game. Two things must hold for that, and neither is written anywhere in the fleet:
  (i) Dualisation reverses ⊴ exactly. In G^d (owners swapped, priorities + 1) relevance (rank) is unchanged and parities flip, so
      Reward^d(v) = −Reward(v): the cycle-node order reverses. For sets, B ≺^d C iff MaxDiff ∈ (B \ C) ∩ R−^d = (B \ C) ∩ R+ or
      ∈ (C \ B) ∩ R+^d = (C \ B) ∩ R−, i.e. iff C ≺ B. For lengths, ℓ ∈ R−^d = R+ gives k ≤ k', which is the reverse of the
      R+ rule k' ≤ k. So ⊴^d is the reverse of ⊴, and a ⊴^d-pointwise-minimal ⊖^d-strategy of the dual arena is a
      ⊴-pointwise-maximal ⊕-strategy of the arena. ✓ (This is also exactly how n5.py S4a computes σ_new: "Odd's optimal
      counterstrategy in the dual of H".)
  (ii) (11) itself. Lemma 5.2 (locally progressive ⇒ Ξ = Θ_{στ}) is proved in the source and I re-checked it (the multiset

      progressive for (σ, σ̄)) rests on §5.1's (3), (6), (8), (9); VJ00 proves (4) in one direction only ("we argue that clause
      2 holds" shows ⊴; the ⊵ direction, every simple path S ∈ Path_σ(v, ℓ) is dominated by a play with λ = ℓ, is asserted).
      I re-derived it: take S ⊴_ℓ-minimal; follow S then a cycle C through ℓ with top ℓ until the first repeat w ∈ S. If w = ℓ

      reward-minimum over reachable cycle tops), hence t ∈ R+ ∩ V_{>ℓ} and t ∈ S[w..ℓ]; then the walk S[v..w] + C[w..ℓ] has
      a set-weight with MaxDiff = t ∈ R+ on S's side, so strictly ⊴_ℓ-smaller than S; shortcutting its cycles (each has an

      disjoint as parts of one simple path) is the MaxDiff on u's side with T ∈ R+, in the second the sets are equal and u's
      path is longer with ℓ odd; both give Ω(u) ⊳ Ω(w*) for the shortest-path successor w*, so u is not the argmin. (9)/(3)
      are immediate. So (11) holds and (F1) follows. This closes G-1P-4 by my own derivation (not an external source);
      mechanically (F1) is checked on every arena of every run (§4: argmax attains the play maximum; brute force over all
      arena strategies on 15,113 arenas, 170,544 strategies).
