## 2. (b) Lemma CHARGE — SIGN WITH GAPS (closed)
Setting. q = (r, τ, t). An event of q at pair j (visits j → j+1) means two things: t ∈ F_τ at visit j in round r, and
t ∈ E′_τ at visit j+1, i.e. t meets P_{j+1}(τ⁺) without being contained in it. Here P(τ⁺) is the round-r prefix before τ
(§22r). A re-steal of q at pair i has its previous event at pair j < i.

G9-b1 (the proof as written uses the wrong set; closed).
- §23g writes "at visit j+1, t meets P_{j+1}(τ)", and "a firing tangle lies in CurR = R \ P_i(τ), so t ∩ P_i(τ) = ∅".
- The second claim is false. At visit i, t fired in region τ, so t ⊆ region_i(τ) ⊆ P_i(τ). The probe shows t ∩ P_i(τ) ≠ ∅ at
  every re-steal.
- The code fact is about the prefix BEFORE τ. A firing tangle's vertices are in CurZ (136-137) or in CurR (138-139). Here CurR
  = R \ P(τ⁺) minus the vertices popped in τ's own region (690, 699). So t ∩ P_i(τ⁺) = ∅.
- Corrected proof:
  - There is a w ∈ t ∩ P_{j+1}(τ⁺), from the event at j, and w ∉ P_i(τ⁺), from the firing at i. In particular i ≥ j + 2.
  - So there is a pair m, j+1 ≤ m ≤ i−1, with w ∈ P_m(τ⁺) \ P_{m+1}(τ⁺).
  - By the local PREFIX-MONO-X* below, pair m has a relevant steal at a step strictly before (r, τ): either round r at a top
    > τ, or an earlier round.
- The correction is needed for strictness. With P(τ), "w leaves P(τ)" could be caused at step τ itself, which is not strictly
  earlier.

## 3. (c) Depth and counting — SIGN
- depth is well defined. Causes lie at strictly earlier pairs, so the recursion "1 + min over causes" is well-founded.
- depth ≤ #steps − 1 ≤ (|R| + 1)|R| − 1. A cause chain is strictly decreasing in the step order (rounds ascending, tops
  descending), and the number of steps is ≤ (|R|+1)·|R|. PROVED given CHARGE, as stated.
- E_0 ≤ Q. The depth-0 events are exactly the first events, one per q.
- E_d ≤ Q·E_{d−1}. For fixed q, each depth-d re-steal maps to a min-depth cause, which has depth d − 1. The map is injective,
  because the cause sets of distinct re-steals of q are disjoint (§2). Summing over the ≤ Q quadruples gives the bound, so
  E_d ≤ Q^{d+1}.
- Σ_q k_q = Σ_{d ≤ D} E_d ≤ Σ_{d ≤ D} Q^{d+1} ≤ (Q/(Q−1))·Q^{D+1} ≤ 2Q^{D+1} for Q ≥ 2.
- N9-c1. For Q = 1 the geometric bound reads D + 1, but there a re-steal has no possible cause (q′ ≠ q is needed). So E_d = 0
  for d ≥ 1 and Σ = 1 ≤ 2. The stated bound holds for all Q ≥ 1.
- F_R ≤ 3·Σ_q k_q ≤ 6Q^{D+1}. With (FIRED-R), Q ≤ poly(|R|).
- Only for CONSTANT D does this give (STEAL-POLY). CONFIRMED.
  - The proved depth bound D ≤ (|R|+1)|R| − 1 gives only Q^{(|R|+1)|R|} = exp(Θ(n² log n)).
  - Even D = Θ(log n) would give n^{Θ(log n)}, which is quasi-polynomial and excluded by TARGET §4.
  - So (STEAL-DEPTH_D) must hold with D a constant independent of n, or with D·log Q = O(log n). The latter is the same thing up
    to constants, since Q ≥ 2 grows with n.
- (STEAL-DEPTH_D) itself is DATA only (G23g-3) and is not signed.
