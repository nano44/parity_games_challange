## 1. The derivation (the reading's §6, items 1 and 2): CORRECT
Step 1 (one segment, Even). Let [a, b] be an interval on which the computed σ̄_k equals a fixed c.
- For each k ∈ [a, b], c = σ̄_k is a best counter-strategy to σ_k, so Θ_{σ_k c} = Ω_{σ_k} (VJ00 (11), §5.2).
- Item 1 asks whether this needs the computed σ̄ or SOME optimal c. Answer: only some positional c with Θ_{σ_k c} = Ω_{σ_k} for
  every k in the segment. The computed σ̄ is one such c on intervals where it is constant, provided it is optimal (G-K9-2).
  - Ties do not matter. VJ00 §5.2 allows any Ω-minimising successor, and every such choice gives Θ = Ω (Prop. 5.1 + Lemma 5.2).
  - So ch_O could even be taken as the minimum over admissible optimal replies. That would give a stronger bound.
- In G_c every ⊖ vertex has out-degree 1, so each ⊕ strategy ρ has a unique play from each vertex, and Ω^{G_c}_ρ = Θ_{ρc}. Hence
  Ω^{G_c}_{σ_k} = Ω^G_{σ_k} for k ∈ [a, b].
- Improvements (VJ00 (2)) are a function of Ωσ and of ⊕'s own edges, which G and G_c share. So σ_k has the same improvements in
  G and in G_c.
- Combined with (T1) (R15 (d): σ_{k+1} = σ_k or Switch_I(σ_k), ∅ ≠ I ⊆ Iσ_k), the distinct consecutive strategies of σ_a..σ_b
  form an improvement sequence of G_c. The transfer is needed only at the source strategy σ_k of each step, and that lies in the
  segment. ✓
- (P) on G_c gives at most C n³ Even moves with both endpoints in the segment. Flat steps (R15 (b)) are moves, so (P) must count
  them (T22 (iii)). My chains count them (§4). ✓
Step 2 (segments, item 2).
- Cutting at every k < K with σ̄_{k+1} ≠ σ̄_k gives exactly 1 + ch_O maximal constant intervals.
- The steps k → k+1 that cross a cut number exactly ch_O, and each carries at most one Even move.
- So #Even moves ≤ (1 + ch_O)·C n³ + ch_O ≤ (C n³ + 1)(1 + ch_O). ✓
- Tightening (G-K9-3): a crossing step's source σ_k lies in the left interval, so the move is an improvement in G_{c_left}. It
  extends the left segment's chain, giving #Even ≤ (1 + ch_O)·C n³.
Step 3 (Odd, on G^d).
- G^d_{c'} fixes every G^d-⊖ vertex (an Even vertex of G) to c' = τ̄. It is a parity game with ⊖ out-degree 1, so (P) applies
  (priorities + 1 are still a parity game). ✓
- τ's moves are Switch_I on G^d by R15 (d). ✓
Step 4. By (T2) (R15 (d)) each iteration contains at least one move, so K ≤ #Even + #Odd ≤ (C n³ + 1)(2 + ch_O + ch_E). ✓
The reading's scope remark is correct: the proof uses only (T1)/(T2) and (P), so it holds for every tie-break of N5, and for any
simultaneous scheme whose moves are improvement switches.

## 2. (P) stated exactly as needed (the Lead's item 2)
(P_K9) There is f(n) such that for every parity game H on n vertices in which every ⊖ vertex has out-degree 1, and EVERY sequence
ρ_0, ..., ρ_L of ⊕ strategies with ρ_{j+1} = Switch_{I_j}(ρ_j), where each I_j is a non-empty unambiguous set of improvements of
ρ_j in H (ANY start ρ_0, ANY choice of I_j, flat steps included), we have L ≤ f(n). K9 then reads K ≤ (f(n) + 1)(2 + ch_O + ch_E).
- Both players are covered by the same (P_K9), because G^d_{c'} is again such an H.
- "Any start" is needed: segment starts are arbitrary strategies of the run.
- "Any I" is needed: N5's Even move is a best response against τ_k in G restricted to A(v), and τ_k is not visible in G_c, so
  inside G_c the chosen subset is unconstrained.
- What can be dropped, but helps little: (P_K9) is needed only for sequences along which c stays optimal in the ORIGINAL G (c is
  the computed reply on the whole segment). In H = G_c, c is the only ⊖ strategy, so this restricts only which games H = G_c can
  occur, not the subset choices.
- Relation to the source (item 3 of the reading's §6, with T22). VJ00 Prop. 7.4 says "the discrete strategy improvement
  algorithm terminates after O(n³) strategy improvement steps for one-player parity games".
  - I re-read printed p.27 and the contrast sentence before it ("the standard policy, i.e., switching all switchable vertices").
  - I agree with T22: the one player is ⊕ (otherwise ⊕ has one strategy and the statement is vacuous), and the text does not say
    "all policies", whereas Prop. 7.6 does ("for which all policies have length …").
  - So (P_K9) is NOT what VJ00 asserts on any safe reading. It is a strictly stronger, unsourced hypothesis (G-K9-1).

## 3. Does a weaker premise suffice? (The Lead's item 3): NO, not for K9 as proved
- (P_SA) (switch-all only, Friedmann thesis Thm 4.9's form) bounds only chains whose every step is a switch-all step. K9's
  segments are chains of N5's moves.
  - N5's Even move S4a is the one-player optimum against τ_k among "keep or take an improving edge".
  - That is a different rule from switch-all. It may leave improvable vertices unswitched, or switch a vertex to a non-best
    improving successor, because what is best against τ_k differs from what is ⊴-best under Ωσ, which is against σ̄.
  - So the segments are not switch-all chains, and (P_SA) does not apply to them.
- A weaker premise could be used only if K9 changed:
  - (i) bound N5's moves by switch-all moves through a domination lemma ("every improvement sequence in a one-player game is at
    most poly(n) times the switch-all length"). That is unknown, and my data (§4) shows arbitrary chains about 14× longer than switch-all (137 vs 10 at n = 8)
    at small n; or
  - (ii) change N5 so that each player's move is a switch-all step against the opponent's reply. That is a different algorithm.
- Neither is in the reading.

Does (3b) conflict with my §3 ("a weaker premise does NOT suffice")? NO.
- My §3 answered the Lead's example axis, switch-all (the policy axis). There the two reports agree: switch-all does not suffice.
- REFEREE's (3b) weakens a different axis, which steps are counted. I checked it:
  - On a segment, Ω^{G_c} = Ω^G at every σ_k, so "flat" means the same in G and G_c.
  - Every flat step is a non-empty switch of improvements in G_c. By R15 (c) applied to G_c, it raises φ (computed in G_c) by
    ≥ 1, and Ω is unchanged along a flat run, so φ is comparable along it.
  - |φ| ≤ n(n−1), so a run of consecutive flat steps has length ≤ 2n(n−1).
  - s strict steps leave at most s + 1 flat runs, so a segment has ≤ s + (s + 1)·2n(n−1) ≤ (C n³ + 1)(2n(n−1) + 1) moves.
  - CORRECT.
