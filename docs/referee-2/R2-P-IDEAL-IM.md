## Proof check
- Fact 0: the β of (z, 0) lies only on its own chain (acyclic; one β per option), so the two sets differ and their ENC integers
  differ. ✓
- IM:
  - (a) Neither chain passes y, so both values are unchanged (LOCAL).
  - Rise at y: y switches to C_y(s). Its new chain avoids y (acyclic), so δ := cv_(s′)(y) − cv_s(y) > 0.
  - A chain through y reaches y under s′ through the same movers, so its value rises by exactly δ (ENC along the prefix).
  - (b) Both values move by δ. (c) One value rises and the other is unchanged, so C_z(s′) ∈ {C_z(s), k}. ✓
- BIT-CHAIN, induction on l.
  - (ii): at level 1 the keys compare at κ^c (1 − c vs c). At level l ≥ 2 the prefixes are the keys of the two distinct level-(l − 1)
    options; they differ and decide.
  - (i): (0, 1) keeps the order, (1, 0) reverses it, and on equal options the own gates decide. ✓
- KEY-DIR: A_u(x) is {u(x)} or {0, 1} (Fact 0). x takes the key-preferred option of A, which is 1 − b_(l−1) by (ii). So x moves iff it
  is unhappy and u(x) = b_(l−1). The bits come from u′, whose lower levels are fixed first. ✓
- VALUE-MONO: by ISO, upper chains avoid 0 and 1. Induction along the Ξ-order: cv_(u′)(x) ≥ v_u(x, u′(x)) ≥ cv_u(x), strictly if x
  moved. NO-REPEAT: the cv vectors strictly increase over the moving steps, so at most 2^(2m) distinct states. ✓
- COMPOSE: A-sets are computed inside each part (chains stay in their part; ranks are raised, which keeps each part's order).
  - K's keys are unchanged.
  - The first G-level's key preference is H's bit b_(m′) (BIT-CHAIN in H).
  - G's bits continue the recursion with G's own gate bits.
  - So H's step is K's c-step on K and G's c_*-step on G (KEY-DIR in both). ✓
- COMPOSE-LB: H's level-0 movers have both options at X and start on their better option, so they stay put. ISO keeps all other values
  free of them, and W-ONLY gives c = b_0 constant.
  - N-1 (text, no gap): the proof should say that H's level-0 gates are chosen so that b_0 = c, the c of the given flip-free
    K-sequence. Gates are free, so this is always possible; the proof uses it silently. ✓
- FRAME (i): Φ1 (z is not on its own chains), Φ2 = IM (a), Φ3 = IM (b), (c). The frame rule «C_x ≠ s(x) and C_x = 1 − b_(l−1)» equals
  KEY-DIR's «s(x) = b_(l−1) and C_x ≠ b_(l−1)» (binary). The bit recursion runs from the new states.
- FRAME (ii): delete the identity steps (still a valid sequence; bit changes do not increase). ✓
