### 3.2 G-TB-1: step 2's inequality
The proof writes W*(x) ⊵ W*(σ_k x) ⊕ x ⊵ W_k(σ_k x) ⊕ x = W_k(x) = W*(x).
- The second and third relations hold: (F1) gives W* ⊵ W_k, ⊕ is monotone, and (V1) at k holds since x is not its cycle node.
- The first relation is a Bellman inequality for the arena optimum. It holds trivially only when x is NOT on y := σ_k(x)'s W*-play: then
  σ*[x → y] is an arena strategy whose value at x is W*(y) ⊕ x, and (F1) applies.
- When x lies on y's W*-play, W*(y) ⊕ x is not the value of any arena strategy. The packet gives no argument for that case.
Closure (my proof, uses (F1) only). Assume W*(x) = W_k(x), x not its own cycle node, c := its cycle node.
- (a) x on y's W*-path BEFORE c. Let Z := x → y → … → x, with top m. Z avoids c and x's W*-path after x.
  - m ≻ c and m even: σ*[x → y] gives x the cycle node m, which beats c for Even, against (F1) at x.
  - m ≻ c and m odd: W*(y).P \ W_k(y).P = Z ∩ (above c), since W_k(y) = (c, P* \ {x}, ℓ − 1) by W_k(x) = W*(x). Its top m is odd, so
    W*(y) ◁ W_k(y), against (F1) at y.
  - m ≺ c and c odd: cycle node m beats c for Even (reward(m) > −p′(c)), against (F1) at x.
  - m ≺ c and c even: W*(y) ⊕ x has W*(x)'s path set and a strictly larger length. So W*(y) ⊕ x ◁ W*(x), against the relation
    W*(y) ⊕ x ⊵ W*(x) already shown.
  - So case (a) never occurs.
- (b) x only on the cycle part of y's W*-play (after c). Let m := top of W*(y).P.
  - If W*(y).P = ∅, σ*[x → y] realises W*(y) ⊕ x at x, and (F1) gives ⊴.
  - Otherwise the new cycle has top m ≻ c. m even contradicts (F1) at x. m odd gives W*(y) ⊕ x ◁ W*(x), since x's path to c on the
    cycle has nothing above c. That contradicts the relation shown, so this sub-case does not occur.
- So equality holds in every case that occurs. CLOSED.
- DATA: 277,668 step-2 instances in the batch (N5 runs, arenas, general games). "x on y's W*-path before c": 0, as (a) predicts.
  "x only on the cycle part": 27,336, equality every time. Climbs: 5,879,798 more, equality every time; in the last climb round, which
  splits the two cases, 403,834 are cycle-only and 0 on-path.

### 4.2 The proof, and two gaps
- G-R-1 (step 1). "Every surviving edge joins two vertices with the same membership in each processed set M_u" is false for the edges out
  of u itself.
  - Even likes u: u ∉ M (reach(v, u) excludes u), yet u keeps its edges INTO M.
  - Odd likes u: u ∈ M, and its edges are not restricted at all.
  - Correct invariant: for a surviving edge x → y and every processed u ≠ x, [x ∈ M_u] = [y ∈ M_u]. That is what step 2 uses: when
    x = u′ is processed, x's own bit is on both sides, since the value via y is W*(y) ⊕ x.
  - With this form, steps 2-3 go through: for every u′ processed before u, the two path sets agree at u′ (u′ ≠ x by the invariant;
    u′ = x by ⊕ x), and at u they differ against the optimiser. CLOSED (wording).
- G-R-2 (the statement). "y optimal for the optimiser at x in the cycle-node and path-set components", read with the formal extension
  W*(y) ⊕ x (length ignored), is FALSE as a sufficient condition for survival.
  - The packet's step 2 case "Even likes u, x = u" argues on plays ("the play through y returns to u before c … worse"), not on ⊕.
  - Instance (my tb_general.py, seed 532, game #13, iteration 1; a dual-arena evaluation at cycle node 19): edge 11 → 13 is deleted at
    step u = 11. W*(13) ⊕ 11 has W*(11)'s cycle node and path set; only the length differs.
  - Also every self-loop u → u at an Even-liked u above c. Totals in the batch: 8,464 deleted edges with (c, P) equal, all with
    u = x; 2,117 of them with x ≠ y (climbs: 110,573 and 84,178).
  - The form TB and CASC use, full equality W*(x) = W*(y) ⊕ x (length included), is TRUE. For x = u, every y → c path in the restricted
    graph passes u, so dist[y] ≥ dist[u] + 1 and the lengths differ. Equivalently: optimal paths are simple (VJ00's reading).
  - Repair: state Lemma R for fully optimal edges, or for edges on an optimal play. CLOSED (statement wording).
- Steps 2-3 otherwise ✓.
  - Even likes u, x ∈ M: u ∉ path[x] but u ∈ path[y]. u is the top difference, and Even likes it, so it is worse for the optimiser.
  - Odd likes u, x ∈ M \ {u}: u ∈ path[x] but u ∉ path[y]. Worse for the optimiser.
  - Survivors are path-set consistent (the invariant), so the survivors of optimal length are exactly the fully optimal edges.
- DATA, on an instrumented re-transcription of S1 (iii)-(vi), asserted equal to si.py's evaluate on every call (0 differences):

  - Every fully optimal edge survives.
