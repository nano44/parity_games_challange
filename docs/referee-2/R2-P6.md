## 1. (a) §22f — SIGN WITH GAPS
What is PROVED, checked:
- Π_R(T) is a function of T for every context R. A best_vertices call is a function of (R, p, T) given G and ω (R2-P4
  §5 (1)).
- Along a phase, T_s grows, so Π_R(T_s) is a sequence indexed by s, whether or not s visits R.
- Let F_R be the number of s with Π_R(T_{s+1}) ≱ Π_R(T_s): descents, including incomparable pairs. The F_R descents
  split the phase into at most F_R + 1 segments, and Π_R is non-decreasing inside each segment.
- In one segment the strict rises form a chain of length ≤ H in the lex order, with H as in §22c (R2-P4 §4, the same
  counting, valid at any R).
- So the transitions at which Π_R rises number ≤ (F_R + 1)·H. Adding the F_R descents gives (F_R + 1)(H + 1).
- Under STR-DET (R2-P5), the first difference e* of every transition is a set-level tattr in a best_vertices call, a
  −1 attractor or a Dom step (sptl excluded, R2-P4 §5). A transition whose e* lies in a best_vertices call at R
  changes that call's log.
G-F1 (gap in the proof; DATA 0).
- The budget counts e*-at-R transitions only if each of them CHANGES Π_R. A rescue-level e* changes Ψ. A region e* at
  τ_j need not change Π_R:
  - the region output is strictly larger, so some v moves up to τ_j;
  - but on a DIRTY call (no C4) another vertex can move to a lower-index top;
  - with U_r, W_{r,t} and RV equal, Φ_top can then stay equal by compensation, and Π_R is unchanged.
- Such a transition is neither a rise nor a descent, so neither term counts it.
- On a clean call this cannot happen: C4 makes Φ_top fall strictly (POS-FALL).
- Fix: define F_R := #descents of Π_R along the phase + #e*-at-R transitions at which Π_R does not rise. The bound then
  holds as written, and (FALL) should be stated for this F_R.
- DATA: L-ALG's §22e table at e* has "Π rises" or "RV falls" only, 0 "Π does not rise". So the extra term is 0 on the
  data.
DATA only (not signed):
- "Π_R descends only where RV falls (73 / 72 cases, all at dirty calls)".
- "At most 2 descents per context per phase".
- Proved here: only that clean visits never descend (PREFIX-MONO, R2-P4 §2). Whether a dirty call can descend through
  Ψ or Φ_top with RV fixed is not proved.
Reduction: GAP-A ⇐ (CTX) ∧ (FALL) given STR-DET is correct with the corrected F_R. The −1 attractor term n·|C_T| and the
+1 (G-e2) are as signed in R2-P4. The Dom term is item (b).
The (CTX) paragraph of §22f is reading plus an instance:

## 2. (b) §22j — SIGN (reading R-I)
- R-I. The input of a Dom step (878-890 / 962-991, top τ_j) must be I = (X, R, τ_j, pr τ_j): X is the whole current
  removed set (old X plus earlier parts), and R is the unconsumed context.
  - The step pushes only τ_j (966), so its output is not the least closed superset of X. A p-vertex with an edge into
    old X is never examined, since old X is not popped.
  - The output N is still the least set N ∋ τ_j closed under these rules, with premises in N:
    - a vertex rule triggered by a pop in N;
    - the escape test against R \ (X ∪ N);
    - a tangle triggered by an escape in N, with vertices in X ∪ N ∪ R, new ones of priority ≤ pr τ_j, and escapes in
      X ∪ N or outside R.
    "Vertices in X" includes old X and earlier parts: the X-straddling acceptances (136-137).
  - Every rule is positive in N and in T. So N = o(I, T) is a function of (I, T) and is monotone in T. This includes
    the X-straddling acceptances, which depend on T only through which tangles exist, a monotone dependence.
- The Lead's question, "is a Dom step's input really fixed by (R, X)?": yes, with R-I.
  - At a first difference, FDL (ii) (with STR-DET) makes every earlier computation identical in s and s+1. So X, R,
    the top order (V) and the threshold are equal: I is equal.
  - The T-dependence of straddling acceptances is on the output side and is monotone, so the chain argument applies.
  - With a smaller "input" (the pushed seed only), the output would not be a function of (input, T).
- The chain is checked. For s₁ < s₂ with e* at input I: o(I, T_{s₁+1}) ⊆ o(I, T_{s₂}^{e*}) ⊊ o(I, T_{s₂+1}), using
  T_{s₁+1} ⊆ T_{s₂} ⊆ T_{s₂}^{e*} and nothing created before e* (STR-DET). The outputs are subsets of R ⊆ G′, so there
  are ≤ n such transitions per input.
  - The same argument holds for the −1 attractor (input determined by (R, X) via 898-912; R2-P4 §5 (2)), and for any
    tattr.
- The formula S − 1 ≤ Σ_{R∈C_bv} (F_R+1)(H+1) + n·(|C_T| + |C_Dom|) + 1 is correct, given (a) with G-F1's F_R:
  - e* ∈ {bv, −1 attractor, Dom} under STR-DET (sptl excluded);
  - the barren last transition gives the +1.
  - Hence GAP-A ⇐ (CTX⁺) ∧ (FALL).
  - The hypothesis (e* ∉ Dom) / (DOM-e*) is no longer needed: it is replaced by the budgeted term n·|C_Dom|.
- The "Where a Dom e* would come from" paragraph is a sketch and is not signed. Its first step is correct: the Dom part
  outside s+1's W_max can only grow through X-straddling acceptances. W_max is closed at max_prio with Gx = R, and it
  contains Dom's vertex-rule additions and its non-straddling acceptances by induction.
