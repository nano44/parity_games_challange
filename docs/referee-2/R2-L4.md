## 1. Re-derivation
Lemma L4.1. H = (V, E ⊆ V × Σ_d × V), |V| ≤ k; H' = (V × Σ_d, E'), pr'(v,p) = p, ((u,p),(v,q)) ∈ E' iff (u,q,v) ∈ E.
(a) The V convention (S1 D1) labels the edge ((u,p),(v,q)) by pr'(u,p) = p, so the word of the H'-path
(v0,p0)(v1,p1)... is p0 p1 p2 ...; the projection to H is v0 -p1-> v1 -p2-> v2 ... (an edge of E' at position i encodes
(v_i, p_{i+1}, v_{i+1}) ∈ E) and the lift of an H-path from any (v0,p) exists for every p ∈ Σ_d. Hence
Words(H') = Σ_d · Words(H) for infinite paths. Correct. One remark for the text: the identity is false for finite
prefixes when H has sinks (a vertex (v,p) with v a sink of H contributes the one-letter prefix p to nothing); the
lemma only uses infinite words, so nothing breaks, and iterated sink removal (which does not change Words) makes the
finite version true as well. My brute force (l41_bruteforce.py) found exactly this and nothing else: after pruning
sinks, (a) holds for all prefix lengths ≤ 5 and (b) holds on all 4,096 multigraphs with k = 2, d = 3 and 300 random
ones with k = 3, d = 4 (0 failures).
(b) A cycle of H' projects to a closed walk of H with the same label multiset (the H'-cycle's labels are the vertex
labels p0..p_{m-1}; the walk's edge labels are p1..p_{m-1}, p0). A closed walk's maximum is the maximum over the simple
cycles of its decomposition, so "H even ⟹ H' even" and "H odd ⟹ H' odd"; the converses hold by lifting a simple cycle,
and are not used. Correct.
(c) Immediate from (a), (b), |V'| ≤ kd, and limsup(p·w) = limsup(w). Correct.
(d) q1 = δ(q0,1) ≠ ⊥ because 1·2^ω ∈ EvenCycles^V_{kd,d} ⊆ L(A) (needs d ≥ 2, k ≥ 1, both assumed); A' = (Q, q1, δ) is
deterministic over Σ_d with L(A') = {w : 1·w ∈ L(A)} and |A'| ≤ |A| (S1 D4 counts Q without ⊥ on both sides). Strong:
EvenCycles^E_{k,d} ⊆ L(A') ⊆ LimsupEven_d. Weak: the same first inclusion and L(A') ∩ OddCycles^E_{k,d} = ∅. Correct.
The proof works verbatim with any letter in place of 1 and for the S convention (an S-graph is an E-graph), as the
lane's remark (ii) says.
Lemma L4.2. (n' ≤ n) EvenCycles^V_{n',d} ⊆ EvenCycles^V_{n,d}, OddCycles likewise; LimsupEven is unchanged. (d' ≤ d)
The restriction A|Σ_{d'} accepts L(A) ∩ Σ_{d'}^ω; EvenCycles^V_{n,d'} ⊆ EvenCycles^V_{n,d} ∩ Σ_{d'}^ω,
LimsupEven_d ∩ Σ_{d'}^ω = LimsupEven_{d'}, OddCycles^V_{n,d'} ⊆ OddCycles^V_{n,d}. States do not increase. Correct;
d' need not be even.
Theorem L4. For even d' with 2 ≤ d' ≤ n and k = ⌊n/d'⌋ ≥ 1: s^V(n,n) ≥ s^V(n,d') (L4.2) ≥ s^V(kd',d') (L4.2, kd' ≤ n)
≥ s^E(k,d') (L4.1, k ≥ 1, d' ≥ 2) ≥ C(⌊lg k⌋ + d'/2 − 1, ⌊lg k⌋) (CDFJLP Thm 5.1 at (k,d'), d' even). Correct.
Corollary L4.3. Every inequality re-derived by hand and checked by exact arithmetic for 64 ≤ n ≤ 20,000
(l4_numeric.py, "chain violations: none"): d' = 2⌊√n/2⌋ is even with √n − 2 ≤ d' ≤ √n; k ≥ ⌊√n⌋; ⌊lg k⌋ ≥ ⌊½ lg n⌋ − 1 ≥ a0
(the text's "n ≥ 16" can be "n ≥ 4"; harmless); d'/2 − 1 ≥ b0; C(a+b,a) monotone in both arguments; C(m,r) ≥ (m/r)^r;
b0/a0 ≥ √n/(2 lg n) for n ≥ 64. The quoted values (optimised 36, 816, 52360, 11716640, 2.6·10^13; closed form 3, 28, 680,
46376, 6.5·10^9) reproduce exactly; the optimising d' is 16, 32, 64, 256, 1024. (√n/(2 lg n))^{a0} = 2^{¼ lg² n − O(lg n lg lg n)} =
n^{Ω(lg n)}. Correct.
Corollary L4.4. Within S2 §1's class (i)-(iii) the running time is ≥ n·|A_n| by clause (iii), and |A_n| ≥ S(n) whenever
A_n is a deterministic strong separator for the TARGET alphabet in any of the three conventions and either letter
encoding: s^E ≥ s^V (S1 F1) and s^V(n, n+2) ≥ s^V(n,n) (L4.2), so L4.4 does not depend on S1 Lemma 2(b-V). Correct as a
conditional statement; see F3 for the quantifier over "known" algorithms.

## 2. CDFJLP Theorem 5.1 as a black box: hypotheses checked against the source
- Statement (universal-trees-inside-separating-automata.tex, first theorem): "Every non-deterministic safety strong
  (n,d)-separator has at least C(⌊lg n⌋ + d/2 − 1, ⌊lg n⌋) states, which is at least n^{lg(d/lg n) − 2}." Quoted
  correctly in L4. L4 uses only the binomial.
- The remark "because d ≤ n" after Lemma 5.1 (tree-embedding) concerns ONLY the second form: the universal-tree bound
  (tree-witnesses-and-universal-trees.tex, Theorem "For all positive integers ℓ and h, every (ℓ,h)-universal tree has at
  least C(⌊lg ℓ⌋ + h − 1, h − 1) leaves, which is at least ℓ^{lg(h/lg ℓ) − 1} provided that 2h ≤ ℓ") has no hypothesis for
  the binomial. This matters: Theorem L4's maximum ranges over d' up to n, where d'/2 > k = ⌊n/d'⌋ happens (e.g. the
  optimising d' = 16 at n = 64 has k = 4, d'/2 = 8). The binomial form is valid there. Checked.
- Convention. The proof of Lemma 5.3 (universal-tree) feeds the word α_t of the graph G_t, which has "for every vertex v_i
  and every even priority p, 1 < p ≤ d, a self-loop ... with the even priority p": parallel self-loops, i.e. convention E.
  Theorem 5.1 is therefore a theorem about separators of EvenCycles^E (as S1 D1 and L4 read it); L4 applies it to s^E only.
  Checked.
- State count. Lemma 5.1 injects the leaves of the D-tree into the states via representatives q_e of the equivalence
  classes of ⪯_1, a quasi-order "on the set of non-rejecting states"; so the bound counts non-rejecting states, which is
  S1 D4's |Q| (⊥ not counted). A deterministic automaton with a sink ⊥ is a non-deterministic safety automaton with
  total transition relation and one rejecting state. Checked.
- Accessibility: the proof first reduces to an accessible automaton (fewer states), so the bound applies to |A|. Checked.
- Evenness of d: CDFJLP's d is even by convention (§2.1); L4 uses even d' only. Checked.
- Consistency with the lane's unrefereed SAT table (comparison only): the Thm 5.1 bound is ≤ every listed s^E value
  (s^E(2,4) = 3 ≥ 2, s^E(2,8) = 5 ≥ 4, s^E(4,4) = 8 ≥ 3, ...) and Theorem L4 gives 1 ≤ s^V(n,n) = 2, 5, 7 for n = 2, 3, 4.

## 4. Findings (CHANGES, all minor)
- F1 (quantifier). Theorem L4 is stated "for all n ≥ 1", but at n = 1 the set {d' even, 2 ≤ d' ≤ n} is empty and the
  maximum is undefined. Write "for all n ≥ 2" (the bound is 1 for 2 ≤ n ≤ 7, 2 at n = 8), or define the empty max as 1.
- F2 (constants). In L4.3 the chain S(n) ≥ C(a0+b0, a0) ≥ (b0/a0)^{a0} ≥ (√n/(2 lg n))^{⌊½ lg n⌋ − 2} is valid for all
  n ≥ 64, but the last member is 2/3 at n = 64, equals 1 at n = 256 and exceeds 1 only from n = 257 (exact check). The
  explicit-constant statement "for n ≥ 64" is therefore vacuous for its last member below 257; say so, or state the
  constants for C(a0+b0, a0) (which is 3 at n = 64) and keep the last form asymptotic. "(For n < 64 the bound is ≤ 1)"
  is right for C(a0+b0, a0).
- F3 (scope of L4.4). "every known quasi-polynomial product algorithm, CDFJLP §3.3-§4" is a statement about the
  literature, not a consequence of L4; it belongs to L-LIT's barrier sign-off (BARRIERS.md B1 fine print). The
  mathematical content of L4.4 is: any algorithm of class (i)-(iii) whose automaton is a deterministic strong separator
  of the TARGET alphabet (any convention, with or without the +2 shift) runs in time ≥ n·S(n) = n^{Ω(lg n)}. Suggest
  splitting the sentence so the theorem part is separable from the literature part.
- Remark (not a change). The L4 proof text and S3 §4b route R1 differ: R1 re-runs CDFJLP Lemma 5.1 on a split G'_t;
  L4 as written uses Thm 5.1 as a black box through Claim R. The GAPS.md G1 row still describes the R1 gap ("CDFJLP Lemma
  5.1 induction not re-derived in V"); for L4 as written, the gap is instead "Thm 5.1 taken from the source" (section 5).
