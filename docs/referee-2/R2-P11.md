## 1. (a) Lemma CHANGE-NEW — SIGN
"Check hard" 1: the visit is a function of (R, p, T) and of nothing else carried across visits. I went through best_vertices
(643-776) and its callees, attracts (41-57), attractVertices (66-101), attractTangle(s) (110-202), for every object read.
- V is cleared by the caller (852, asserted at 648) and recomputed from R (662-667). R is only read, because CurR is a copy
  (690).
- Z, prevV, CurR and CurZ are locals (651-654). Candidates (global) is written before it is read in each round (712-714).
  Q (global) is empty on entry: every loop that fills it drains it (697, 727, 883, 918, 944, 1032).
- str is written at 73, 89, 171 and 694, and read only at 73 (`str[from] == -1`), where it decides whether to write str. So
  the set-level computation never depends on str, and STR-DET is not needed for this step (N11-a1).
- The tangle store is read: tpr, tv, tout, and tin (order by tangle id, since new ids are appended at 443).
  - Lazy deletion (132-135) can change tpr from one visit to the next. But a tangle with a vertex outside G returns false
    whether it is deleted at 117 or reaches 132.
  - A vertex outside G is outside R ⊆ G, so no such tangle ever fires.
  - So the set-level behaviour depends only on the alive set T.
- priority and owner are fixed. this->G is read at 132; it changes only at 1035.
- depth, X, W, cur_depth and val are not read by best_vertices.
So the set-level computation is a deterministic function of (R, p, alive T), given the order datum, and the context key
(depth, R) is finer than needed. Identical visits require only equal alive T. Probe: there are 0 differing pairs with equal T.

"Check hard" 2: only appended.
- Tangles are added only at 458-461 (push_back), and nothing removes an entry.
- tpr[t] = −1 is set only at 134, and only for a tangle with a vertex outside this->G.
- this->G is assigned only at 1082 (start) and 1035 (dominion loop of search(), after search_rec). So within a phase (G′
  and p fixed), G is constant. A tangle alive at visit x stays alive, and newly extracted tangles lie inside R ⊆ G.
- So T_x ⊆ T_y as alive sets, and "born between" = ids in [ntv(x), ntv(y)). CONFIRMED.

Proof steps.
- Let e_k be the first tattr whose output differs. All earlier outputs agree, so its input is equal: the prefix P(τ⁺), V_r
  and τ for a region step, or (Z_in, t) for a threshold step.
- Region step.
  - The exclusion status of an OLD tangle depends only on P(τ⁺), so E_y ∩ T_x = E_x.
  - By EXACT, out(x) = Cl(base; T_x \ E_x) ⊆ Cl(base; T_y \ E_y) = out(y).
  - By EXACT*, out(y) = Cl(base; F(y)). If F(y) ⊆ T_x, then F(y) ⊆ T_x \ E_x (fired tangles are not excluded), so
    out(y) ⊆ out(x) and the outputs are equal. Contradiction.
- Threshold step (722-731). There are no exclusions (Gx = R, nothing consumed, all of Z pushed at 724), so out = Cl_t(Z_in; T).
  - The EXACT* argument holds here verbatim: the derivation uses only the tangles that fired, and the closure over them is
    ⊆ the closure over T, which equals out.
  - So out(y) = Cl_t(Z_in; F_thr(y)), and the same contradiction follows.
- The candidate tests (attracts, 714, 738) and the round control (748-772) are functions of these sets. So the first set-level
  difference is always at a region or threshold output.
- The tangle that fires at e_k in y is born between x and y. □

## 2. (b) Corollary — SIGN, with N11-b1
- The birth intervals [ntv(x_k), ntv(x_{k+1})) of consecutive pairs are disjoint. So the differing pairs get distinct new
  tangles, each firing at R, and D_R ≤ #fired⁺(R).
- N*_R ≤ D_R. If x and y had identical computations, P_y(τ⁺) = P_x(τ⁺), so a tangle in F_τ(x) ⊆ T_x \ E_x is not in E_y.
  So a relevant-steal pair differs.
- R11 (c) then gives F_R ≤ 3·N*_R ≤ 3·D_R ≤ 3·#fired⁺(R), with no steal premise.
- With R9 and the sum over C_bv: GAP-A ⇐ (CTX⁺) ∧ (FIRED⁺-R), given STR-DET. CORRECT.
- N11-b1 (a sharper use; it removes H). Take an e*-at-R transition s → s+1. The calls at the e* position in s and in s+1 have
  equal input R and different outputs. Along the visits of R between them, some CONSECUTIVE pair must differ: otherwise the
  chain of identical computations makes the endpoints equal.
  - Two such intervals overlap only inside s+1 before π, where T is constant (STR-DET (c)). There every call is identical,
    so the charged pairs are distinct.
  - Hence #(e*-at-R transitions) ≤ D_R ≤ #fired⁺(R) given STR-DET, and ≤ 2·D_R without it.
  - So S − 1 ≤ Σ_{R ∈ C_bv} #fired⁺(R) + n(|C_T| + |C_Dom|) + 1 (R9's other terms). There is no H and no F_R. The reduction
    is the same; the constant is much smaller.

## 3. (c) Honest limit — CONFIRMED; (FIRED⁺-R) is GAP-A in disguise
- Tightness: my probe reproduces spp_chain_up_n43. In the pinned order the root context (|R| = 43) has 42 visits, D = 41 and
  #fired⁺ = 41. So D_R = #fired⁺(R) is attained. It is also attained elsewhere: max D_R/#fired⁺ = 1.00 in both orders.
- At G′: D_{G′} counts the searches whose ROOT call differs from the previous one. The data has #fired⁺(G′) ≤ |G′|, and
  #fired⁺/|R| reaches exactly 1.00 (fired18_stable_n20, stable), so "≤ |R|" has no slack on data.
- Necessity. GAP-A (S polynomial) implies (FIRED⁺-R) at every context. By Lemma W (≤ 1 tangle per top per search, §22t),
  #fired⁺(R) ≤ |T_phase| ≤ n·S. GAP-A also implies (CTX⁺), since one search is polynomial (R5 (k)), so there are polynomially
  many calls.
- Sufficiency. (CTX⁺) ∧ (FIRED⁺-R) implies GAP-A (this corollary).
- So (CTX⁺) ∧ (FIRED⁺-R) ⇔ GAP-A up to polynomial factors. This is an equivalence, not a reduction.
- At G′ alone, (FIRED⁺-R) is necessary and bounds the root-e* transitions (N11-b1). On families where every transition's first
  difference is at the root, such as spp_chain_up, it is the whole count. In that sense it is "essentially GAP-A", as §23s
  says.
