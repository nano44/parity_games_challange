## 1. EXACT* — SIGN
F_τ is the set of tangles for which attractTangle returned true (184-190) during region τ's pop loop (697-702). Such a
tangle added at least one vertex (146, 163-172).
- P(τ) ⊆ Cl(P(τ⁺) ∪ {τ}; F_τ). The code's derivation of region(τ) is a sequence of rule instances (R2-P7 §1, (⊆)). Its
  tangle instances are, by definition, tangles of F_τ. Each instance is valid in the closure with tangle set F_τ.
- Cl(…; F_τ) ⊆ Cl(…; T \ E_τ) = P(τ). F_τ ⊆ T \ E_τ, because a fired tangle has no vertex in P(τ⁺) (138-139). Then
  monotonicity in the tangle set and EXACT give the inclusion.
- N8-1: §22s labels the first inclusion "⊇" and the second "⊆", reading the equation as Cl = P(τ). The content is right.
