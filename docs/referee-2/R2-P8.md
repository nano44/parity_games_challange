## 1. EXACT* — SIGN
F_τ is the set of tangles for which attractTangle returned true (184-190) during region τ's pop loop (697-702). Such a
tangle added at least one vertex (146, 163-172).
- P(τ) ⊆ Cl(P(τ⁺) ∪ {τ}; F_τ). The code's derivation of region(τ) is a sequence of rule instances (R2-P7 §1, (⊆)). Its
  tangle instances are, by definition, tangles of F_τ. Each instance is valid in the closure with tangle set F_τ.
- Cl(…; F_τ) ⊆ Cl(…; T \ E_τ) = P(τ). F_τ ⊆ T \ E_τ, because a fired tangle has no vertex in P(τ⁺) (138-139). Then
  monotonicity in the tangle set and EXACT give the inclusion.
- N8-1: §22s labels the first inclusion "⊇" and the second "⊆", reading the equation as Cl = P(τ). The content is right.
- Probe: EXACT* holds at 463,742 / 463,742 region steps (Oink order) and 463,743 / 463,743 (R2_REV=1), with 0 failures.
  At every step F_τ ⊆ T \ E_τ and F_τ ∩ P(τ⁺) = ∅, with 0 exceptions. 24,140 / 24,192 steps fired at least one tangle.

## 4. The §22u chain, as a conditional statement — VALID with corrections
The chain, with the steps checked:
1. F_R ≤ 3·N*_R (§3, G8-1). §22u writes "F_R ≤ #relevant-steal visits", which needs the factor 3 when the visits counted
   are consecutive pairs.
2. Every relevant-steal pair contains at least one relevant triple (round r, top τ, tangle t) with t ∈ F_τ in the earlier
   visit.
3. Let (STEAL-ONCE*) be the weaker form of (STEAL-ONCE): each RELEVANT triple is newly stolen at most once per phase.
   Under it, N*_R ≤ #distinct relevant triples at R, because each pair is charged to a triple used by no other pair.
4. Count the triples:
   - rounds ≤ |V_1| + 1 ≤ |R| + 1, since every non-final round removes a vertex (748-772);
   - tops ≤ |R|;
   - tangles ∈ FIRED(R).
   So N*_R ≤ (|R| + 1)·|R|·#fired(R).
5. Hence F_R ≤ 3(|R| + 1)|R|·#fired(R) ≤ 3(n+1)n·#fired(R). §22u's (n+1)·n·#fired(R) lacks the factor 3.
6. G8-2 (closed). (FALL) is "Σ_{R ∈ C_bv} F_R polynomial", a sum over the first-difference contexts. The per-context bound
   gives (FALL) only together with a polynomial |C_bv|, which is part of (CTX⁺). So "(FALL) ⇐ (STEAL-ONCE) ∧ (FIRED-R)"
   is right per context. As a statement about (FALL) it needs (CTX⁺). The conclusion that matters is unaffected:
   GAP-A ⇐ (CTX⁺) ∧ (STEAL-ONCE) ∧ (FIRED-R), given STR-DET, with the R9 budget as corrected in R2-P7 §7.
- The circularity remark of §22t is correctly removed. The count uses #fired(R), not |T_phase|.
