## 1. (a) Lemma ENTRY-CHARGE — SIGN WITH GAPS (closed)
Step 1 (event → entry): CORRECT.
- (i, q = (σ, t)) is an event: t ∈ F_σ(i), and t meets P_{i+1}(σ⁺) without being contained in it.
- t fired in region σ at visit i, so t ∩ P_i(σ⁺) = ∅. A firing tangle's vertices are in CurZ (136-137) or CurR (138-139).
  CurR = R \ P(σ⁺) minus the popped vertices (690, 699); this is G9-b1.
- So each w ∈ t ∩ P_{i+1}(σ⁺) enters at (σ, w, i).

Step 2 (fan-out < |R|): CORRECT. This is the step that removes (FIRED-R), and I checked it line by line.
- Events mapped to one entry (σ, w, i) share σ and i, so they are distinct quadruples (σ, t) with distinct t ∈ F_σ(i).
  Fan-out ≤ |F_σ(i)|.
- attractTangle returns true only if some vertex v of t has !Z[v] (CurZ) and R[v] (CurR) and pr ≤ max_prio. That is
  can_attract_new (142-146).
- Between that check and the attract loop nothing writes Z. So that v is added at 169-172: `if (Z[v]) continue; Z[v] = true`.
- Each firing therefore adds at least one vertex to CurZ that was not there before. CurZ only grows during the step: no line in
  690-705 or in the attract functions clears it before 704.
- The top τ is in CurZ before any firing (693). So each distinct fired tangle can be mapped to a distinct vertex it added, in
  region(σ) \ {τ}.
- A tangle cannot fire twice in one step: after firing, all its vertices are in CurZ, so 146 rejects it.
- Hence |F_σ(i)| ≤ |region_i(σ)| − 1 ≤ |R| − 1, and Σ_q k_q = #events ≤ (|R| − 1)·N_ent ≤ |R|·N_ent.
- The bound is per entry (one visit, one step), which is why no phase-wide count of fired tangles enters.

Step 3 (entries ≤ exits + 1 per (σ, w)): CORRECT, with G10-a1.
- For fixed (σ, w), the indicator [w ∈ P_i(σ⁺)] along the visits i = 1, 2, … changes from 0 to 1 at entries and from 1 to 0 at
  exits. So entries ≤ exits + 1.
- Steps: r ≤ |V_1| + 1 ≤ |R| + 1 (748-772, V_1 = the p-vertices of R, 662-667), and τ ranges over the p-vertices of R, so
  ≤ (|R|+1)|R| steps. There are ≤ |R| vertices w.
- So N_ent ≤ X_R + (|R|+1)|R|².
- G10-a1 (definition; closed). The alternation needs P_i(σ⁺) and the exit count at EVERY visit, for a FIXED (σ, w).
  - §23q says "P_i(σ⁺) is defined for every τ ∈ V_r, processed or not". If "τ ∈ V_r" is read per visit, an exit at a pair where
    τ ∉ V_r of that visit is not counted, while a later entry at τ is. Then entries ≤ exits + 1 is not guaranteed.
  - The fix is the reading the step count already uses: X_R counts exits over the fixed set {(r, τ) : r ≤ |R|+1, τ a p-vertex
    of R}, with virtual rounds as in G9-b2. P_i(σ⁺) is the union of the round-r regions of tops above τ, defined whether or not
    τ ∈ V_r.
  - My probe uses this wide set. A narrow-reading variant (an10b.py) did not break the alternation on the DE20 instances, but
    the proof does not cover it.
  - The wide X_R is larger than §23p's numbers (up to 33.8·|R| here, against 3.78·|R| in §23p). The data bounds below are for
    the wide count.

## 2. (b) Corollary C1 — SIGN, with N10-b1
- (EXITS-POLY) ⇒ (STEAL-POLY_sum) by (a). With R12 (a) (signed), GAP-A ⇐ (CTX⁺) ∧ (EXITS-POLY), given STR-DET. Neither
  (FIRED-R) nor (STEAL-DEPTH) is used. CORRECT.
- N10-b1 (what is new). FIRED-freeness was already available. R11 (c) is signed: F_R ≤ 3·N*_R, with N*_R the consecutive
  visit pairs with a relevant steal. So GAP-A ⇐ (CTX⁺) ∧ (RELSTEAL) holds, with (RELSTEAL) meaning N*_R is polynomial, and it
  needs no (FIRED-R). (FIRED-R) entered only through the per-quadruple routes (STEAL-ONCE, k_R, depth).
- Shorter route, by step 1 alone. Every pair with a relevant steal contains an entry at that pair, and distinct pairs give
  distinct entries. So N*_R ≤ N_ent ≤ X_R + (|R|+1)|R|², and
  F_R ≤ 3·N*_R ≤ 3·(X_R + (|R|+1)|R|²).
  This route does not need step 2 or the sum form R12 (a). Probe: N*_R ≤ N_ent in every (context, phase).

## 3. (c) Corollary C2 — SIGN
- (EXIT_c) gives X_R ≤ c·(|R|+1)|R|·|R| = c(|R|+1)|R|². So N_ent ≤ (c+1)(|R|+1)|R|², and Σ_q k_q ≤ |R|·N_ent ≤ (c+1)(|R|+1)|R|³.

- Via N10-b1, the bound tightens to F_R ≤ 3(c+1)(|R|+1)|R|². The argument works the same for c = poly(|R|).

## 4. (d) Corollary C3, the honesty clause — CONFIRMED, no stronger than claimed
- X_R ≤ N*_R·|R|·#steps. By CHARGE's local PREFIX-MONO-X* with round alignment (R12 (b); G23g-1/2), an exit at pair m means
  P_m(σ⁺) ⊄ P_{m+1}(σ⁺). That forces a relevant steal at pair m, so the pair is counted in N*_R. Each such pair has at most
  |R| × #steps exits.
- Together with the bounds above:
  N*_R ≤ Σ_q k_q ≤ |R|·N_ent ≤ |R|(X_R + (|R|+1)|R|²) and X_R ≤ |R|(|R|+1)|R|·N*_R.
  So (RELSTEAL), (STEAL-POLY_sum) and (EXITS-POLY) are equivalent up to polynomial factors per context. ENTRY-CHARGE is a
  reformulation, not a reduction, exactly as §23q says.
- What is gained is a premise that can be stated locally: (EXIT_c) speaks about one (step, vertex). It is FIRED-free, but so
  was (RELSTEAL) (N10-b1).
- Probe: X_R ≤ N*_R·|R|·#steps held in every (context, phase), and there are no exits in a (context, phase) without a
  relevant steal.
